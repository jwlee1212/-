# 일러스트·배경 자리

대화 화면(`scripts/screens/dialogue_view.gd`)은 아래 경로에 PNG 가 있으면 자동으로 쓰고, 없으면 자리(테두리 상자 + 이름 + 경로)만 보여 준다.

- 원칙 6: 대화 화면 일러스트는 애니메이션풍 반신, 인게임 캐릭터(`characters/`)는 SD 카툰풍. 실사·사실적 AI 얼굴 금지. AI 로 만든 그림은 `licenses/assets.md` 에 도구와 상업 이용 여부를 적는다
- 일러스트: 세로로 긴 그림(대략 3:4, 높이 1000px 안팎, 배경 투명). 화면 왼쪽에 서고 아래쪽은 대사창에 가려진다
- 배경: 가로 그림(844×390 비율 이상, 1688×780 권장). 화면을 덮도록 잘린다

## 인게임 캐릭터 `characters/batter/` (타자 뒷모습, 포즈별 그림)

`scripts/characters/batter_sprite.gd` 가 진행에 맞춰 그림을 갈아 끼운다. 없는 포즈는 준비 자세가 대신 나온다.

| 파일 | 포즈 | 언제 |
|---|---|---|
| `stance.png` | 준비 자세 | 공을 기다릴 때 — **들어 있다** |
| `load.png` | 힘 모으기 | 투수가 던지기 시작해서 스윙 전까지 — **들어 있다** |
| `contact.png` | 맞는 순간 | 탭한 순간부터 (히트스톱 동안 이 그림에서 멈춘다) — **들어 있다** |
| `follow.png` | 팔로스루 | 스윙 끝 — **들어 있다** |
| `bunt.png` | 번트 | 스윙 종류가 번트일 때 |

넣는 법: 초록(#00FF00) 배경 원본을 `source/<포즈>.png` 로 넣고 `scripts/cut_batter_poses.py` 를 돌린다. 그다음 `batter_sprite.gd` 의 `FRAMES` 에 그 그림의 발 자리와 키(헬멧 꼭대기~발바닥, 픽셀)를 적는다 — 포즈마다 그림 크기가 달라도 이 숫자로 키와 발 자리를 맞춘다.
