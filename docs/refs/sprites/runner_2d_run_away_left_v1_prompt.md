# 주자 2D 좌상향 달리기

내장 이미지 생성 도구 사용. 우상향 달리기 줄의 그림체와 비율을 참조했다.

Single horizontal strip of four equal cells, four frame baseball baserunner run loop. Use only middle row of reference as character and scale. Change running direction to screen UPPER LEFT: show back and LEFT side of helmet with brim unmistakably pointing LEFT, runner moving diagonally away from camera, torso leaning left. Same overhead broadcast angle, squat proportions, blue helmet, white jersey, short blue shoes, smooth clean 2D cel art. Four distinctly different phases left to right: left leg forward and right trailing, passing stance, right leg forward and left trailing, opposite passing stance. Alternating arms, no glove, no bat. Same scale and centered anchor, entire body per cell. Actual transparent alpha, no background, shadow, glow, text, grid, props. Only four running sprites in one row.
