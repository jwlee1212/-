# 11. FA와 트레이드

## 확정 사항
- 연봉 상한은 **소프트캡** (초과 시 제재금, 연속 초과 시 제재 강화)
- 2차 드래프트 없음
- FA 협상: **역제안 + 경쟁 입찰로 조건 상승**
- 트레이드·FA 가치에 **포지션 필요도 가중치**
- 핵심 목표: **AI가 호구가 되지 않게**

## 선수 가치 평가 (공통)
```
선수 가치 = Σ(향후 N년 기대 WAR × 연도 가중치) − 남은 계약 연봉 부담
최종 가치 = 선수 가치 × 포지션 필요도
```
- 기대 WAR: 현재 능력치 + 09의 나이 곡선 예측
- AI는 오차 섞인 정보로 평가 (02), 폼은 거의 무시 (08)

| 구단 모드 | 평가 |
|---|---|
| 우승 도전 | 올해 WAR 가중 큼, 지명권·유망주 낮게 |
| 중립 | 균형 |
| 리빌딩 | 3~5년 후 WAR 가중, 베테랑 낮게, 지명권 높게 |
AI 구단 모드는 순위·선수단 나이로 시즌 시작과 트레이드 마감 전에 재결정.

## 포지션 필요도 (0.8 ~ 1.5)
| 팀 상황 | 필요도 |
|---|---|
| 주전 없음 또는 리그 하위 수준 | 1.3~1.5 |
| 주전 있으나 백업 없음 | 1.1 |
| 충분 | 1.0 |
| 넘침 (주전급 둘) | 0.8 |
- **영입 이후 상태로 계산** (한 거래에서 같은 포지션 두 명을 받으면 두 번째는 0.8)
- 투수는 선발 5자리, 불펜 역할별로 판단
- AI에도 동일 적용 → 서로 남는 포지션을 주고받는 윈윈 트레이드가 AI끼리도 성립
- FA 입찰, 드래프트 지명에도 동일 가중치

## FA
**자격** (확인 필요): 고졸 8시즌, 대졸 7시즌, 재자격 4시즌. 한 시즌에 1군 등록 주차가 기준 이상이면 1시즌 인정. 군 복무 기간 불인정.

**등급과 보상** (현실 A/B/C 등급제 참고, 세부 확인 필요)
- 연봉 순위로 등급
- A·B등급 영입 시 원소속팀에 **보상선수 + 보상금**. 영입 팀이 보호선수 명단 제출, 원소속팀이 명단 밖에서 1명 선택
- C등급은 보상선수 없음

**협상**
1. 스토브리그 시작 때 FA 명단 공개 (리그 환경 발표와 동시)
2. 원소속팀 우선 협상 기간 없음
3. 스토브리그를 주차로 나눠 매주 제안 → 응답
4. 선수 판단 요소: 총액, 기간, 우승 가능성, 원소속팀 애정, 출전 기회. 30대는 기간 중시, 20대는 연봉 중시
5. 더 좋은 제안이 오면 언제든 다른 팀과 계약

**경쟁 입찰**
- FA 희망 조건은 시장가에서 출발, **관심 구단 수에 비례해 상승**
- 각 AI 구단은 가치 평가로 **최대 제시액**을 정하고 넘으면 철수. 구단 성향 배율(한강 팬텀스 공격적 등)
- 유저 정보: "N개 구단 관심", 에이전트의 타 구단 제시액 언급 (**과장 섞일 수 있음**)
- **역제안**: 주차당 1회 ("금액은 좋은데 기간 1년 더")
- 스토브리그 종료 시 미계약 FA: 헐값 1년 계약 수락 또는 미계약

**계약 구성**
- **계약금**: 운용 자금에서 일시 지출
- **연봉**: 연봉 총액에 반영
- 연봉 여유는 없고 현금이 많은 구단은 "계약금 크게, 연봉 작게" 전략 가능

**비FA 다년계약**: FA 전 우리 선수와 장기 계약 가능.

## 트레이드
- 시기: 시즌 중(7월 말 마감) + 스토브리그
- 구성: 선수, 지명권, 현금(운용 자금)
- 제약: 외국인 3명 규칙, 엔트리·보유 인원, 연봉 총액
- **AI 수락 조건**: `받는 가치 ≥ 주는 가치 × (1 + 수익 요구치)` (난이도별 요구치, 14)

**꼼수 방지**
- **협상 피로도**: 같은 팀에 거절된 제안을 반복하면 일정 기간 협상 거부 (수락 기준선 탐색 방지)
- 트레이드로 받은 선수를 원 소속팀에 곧바로 되파는 것 금지
- 폼 무시, 영입 후 기준 포지션 필요도

**AI 주도 거래**: AI → 유저 제안(알림함), AI끼리 시즌당 몇 건.

## 방출·연봉 재계약
- 방출: 남은 연봉 전액 지급, 다른 팀이 영입 가능
- 비FA 연봉 재계약: 스토브리그마다 전 시즌 성적(WAR 중심)으로 자동 산정

## 소프트캡
| 초과 | 제재 |
|---|---|
| 1회 | 초과분 50% 제재금 |
| 2회 연속 | 초과분 100% + 다음 드래프트 1라운드 순번 하락 |
| 3회 연속 | 초과분 150% + 순번 하락 |
- 판정 시점: 시즌 종료 시 연봉 총액
- 제재금은 운용 자금에서 지출
- 상한 금액·비율은 현실 경쟁균형세 참고 (확인 필요)
