# 05. 경기 진행 로직

## 확정 사항
- **경기 중 개입 없음.** 문자 중계는 관전 전용. 관전 경기와 넘긴 경기는 같은 로직
- 정규시즌 연장 **11회까지**, 동점이면 **무승부** (승률 계산 제외)
- 포스트시즌 연장 **15회까지**, 무승부 시 시리즈에 추가 경기 (14)
- 시뮬레이터는 경기 종류별 규칙(`GameRules`)을 받는다

## 경기 상태
- 베이스 3비트(1루=1, 2루=2, 3루=4) × 아웃 0~2 = 24가지 상태
- 베이스마다 **주자 선수 객체**와 **그 주자를 내보낸 투수(책임 투수)**, **실책·가상 아웃 관련 여부**를 함께 저장

## 타석 결과의 상태 조건
| 결과 | 가능 조건 |
|---|---|
| 희생플라이 | 3루 주자 + 2아웃 미만 |
| 병살타 | 1루 주자 + 2아웃 미만 |
| 희생번트 | 주자 있음 + 2아웃 미만 |
| 도루 | 해당 베이스 주자 + 다음 베이스 빔 |
조건이 안 맞으면 확률표에서 제거하고 가장 가까운 결과로 대체.

## 주자 진루
안타 시 추가 진루는 주자 주루 능력치로 확률 판정 (주루 50 기준값).
| 상황 | 추가 진루 | 기본 확률 |
|---|---|---|
| 1루타, 2루 주자 | 홈 | ~60% |
| 1루타, 1루 주자 | 3루 | ~28% |
| 2루타, 1루 주자 | 홈 | ~40% |
| 뜬공, 3루 주자 (2아웃 미만) | 태그업 홈인 | 타구 깊이 + 주루 |
| 땅볼, 주자 있음 | 진루 또는 병살 | 타자 주루 + 내야 수비 |
추가 진루 시도에는 **주루사 확률**이 있다.

## 타석 사이 사건
- 도루: 시도 여부는 사전 지시 도루 성향, 성공은 주자 주루 vs 포수 수비
- 폭투·포일: 낮은 확률, 투수 제구·포수 수비 영향

## 실책과 자책점
- 실책: 인플레이 타구의 약 1.5%, 해당 수비수 능력치 영향
- 이닝마다 **"실책이 없었다면 잡혔을 아웃" 카운터**를 둔다
  - 실책으로 출루한 주자의 득점은 비자책
  - 가상 아웃이 3개가 된 이후의 득점은 모두 비자책
- 책임 주자: 투수가 내보낸 주자가 다음 투수 때 득점하면 앞 투수의 실점

## 이닝·경기 종료
- 9회초 종료 시 홈팀 리드면 9회말 생략
- 끝내기: 말 공격에서 결승점이 나는 순간 종료. 끝내기 홈런은 모든 주자와 타자 득점 인정
- 연장 제한 이닝 도달 시 무승부 (정규시즌)

## 투수 기록 판정
| 기록 | 조건 |
|---|---|
| 승리 | 팀이 마지막으로 리드를 잡은 시점의 투수. 선발은 5이닝 이상 필요. 미달 시 구원투수 중 가장 효과적인 투수 |
| 패전 | 결승점 주자를 책임진 투수 |
| 세이브 | 승리 팀 마지막 투수, 승리투수 아님, 그리고 ① 3점 차 이내 등판 후 1이닝 이상 ② 동점 주자가 누상·타석·대기 타석에 있을 때 등판 ③ 3이닝 이상 투구 중 하나 |
| 홀드 | 세이브 상황에 등판해 리드를 지키고 내려간 중간 투수 |

## 이벤트 스트림
```
GameSimulator → List<GameEvent> → StatsRecorder     (항상)
                                → BoxScoreValidator (항상)
                                → CommentaryRenderer(관전 시)
```

## 박스스코어 검증 (매 경기)
| 항목 | 등식 |
|---|---|
| 타석 구성 | 타석 = 타수 + 볼넷 + 사구 + 희생번트 + 희생플라이 + 타격방해 |
| 주자 보존 | 출루 주자 수(안타·볼넷·사구·실책·야수선택·낫아웃·타격방해) = 득점 + 잔루 + 베이스에서 아웃된 주자 |
| 아웃 수 | 투수들이 잡은 아웃 합 = 수비 이닝 × 3 (끝내기·생략 이닝 예외 처리) |
| 득점 일치 | 팀 득점 = 선수 득점 합 = 이닝별 점수 합 |
| 자책점 | 자책점 ≤ 실점 |
| 승패 | 승부가 난 경기: 승리투수 1, 패전투수 1, 세이브 ≤ 1. 무승부: 없음 |

- 개발 중(테스트·디버그 빌드): 실패 시 즉시 예외
- 릴리스 빌드: 로그만 남김
- 팀 출루율 0인데 득점하는 경기는 **정상**일 수 있다 (실책·야수선택·낫아웃·타격방해 출루). 이 출루 방법들을 별도로 기록해 주자 보존 등식에 포함한다.
