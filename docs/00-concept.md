# 00. 컨셉 — 내 선수 커리어 (2026-10-05 확정)

> 이전 컨셉(단장 시뮬레이션, 스카우터)은 git 태그 `pre-redesign`·`pre-godot`에 있다.
> 톤: **캐주얼.** 게임빌 프로야구 같은 SD 캐릭터·연출 (`02-design.md`).

## 1. 한 줄 요약

고교 1학년 야구부 신입이 되어 **내 선수 한 명**을 키운다. 경기에서는 **내 차례만 직접 조작**하고(타석·투구·내 쪽으로 온 수비), 경기 밖에서는 훈련과 돌발 이벤트로 성장과 이야기가 쌓인다. 고교 3년 → 드래프트 → 프로 → 은퇴까지가 한 판이다.

## 2. 유저가 느껴야 할 것

- **"딱!" 하는 손맛**: 타이밍이 맞았을 때의 소리·멈춤·흔들림. 타격 프로토타입에서 확인한 감각이 게임 전체의 기준이다
- **"내가 키운 선수"**: 능력치가 오르면 조작이 실제로 쉬워진다 (컨택이 오르면 판정 폭이 넓어지는 식). 성장이 숫자가 아니라 손으로 느껴진다
- **"이 바닥은 야구만 하는 곳이 아니다"**: 스카우트, 학부모, 감독, 라이벌, 언론 사이에서 내리는 선택이 커리어를 바꾼다

## 3. 커리어 흐름

```
고교 1~3학년 (한 판의 1/3, 게임의 1막)
  주말 리그·전국 대회 → 스카우트 눈도장 → 진로 선택(프로 지명 / 대학 / 독립리그)
드래프트
  지명 순위는 고교 성적·스카우트 평가로. 지명 안 되면 대학·독립리그 경로
프로
  2군에서 시작 → 1군 승격 → 주전 경쟁 → 연봉·FA·트레이드 → 군 입대 시기 → 전성기 → 노쇠
은퇴
  커리어 연대기(스크랩북)와 업적 → 다음 선수로 새 판
```

포지션은 시작할 때 고른다: **타자**(포지션 선택) / **투수** / **투타겸업**(어렵지만 둘 다 한다).

## 4. 경기 — 내 차례만 직접

경기는 자동 시뮬레이션으로 흘러가다가 **내 차례**가 오면 조작 화면으로 넘어간다. 내 차례가 아닌 장면은 문자 중계·하이라이트로 빠르게 지나간다.

| 내 차례 | 조작 (초안) | 능력치 영향 |
|---|---|---|
| 타석 | 공이 오면 탭해서 스윙 (타이밍 → 정타/빗맞음/파울/헛스윙). G1에서 존 조준(노려치기) 추가 | 컨택 = 판정 폭, 파워 = 거리, 선구안 = 구종이 보이는 시점 |
| 투구 | 구종·코스를 고르고 게이지 타이밍으로 제구 → 타자 AI 가 친다 | 구위 = 공 속도·움직임, 제구 = 게이지 폭, 체력 = 투구 수 |
| 수비 | 내 쪽으로 온 타구: 낙구 지점으로 끌어 이동 → 탭으로 포구 → 송구 방향 스와이프 | 수비 범위 = 이동 속도, 포구 = 판정 폭, 송구 = 정확도·속도 |
| 주루 | (선택) 도루·추가 진루 판단만 버튼으로 | 주력 |

- 한 경기에서 내가 조작하는 시간은 **2~5분**을 목표로 한다 (출퇴근 중 한 경기)
- 내 차례가 아닌 경기 결과는 자동 시뮬레이션이 정한다. 같은 판정 규칙을 쓰는 타석 단위 시뮬레이션 (옛 Kotlin 엔진의 Log5 방식을 참고해 GDScript로 다시 만든다, `docs/engine/04`)

## 5. 경기 밖 — 주간 루프

```
한 주 = 훈련 고르기 → 경기(주 1~3회) → 돌발 이벤트 0~2개 → 결산(성장·평판)
```

- **훈련**: 이번 주에 키울 능력치를 고른다 (예: 3칸 배분). 무리하면 컨디션·부상 위험
- **컨디션·폼**: 좋으면 판정 폭이 조금 넓어지고, 나쁘면 좁아진다 — 역시 손으로 느껴지게
- **매주 꼭 해야 하는 결정은 0~3개.** 나머지는 기본값으로 자동 진행

## 6. 돌발 이벤트 (몰입의 중심)

### 6-1. 원칙
1. **공짜 정답이 없다.** 모든 선택지에 대가: 컨디션, 능력치 성장, 평판, 인간관계, 돈, 양심
2. **결과는 늦게 올 수 있다.** 고교 때 받은 뒷돈이 프로 2년 차에 기사로 터지는 식
3. **한 주에 0~2개.** 많으면 업무가 된다
4. 등장인물이 말풍선으로 말을 건다. 톤은 담백한 구어체

### 6-2. 예시
| 시기 | 이벤트 | 선택지 → 여파 |
|---|---|---|
| 고교 | 부모가 스카우트에게 봉투를 건네려 한다 | 말린다 / 모른 척 → 지명 순위↑ 대신 나중에 폭로 위험 |
| 고교 | "○○ 인성 나쁘다" 찌라시가 돈다 (대상이 나) | 해명 / 무시 / 라이벌이 퍼뜨린 증거 찾기 |
| 고교 | 감독이 혹사 등판을 요구 | 던진다(팀 승리↑, 부상 위험) / 거절(감독 신뢰↓) |
| 고교 | 대학 감독이 장학금 제안 | 프로 대신 대학 → 4년 뒤 다시 드래프트 |
| 프로 | 2군 코치가 폼 교정을 권한다 | 받아들인다(일시 하락 후 상승 가능) / 거절 |
| 프로 | 승부조작 브로커 접근 | 거절·신고 / 모른 척 (영구 제명 엔딩 가능) |
| 프로 | 군 입대 시기 | 지금(전성기 전) / 미루기(국제대회 메달로 면제 노림) |
| 프로 | FA 협상 | 의리(친정팀) / 돈 / 우승 가능성 |

## 7. 스토리

- **메인 서사(1막: 고교 3년)**: 약체 야구부의 신입이 동료들과 전국 대회를 노린다. 고정 인물: 무뚝뚝한 감독, 라이벌 학교의 천재, 나를 처음 알아본 스카우트, 부모
- **개인 서사**: 라이벌과의 맞대결이 고교 → 프로로 이어진다. 내가 한 선택이 나중에 다시 돌아온다
- 1막 이후(프로)는 고정 대본보다 이벤트 조합으로 생기는 이야기가 중심

## 8. 빼는 것

- 구단 운영(트레이드 결정·연봉 책정·스카우트) — 나는 선수다
- 팀 전체 조작 — 내 차례만
- 현실 규정의 정밀한 재현 (엔트리 인원, FA 연수 등은 대략)

## 9. 확정된 세부 결정 (유저 승인, 2026-10-05)

- 조작 범위는 **내 선수 한 명** (팀 전체가 아님) — 유저가 "내 선수의 타석"을 프로토타입 목표로 정한 것을 근거로 했다
- 포지션은 시작 시 선택, 투타겸업 허용
- 고교 시즌은 실제보다 짧게 (한 학년 = 경기 15~20개 정도)
- (아직 초안) 투구·수비 조작 방식은 위 표의 초안이고, 각 마일스톤에서 프로토타입으로 손맛을 확인한 뒤 확정한다
