## 1. 한 줄 요약

고교 1학년 야구부 신입이 되어 **내 선수 한 명**을 키운다. 경기에서는 **내 차례만 직접 조작**하고(타석·주루 — 투구·수비 조작은 없다, §0), 경기 밖에서는 구간 훈련·경기 결과 성장과 돌발 이벤트로 성장과 이야기가 쌓인다. 고교 3년 → 드래프트 → 프로 → 은퇴까지가 한 판이다.

## 1-1. 사실성의 기준 (2026-10-06 확정)

목표는 **게임빌 프로야구 2013 + 한국 야구의 사실성**이다.
- **경기 조작**: 게임빌식 손맛(탭 타이밍, 히트스톱·소리·연출)을 유지한다. 스윙은 더쇼처럼 밸런스/컨택/파워/번트 중 고른다
- **기록**: 시즌 기록이 한국 프로·고교 야구 같은 분포로 나와야 한다 (좋은 타자가 3할, 홈런왕이 30~40개, 평범한 타자 삼진율 18~20%). 그래서 타구는 확률표가 아니라 타구 속도·발사각·방향과 수비수 위치로 결과가 정해진다
- **이벤트·커리어**: 한국 야구 제도를 따른다 — 고교 졸업 때 대학 진학/신인 드래프트(지명 순위), 군 복무(상무·경찰야구단·현역, 입대 시기 결정), **아시안게임 금메달·올림픽 메달 병역 특례**, FA 자격 연수, 해외 진출 등. 실명·실제 구단명·학교명은 쓰지 않는다
- **하지 않는 것**: 엔트리 등록·연봉 협상 서류 같은 관리 디테일을 유저가 직접 처리하게 만들지 않는다. 제도는 이벤트와 선택지로 체감하게 한다

## 2. 유저가 느껴야 할 것

- **"딱!" 하는 손맛**: 타이밍이 맞았을 때의 소리·멈춤·흔들림. 타격 프로토타입에서 확인한 감각이 게임 전체의 기준이다
- **"내가 키운 선수"**: 능력치가 오르면 조작이 실제로 쉬워진다 (컨택이 오르면 판정 폭이 넓어지는 식). 성장이 숫자가 아니라 손으로 느껴진다
- **"이 바닥은 야구만 하는 곳이 아니다"**: 스카우트, 학부모, 감독, 라이벌, 언론 사이에서 내리는 선택이 커리어를 바꾼다

## 3. 커리어 흐름

```
고교 1~3학년 (한 판의 1/3, 게임의 1막)
  주말 리그·전국 대회 → 스카우트 눈도장 → 드래프트 (→ §0: 진학·독립리그 경로 없음)
드래프트
  지명 순위는 고교 성적·스카우트 평가로. 유저는 하위 라운드라도 반드시 지명된다 (§0)
프로
  2군에서 시작 → 1군 승격 → 주전 경쟁 → 연봉·FA·트레이드 → 군 입대 시기 → 전성기 → 노쇠
은퇴
  커리어 연대기(스크랩북)와 업적 → 다음 선수로 새 판
```

**타자 전용 (2026-10-06 결정).** 포지션(내야·외야 등)만 고른다. 투수·투타겸업은 볼륨이 커서 백로그로 미룬다.

## 4. 경기 — 내 차례만 직접

경기는 자동 시뮬레이션으로 흘러가다가 **내 차례**가 오면 조작 화면으로 넘어간다. 내 차례가 아닌 장면은 문자 중계·하이라이트로 빠르게 지나간다.

| 내 차례 | 조작 (초안) | 능력치 영향 |
|---|---|---|
| 타석 | 스윙 종류(밸런스/컨택/파워/번트)를 고르고, 공이 오면 탭해서 스윙 (타이밍 → 정타/빗맞음/파울/헛스윙). 노려치기. 맞으면 타구 중계 화면 | 컨택 = 판정 폭, 파워 = 타구 속도, 선구안 = 구종이 보이는 시점, 주력 = 내야안타·추가 진루 |
| ~~수비~~ | ~~내 쪽으로 온 타구 포구·송구~~ → 삭제 (§0, 수비는 자동) | — |
| 주루 | (선택) 도루·추가 진루 판단만 버튼으로 | 주력 |

- 한 경기에서 내가 조작하는 시간은 **2~5분**을 목표로 한다 (출퇴근 중 한 경기) → §0: 짧은 경기 1~2분, 모든 경기를 직접
- 내 차례가 아닌 장면의 결과는 자동 시뮬레이션이 정한다 (경기 전체를 넘기는 시뮬레이션은 없다, §0). 같은 판정 규칙을 쓰는 타석 단위 시뮬레이션 (옛 Kotlin 엔진의 Log5 방식을 참고해 GDScript로 다시 만든다, `docs/engine/04`)

## 5. 경기 밖 — 주간 루프 (→ §0: 구간 진행으로 바뀜, 주간 스케줄 삭제)

새 루프: 구간 시작(목표 확인 + 훈련 방향 하나) → 구간 안 모든 경기를 직접 → 경기마다 결과 성장 → 이야기 카드·돌발 이벤트 → 구간 결산. 아래는 옛 내용.

```
한 주 = 평일 스케줄(칸 3개) → 주말 경기 → 돌발 이벤트 0~2개 → 결산(성장·평판)
```

- **스케줄 (2026-10-21, 러브딜리버리 참고)**: 홈 화면은 "내 방" — 방 그림 위에 내 선수 일러스트, 옆에 이번 주 달력. 평일을 월·화 / 수·목 / 금 세 칸으로 나눠 칸마다 훈련·휴식을 넣고 [스케줄 시작]을 누르면 칸마다 **대성공·성공·실패** 도장이 찍힌다. 지치면 실패가 늘어 휴식을 끼워 넣게 된다. 지난주 스케줄을 이어 쓰므로 바꿀 칸만 고친다 (결정 0~3개 원칙 유지). 무리하면 컨디션·부상 위험
- **컨디션·폼**: 좋으면 판정 폭이 조금 넓어지고, 나쁘면 좁아진다 — 역시 손으로 느껴지게
- **매주 꼭 해야 하는 결정은 0~3개.** 나머지는 기본값으로 자동 진행

## 6. 돌발 이벤트 (몰입의 중심)

### 6-1. 원칙
1. **공짜 정답이 없다.** 모든 선택지에 대가: 컨디션, 능력치 성장, 평판, 인간관계, 돈, 양심
2. **결과는 늦게 올 수 있다.** 고교 때 받은 뒷돈이 프로 2년 차에 기사로 터지는 식
3. **한 주에 0~2개.** 많으면 업무가 된다
4. 등장인물이 말풍선으로 말을 건다. 톤은 담백한 구어체

### 6-2. 예시
| 시기 | 이벤트 | 선택지 → 여파 |
|---|---|---|
| 고교 | 부모가 스카우트에게 봉투를 건네려 한다 | 말린다 / 모른 척 → 지명 순위↑ 대신 나중에 폭로 위험 |
| 고교 | "○○ 인성 나쁘다" 찌라시가 돈다 (대상이 나) | 해명 / 무시 / 라이벌이 퍼뜨린 증거 찾기 |
| 고교 | 감독이 혹사 등판을 요구 | 던진다(팀 승리↑, 부상 위험) / 거절(감독 신뢰↓) |
| 고교 | 대학 감독이 장학금 제안 | 프로 대신 대학 → 4년 뒤 다시 드래프트 |
| 프로 | 2군 코치가 폼 교정을 권한다 | 받아들인다(일시 하락 후 상승 가능) / 거절 |
| 프로 | 승부조작 브로커 접근 | 거절·신고 / 모른 척 (영구 제명 엔딩 가능) |
| 프로 | 군 입대 시기 | 지금(전성기 전) / 미루기(국제대회 메달로 면제 노림) |
| 프로 | FA 협상 | 의리(친정팀) / 돈 / 우승 가능성 |
