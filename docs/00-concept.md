# 00. 새 컨셉 — 스카우터 (초안, 2026-10-05)

> 상태: **확정 (2026-10-05)**. 기존 기획(단장 시뮬레이션 상세판)은 git 태그 `pre-redesign`에 보존돼 있다.
> 톤: **캐주얼.** 게임빌 프로야구 같은 SD 캐릭터·일러스트·애니메이션 (`02-design.md`).

## 1. 한 줄 요약

가상 프로야구 리그의 **한 구단 소속 아마추어 스카우터**가 되어 고교 선수들을 관찰·분석하고, 드래프트에서 누구를 뽑을지 구단을 설득하는 모바일 텍스트 게임.
바탕은 숫자로 하는 분석이고, 몰입은 **돌발 이벤트**에서 나온다.

## 2. 유저가 느껴야 할 것

- "남들이 못 본 걸 나는 봤다": 불완전한 단서로 진짜 실력을 추리하는 재미
- "이 바닥은 숫자만으로 굴러가지 않는다": 뒷돈, 찌라시, 학부모, 감독, 라이벌 구단 사이에서 내리는 판단
- "내 선택이 몇 년 뒤 돌아온다": 내가 밀었던 선수, 거른 선수의 프로 커리어가 성적표로 돌아온다

## 3. 핵심 루프

```
[주 단위, 3~8월]
  1. 이번 주 일정 고르기: 어느 대회·학교에 갈지 (시간·출장비 한정 — 전부는 못 본다)
  2. 관찰: 경기 결과 + 관찰 카드(정성적 단서) 수집 → 선수 파일의 범위 막대가 좁혀짐
  3. 돌발 이벤트: 주에 0~2개. 선택지가 있고, 결과는 즉시 또는 나중에 돌아옴
[9월 드래프트]
  4. 보고서: 내 추천 순위(빅보드) 작성
  5. 스카우트 회의: 팀장·단장에게 설득. 내 평판과 구단의 필요(예: "좌완이 급하다")가 충돌
  6. 드래프트 당일: 내 추천이 채택됐나, 다른 팀이 먼저 채갔나
[겨울: 시간 점프]
  7. 내가 봤던 선수들의 프로 성적이 쌓임 → 적중률·평판 갱신 → 승진/이직/해고
```

장기 목표: 지역 담당 스카우터 → 스카우트 팀장 → (엔딩 후보) 단장 또는 타 구단 스카우트 디렉터.

## 4. 숫자 레이어 (바탕)

- 선수의 진짜 능력치·잠재력·성향은 숨김. 유저는 **범위 막대**와 **등급**으로만 본다 (기존 `ScoutingView` 재사용)
- 관찰할수록 범위가 좁아진다. 단, 표본이 적으면 운에 속는다 (고교 경기는 엔진이 실제로 시뮬레이션하므로 3타수 3안타가 진짜 실력인지 운인지 구분해야 함)
- 관찰 카드는 숫자 대신 말로 준다. 예: "직구가 끝에서 살아 들어온다", "볼카운트가 몰리면 표정이 굳는다". 카드 하나가 어떤 숨김 수치와 연결되는지는 유저가 경험으로 배운다
- **숫자 화면은 유저가 원할 때 펼쳐 보는 곳**이지, 매주 처리해야 하는 일이 아니다

## 5. 돌발 이벤트 (몰입의 중심)

### 5-1. 설계 원칙

1. **이벤트는 정보이기도 하다.** 찌라시·제보·면담 결과는 숨김 수치(성향·부상 이력·성장 여지)와 연결된다. 사실일 수도, 거짓일 수도 있다
2. **공짜 정답이 없다.** 모든 선택지에 대가가 있다: 돈, 시간, 평판, 인맥, 양심(청렴도)
3. **결과는 늦게 올 수 있다.** 뒷돈을 받은 선택이 3년 뒤 기사로 터지는 식. 과거 선택이 다시 돌아오는 게 몰입을 만든다
4. **한 주에 0~2개.** 많으면 다시 업무가 된다
5. 비서 대신 **팀장(상사)과 동료 스카우터**가 말을 건다. 톤은 담백한 구어체

### 5-2. 이벤트 예시

| 이벤트 | 선택지 | 대가와 여파 |
|---|---|---|
| 학부모가 봉투를 내밈 | 거절 / 받고 모른 척 / 받고 상부 보고 | 받으면 돈 +, 청렴도 −, 나중에 폭로 위험. 거절하면 그 학부모·학교와 관계 악화 |
| "○○ 인성 나쁘다" 찌라시가 돎 | 무시 / 직접 확인(출장비·시간) / 라이벌 구단에 역이용 | 사실이면 지명 후 사고, 거짓이면 라이벌이 퍼뜨린 견제일 수 있음 |
| 고교 감독이 "우리 애 좀 봐 달라" | 일정 바꿔 방문 / 거절 | 방문하면 다른 대회를 놓침. 감독과의 인맥이 다음 제보로 이어짐 |
| 유망주가 비공개 부상을 숨기는 듯 | 의료 기록 요청 / 넘어감 | 요청하면 학교 측 반발, 넘어가면 지명 후 수술 위험 |
| 라이벌 구단 스카우터가 정보 교환 제안 | 수락 / 거절 / 가짜 정보 흘리기 | 정보는 얻지만 내 관심 선수가 노출됨 |
| 팀장이 "윗선이 ○○를 원한다"며 압박 | 따른다 / 내 판단을 고집 | 따르면 평판 보존, 고집해서 맞히면 크게 오르고 틀리면 크게 깎임 |
| 선수가 "프로 대신 대학 간다" 소문 | 직접 설득 / 다른 후보로 전환 | 지명권 낭비 위험 |

### 5-3. 유저 상태값

- **평판**: 구단 안에서의 신뢰. 회의 설득력과 승진을 좌우
- **적중률**: 내가 추천한 선수들의 실제 프로 성적으로 매겨지는 성적표
- **청렴도**: 숨김에 가까운 값. 낮으면 폭로 이벤트가 생긴다
- **인맥**: 감독·학부모·동료 스카우터와의 관계. 제보의 질과 양을 좌우
- **예산·시간**: 주마다 쓸 수 있는 출장 횟수

## 6. 보상 구조 (늦은 보상 보완)

- 짧은 보상: 관찰 직후 범위 좁혀짐, 이벤트 즉시 결과, 드래프트 당일 결과
- 중간 보상: 지명 1년 차 퓨처스 성적, 라이벌 스카우터와의 적중률 비교
- 긴 보상: 시간 점프 시 커리어 연대기 — "2027년 내가 3라운드에 민 투수, 2031년 다승왕"

## 7. 빼는 것

FA·트레이드·연봉·샐러리캡·외국인 선수·구단 경영·재정·로스터 운영·경기 작전 지시·감독 AI 조작.
프로 리그는 배경에서 자동으로 굴러가며, 유저는 **결과만 본다**.

## 8. 기존 엔진 재사용

| 살림 | 용도 |
|---|---|
| `sim/`, `stats/` | 고교 경기 시뮬레이션(=관찰 재료), 배경 프로 리그 |
| `model/` (Player, HiddenTraits, Personality) | 선수와 숨김 수치 |
| `development/` | 고교 선수 성장, 지명 후 프로 커리어 |
| `condition/Injury` | 숨긴 부상 이벤트의 근거 |
| `scouting/ScoutingView` 계열 | 범위 막대·등급 노출 |
| `market/DraftPool`, `Draft`, `DraftAI` | 드래프트 풀 생성과 타 구단 지명 |
| `events/Incidents`, `season/IncidentDesk` | 돌발 이벤트 뼈대 (검토 후 재사용 여부 결정) |
| `text/`, `util/`, 리그 생성기 | 이름·조사 처리, 시드 랜덤 |

정리 대상: `management/` 대부분, `market/`의 FA·트레이드·외국인, `season/`의 로스터·오프시즌 운영, `tactics/`(배경 리그용 기본 AI만 남김), `app/` 화면 전체.

## 9. 임시 결정 (유저가 "그대로 진행"으로 승인, 2026-10-05)

- **한 판의 길이**: 커리어형(여러 드래프트 시즌). 한 시즌(3월~9월 드래프트)은 30~40분 정도를 목표로 한다
- **관찰 방식**: 기본은 관찰 카드 요약. 문자 중계는 원할 때만 펼쳐 본다
- **담당 범위**: 처음엔 한 지역(예: 3~4개 고교 권역)만 담당하고, 승진하면 전국으로 넓어진다
- **대학·독립리그 선수**: 1차 버전에서는 고교만
