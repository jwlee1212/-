# 14. 게임 목표와 진행

## 확정 사항
- 끝이 정해지지 않은 커리어 게임
- 플레이 모드는 **단장 전용 / 감독 겸직** 두 가지 (감독 전용 제외)
- **시나리오 모드는 정식 출시 이후 업데이트**

## 목표 구조
- 단기: 구단주 시즌 목표 (13)
- 중장기: 업적
- 최종: 유저가 은퇴를 선택하면 커리어 기록으로 **명예의 전당** 평가

| 업적 예시 | 조건 |
|---|---|
| 첫 우승 | 한국시리즈 우승 |
| 왕조 | 3년 연속 우승 |
| 기적의 재건 | 꼴찌 팀을 3년 안에 우승 |
| 드래프트의 신 | 5라운드 이하 지명 선수가 올스타 |
| 짠돌이 단장 | 연봉 총액 최하위로 PS 진출 |
| 전국구 단장 | 서로 다른 3개 구단에서 우승 |

## 플레이 모드
- 단장 전용: 선수단 운영. 경기는 감독 캐릭터에게
- 감독 겸직: 사전 지시 규칙표 직접 편집
- 변경은 시즌 사이에만

## 난이도
주 난이도는 **구단 선택**. 세부 설정:
| 항목 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| AI 트레이드 수익 요구치 | 낮음 | 보통 | 높음 |
| 스카우트 정확도 | 보너스 | 기본 | 페널티 |
| 구단주 인내심 | 높음 | 보통 | 낮음 |
| 부상 발생률 | 낮음 | 기본 | 기본 |

## 포스트시즌 규정 (확인됨)
- 연장: 정규이닝 + 최대 6이닝 = **15회까지**
- 무승부: 승패 없이 넘어가고, 승자가 나올 때까지 **추가 경기**
- 와일드카드: 4위가 **1승 안고 시작**, 전 경기 4위 홈, 4위는 1승 또는 1무로 진출. 5위는 2연승 필요
- 준PO·PO 5전 3선승, KS 7전 4선승
- `GameRules`로 정규시즌(11회, 무승부 인정)과 분리

## 세이브
- 자동 저장: 매주 결정 단계 시작 + 스토브리그 단계마다
- 수동 슬롯 3개
- 내용: 선수 약 580명, 현재 시즌 박스스코어, 역대 누적 기록, 리그 상수, 단장 커리어, 주차별 랜덤 시드
- **랜덤 결과 고정 (기본)**: 주차 시드를 세이브에 저장 → 같은 결정이면 같은 결과
- **아이언맨 모드 (옵션)**: 자동 저장 1개, 되돌리기 불가
