# 14. 게임 목표와 진행

## 확정 사항
- 끝이 정해지지 않은 커리어 게임
- 플레이 모드는 **단장 전용 / 감독 겸직** 두 가지 (감독 전용 제외)
- **시나리오 모드는 정식 출시 이후 업데이트**

## 목표 구조
- 단기: 구단주 시즌 목표 (13)
- 중장기: 업적
- 최종: 유저가 은퇴를 선택하면 커리어 기록으로 **명예의 전당** 평가

| 업적 예시 | 조건 |
|---|---|
| 첫 우승 | 한국시리즈 우승 |
| 왕조 | 3년 연속 우승 |
| 기적의 재건 | 꼴찌 팀을 3년 안에 우승 |
| 드래프트의 신 | 5라운드 이하 지명 선수가 올스타 |
| 짠돌이 단장 | 연봉 총액 최하위로 PS 진출 |
| 전국구 단장 | 서로 다른 3개 구단에서 우승 |

## 플레이 모드
- 단장 전용: 선수단 운영. 경기는 감독 캐릭터에게
- 감독 겸직: 사전 지시 규칙표 직접 편집
- 변경은 시즌 사이에만

## 난이도
주 난이도는 **구단 선택**. 세부 설정:
| 항목 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| AI 트레이드 수익 요구치 | 낮음 | 보통 | 높음 |
| 스카우트 정확도 | 보너스 | 기본 | 페널티 |
| 구단주 인내심 | 높음 | 보통 | 낮음 |
| 부상 발생률 | 낮음 | 기본 | 기본 |

## 포스트시즌 규정 (확인됨)
- 연장: 정규이닝 + 최대 6이닝 = **15회까지**
- 무승부: 승패 없이 넘어가고, 승자가 나올 때까지 **추가 경기**
- 와일드카드: 4위가 **1승 안고 시작**, 전 경기 4위 홈, 4위는 1승 또는 1무로 진출. 5위는 2연승 필요
- 준PO·PO 5전 3선승, KS 7전 4선승
- `GameRules`로 정규시즌(11회, 무승부 인정)과 분리

## 포스트시즌 진행 (2026-10-03)
- 우리 시리즈는 **한 경기씩**, 남의 시리즈는 시리즈째 진행. 시작 버튼은 대진만 짠다
- 단장 결정 (단장 전용 원칙 유지 — 라인업·선발 순서는 감독): ① 방침 총력전/정상/보호(경기마다, 기본 총력전) ② 다음 경기 휴식 지시(경기 후 해제) ③ 엔트리(우리 시리즈 시작 전까지, 재등록 제한 없음 — 임시)
- 경기마다 하루 피로 회복, 시리즈 사이 쉬는 날 1일(임시). 부상·폼 변화는 없음
- 포스트시즌 진행 상태는 세이브에 들어간다. 경기마다 시드를 따로 뽑아 도중 저장·불러오기 후에도 결과가 같다

## 세이브
- 자동 저장: 매주 결정 단계 시작 + 스토브리그 단계마다
  - 〔구현 2026-10-01〕 **상태가 바뀔 때마다(1초 디바운스) 주차 경계 상태를 저장한다** — 한 주 진행, 엔트리 조작, 트레이드, 돌발 이벤트 답 모두.
    주중 멈춤(돌발 이벤트)·드래프트 도중·**스토브리그·FA 시장 중에는 저장하지 않는다** → 그때 앱을 닫으면 직전 세이브(그 주 시작 / 시즌 종료)로 돌아가고,
    시드가 같아서 같은 일이 다시 일어난다. 스토브리그 단계별 저장은 아직 아니다 (오프시즌 상태를 담는 일은 별도 작업)
  - 세이브 = "지금 리그"(선수·자금·팬심·지명권) + 시즌 스냅샷(순위·기록·엔트리 이력·스카우트·드래프트·뉴스·결정 일지 …) + 게임 시드 + 지난주 결산. 약 1.2MB
  - 주차 시드는 세이브에 따로 넣지 않고 **게임 시드 하나에서 (시즌, 주차, 단계)로 파생**한다 (`util/Seeds`). 결과는 같다
- 수동 슬롯 3개
- 내용: 선수 약 580명, 현재 시즌 박스스코어, 역대 누적 기록, 리그 상수, 단장 커리어, 주차별 랜덤 시드
- **랜덤 결과 고정 (기본)**: 주차 시드를 세이브에 저장 → 같은 결정이면 같은 결과
- **아이언맨 모드 (옵션)**: 자동 저장 1개, 되돌리기 불가
