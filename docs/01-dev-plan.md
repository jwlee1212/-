## G1.5. 타석의 사실성 (2026-10-06 유저 결정)
- 스윙 종류 4가지 (더쇼 방식): 밸런스 / 컨택(판정 폭↑ 타구 속도↓) / 파워(판정 폭↓ 타구 속도·발사각↑) / 번트(판정 폭 넉넉, 짧게 굴림, 2스트라이크 번트 파울 = 삼진)
- 타구 물리: 타구 속도·발사각·방향 → 공기 저항이 있는 궤적 → 비거리·체공 시간
- 수비수 9명 기본 위치 → 뜬공은 체공 시간 안에 도달하면 아웃, 땅볼은 내야수가 길목을 막고 1루 송구가 타자보다 빠르면 아웃, 아니면 안타. 장타는 수비수가 공을 줍고 던지는 시간 vs 타자 주루 시간으로
- 구장: 좌우 펜스 거리 ~ 가운데 펜스 거리, 펜스 높이
- 타구 중계 화면: 맞으면 야구장 전체를 비추는 화면으로 바뀌어 공의 궤적·그림자, 수비수 이동·포구가 보인다 (결과와 화면이 같은 계산에서 나온다)
- 기록 보정: 가상 타자로 한국 프로야구 평균 근처(타율 .270 안팎, BABIP .300, 삼진 18~20%, 홈런 2~3%)가 나오게 맞춘다
- 완료: 물리·수비 판정 테스트, 기록 분포 테스트, 폰 확인
- 상태 (2026-10-06): 구현·테스트 완료, **폰 확인 대기**. 공이 맞은 뒤의 분포(타구 종류별 안타율)는 실제와 맞췄고, 삼진율·정타 비율은 판정 폭(유저가 폰에서 넓힌 값)에 달려 있다

## 내 주루 조작 (2026-10-12 추가, 완료·폰 확인 대기)
- **추가 요소**: 주루 설정 자동(기본)·보조·수동 (더쇼 방식). 자동이면 예전처럼 전부 AI, 도루 없음
- 내 주자만 직접: 타구가 맞으면 오른쪽 아래 베이스 버튼(1루·2루·3루·홈) → 누른 베이스까지 뛴다 (태그업 포함). 1·2루에서 도루(투수가 던지는 순간 탭 — 반응 + 주력 vs 투구 + 포수 송구)
- 안 누르면 보조는 코치 사인(AI 판단)대로, 수동은 한 베이스만. 화면 없는 자동 진행(테스트·빨리 감기)은 예전 그대로
- 도루·도루 실패 기록, 도루 성공 → 주력 성장
- 보류: 다른 주자·상대 팀의 도루, 홈 도루·더블 스틸, 투수·포수 개인차, 투수 동작 그림 (G8)
