# 08. 컨디션 시스템

## 확정 사항
- 피로도, 부상, 폼 세 가지
- **수술·중상 후 능력치 영구 하락 있음**
- **팀 분위기(연승·연패)는 경기력에 영향 없음** — 팬심·관중 수입에만 영향 (13)
- **폼은 5단계로 모든 선수 공개**

## 피로도 (0~100)
**투수**
| 요소 | 규칙 |
|---|---|
| 증가 | 투구수 비례 |
| 연투 가중 | 전날 등판 시 추가, 3연투째는 크게 |
| 회복 | 매일 일정량. 체력 높고 젊을수록 빠름. 컨디셔닝 코치 보너스 (13) |
| 기준 | 100구 선발 → 4일 휴식이면 거의 회복, 불펜 20구 → 하루면 회복 |

**야수**: 출장마다 소폭 증가, 휴식일·결장일 회복. 포수는 2배.

**효과**: 기준 초과 시 능력치 하락(투수 구위·제구, 야수 주루·수비 우선) + **부상 확률 증가**.

## 부상
```
부상 확률 = 기본 확률 × 피로 보정 × 내구도 보정 × 나이 보정 × (팀 닥터 보정)
```
| 단계 | 기간 | 비율 |
|---|---|---|
| 경미 | 1~2주 | ~60% |
| 중간 | 3~6주 | ~28% |
| 중상 | 2~4개월 | ~10% |
| 시즌 아웃·수술 | 시즌 잔여, 투수 팔꿈치 수술은 1년+ | ~2% |

- 부위: 투수 팔꿈치·어깨, 야수 햄스트링·손목·허리 등. 부위별로 복귀 직후 떨어지는 능력치가 다름 (햄스트링 → 주루)
- 복귀: 기간 종료 → 2군 재활 1주 → 1군 등록 가능
- 복귀 후 수 주간 **재발 위험 기간**
- 재활 트레이너가 기간 단축·재발 위험 감소 (13)

### 영구 하락
| 단계 | 영구 하락 |
|---|---|
| 경미·중간 | 없음 |
| 중상 | 50% 확률로 관련 능력치 −1~4 |
| 시즌 아웃·수술 | 관련 능력치 −3~8, 잠재력 상한도 하락 |
- 관련 능력치는 부위로 결정 (팔꿈치 → 구위·구속)
- 나이가 많을수록 하락 폭 증가
- 팀 닥터 등급이 하락 폭을 줄임 (13)

## 폼
- 선수마다 숨겨진 폼 값. 매 경기 랜덤 워크 + 평균 회귀. 변동 폭은 **기복** 수치
- 효과: 능력치 ±5 이내
- 표시: 급상승 / 상승 / 보통 / 하락 / 슬럼프 (모든 선수 공개)
- 슬럼프 탈출: **2군 말소 시 폼이 평균으로 빠르게 회복**, 휴식도 소폭 회복
- AI 구단은 트레이드·FA 평가에서 폼을 거의 무시하고 실제 능력치를 본다 (슬럼프 선수 헐값 매입 꼼수 방지)
