# 07. 주간 루프

## 확정 사항
- 1주 = 6경기 단위 진행, 주간 결산 표시
- **우천 취소 없음.** 24주 고정 일정
- **여러 주 자동 진행** + 유저 선택 멈춤 조건
- 경기별로 **문자 중계 관전** 선택 가능 (포스트시즌, 데뷔전 등)
- 2군 경기는 시뮬레이션하지 않고 **추정 성적** 생성

## 시즌 캘린더
| 시기 | 내용 |
|---|---|
| 3월 말 | 개막 |
| 4~6월 | 정규시즌 |
| 7월 중순 | 올스타 브레이크 (1주 휴식, 피로 대폭 회복, 전반기 결산) |
| 7월 말 | 트레이드 마감 |
| 9월 중순 | 신인 드래프트 주차 (10) |
| 9월 말~10월 | 포스트시즌 |
| 이후 | 스토브리그 (여러 주차로 구성, 11·13) |
- 상대별 16경기 = 3연전 4회 + 2연전 2회. 2연전은 시즌 후반 배치
- 일정표는 고정 리그 데이터에 미리 생성해 포함
- 국제대회가 있는 해(2026 아시안게임 등)는 대회 기간 대표 선수 결장 처리 (12)

## 한 주의 흐름
**주 시작 (결정 단계)**
1. 알림함: 부상, 복귀 가능, 2군 호성적, 감독 요청, 트레이드 제안, 스카우트 리포트 갱신, 구단주 경고
2. 엔트리 관리: 등록·말소, 콜업
3. 선발 로테이션 확인 (이번 주 매치업)
4. 주간 방침: 정상 / 총력전 / 선수 보호
5. 주목 경기 체크 (관전할 경기)
알림이 없으면 바로 "진행" 가능해야 한다.

**주 진행**: 화~일 6경기 순서대로. 관전 체크한 경기에서 멈추고 문자 중계.

**주중 개입 (돌발 이벤트)** 〔구현 2026-09-27, 상세는 docs/16 §4-1〕: 주 시작과 매일 경기 뒤에 유저 구단에 생긴 일
(주전 부상, 연패, 감독 거취, 트레이드 제안, SNS 논란, 기자 질문, 피로 누적, 2군 폭격, 출장 요구, 라이벌 주간)을 살펴
걸리면 그 경기 뒤에서 진행을 멈춘다. 답한 효과(엔트리·폼·피로·팬심·구단주 신뢰·이번 주 방침)는 **다음 경기부터** 반영된다.
판정 난수는 주차·요일 시드로 따로 만들어, 같은 답이면 같은 시즌이 나온다.
- 〔2026-10-04〕 **선수가 보내는 메시지**(이적 요청·연봉 불만·멘토링 자청, 출장 요구도 선수 발신으로)와 **선수 만족도의 주간 갱신**이 붙었다 (docs/13 "선수 성향과 만족도").
  만족도는 주 결산에서 유저 구단만 갱신하고, 매일 폼이 돌아가는 중심을 옮긴다. 선수 메시지 판정 난수는 예전 이벤트 난수와 따로 만들어 기존 이벤트 순서를 건드리지 않는다
- 트레이드 제안은 들어온 주 안에 답해야 한다. 지나면 철회된다(`incidents.tradeOffer.validWeeks`)
- **기회형 이벤트** 〔2026-10-03〕: 위기형 선택 이벤트가 없는 주의 주 시작에 트레이드 문의·방출 매물·유망주 1군 시험·연장 계약 협상 중 하나가 올 수 있다
  (docs/16 §4-1 표). 같은 주차 시드로 판정해 재현성은 그대로다

**결과 공개** 〔2026-10-02, 재미 개선 1번, 화면은 docs/16 §4-1·§12〕: 한 주가 끝나면 주 결산 전에 우리 경기 결과를 한 장씩 공개한다.
경기를 다시 돌리지 않고 주간 진행이 남긴 박스스코어·이벤트 스트림을 보여 줄 뿐이다(불변 원칙 5). 결승 장면 = 이긴 팀이 마지막으로 앞서 나간 득점 장면.
이번 주 영웅 = 루타+타점+볼넷/2(타자), 이닝+탈삼진×0.3+승×2+세이브×1.5−자책×2(투수)가 가장 높은 우리 선수 (표시용 순위, 임시 결정).

**주 결산**
| 영역 | 내용 |
|---|---|
| 성적 | 주간 전적, 순위·게임 차 변동 |
| 선수 | 주간 MVP, 부진 선수, 기록 달성 |
| 사건 | 부상, 폼 변화 |
| 경고 | 피로 누적(연투 등), 연패·팬심 하락 |
| 하이라이트 | 주요 장면 문자 중계 3~5줄 |
| 2군 리포트 | 2군 성적 상위 |
| 다음 주 예고 | 상대와 예상 선발 매치업 |
결과 나열로 끝내지 말고 다음 주 결정거리를 만든다.

## 엔트리 규칙
- 1군 등록 인원 제한 (임시 28, 확인 필요)
- 말소 후 재등록 제한: 말소한 다음 주 불가, 그다음 주부터 가능
- 부상자 명단은 엔트리 자리를 차지하지 않음
- 부상 복귀 선수는 2군 재활 1주 후 등록 가능
- **단장 직접 등록·말소** 〔2026-09-27〕: 로스터 화면에서 언제든(주중 포함). 1군이 꽉 차면 같은 쪽(투수/야수) 선수와 맞바꾼다.
  **포지션 제한 없음**(2026-10-01 유저 요청) — 남는 규칙은 1군 28명, 재등록 제한, 부상·군 복무뿐이다. 1군이 꽉 찼으면
  맞바꾸기 창에서 내릴 선수를 같이 고른다. 주 시작 자동 관리는 유저 구단에 부상자 말소·부상 복귀(자리가 있을 때)·빈자리 채우기만 한다
- **유저 구단 베스트 엔트리 자동 유지** 〔2026-10-03 유저 요청 "수동 조작 안 하더라도 로스터를 항상 베스트로"〕: 주 시작마다
  ① 부상 회복한 1군 선수는 1군이 꽉 차 있어도 가장 약한 선수와 바꿔 복귀 ② 2군에 1군 최약체(같은 투수/야수)보다 종합이
  `roster.userAutoBestMargin`(2.0) 넘게 높은 선수가 있으면 맞바꾼다. 포지션 최소(포수 2명 등)를 깨는 맞바꿈은 하지 않는다.
  **단장이 직접 올린 선수**(로스터 화면 등록·맞바꾸기, 돌발 이벤트에서 단장이 고른 콜업)는 올린 뒤 `roster.userPickProtectWeeks`(3)주
  동안 자동으로 내리지 않는다(2026-10-03 유저 결정). 비서 처리 콜업은 보호하지 않는다 — 다음 주 시작에 정리된다
- **AI 구단 1군 구성 가이드** 〔2026-10-01 · 처음엔 유저에게도 거는 규칙이었으나 같은 날 유저 요청으로 **AI 전용**이 됐다 · 임시 결정 `roster.positionLimits`〕

  | 칸 | 범위 | 칸 | 범위 |
  |---|---|---|---|
  | 투수 전체 | 12~14 | 야수 전체 | 14~16 |
  | 선발(SP) | 5~7 | 불펜(RP·마무리) | 6~9 |
  | 포수 | 2~3 | 1루·2루·3루·유격 | 각 1~3 |
  | 좌익·중견·우익 | 각 1~3 | 지명타자 | 0~2 |

  - 주 포지션 기준. 최대는 등록 인원 전부로, 최소는 **뛸 수 있는(부상 아닌)** 인원으로 센다
  - 이미 범위를 벗어난 상태에서는 **더 나빠지는 이동만** 막는다 (고치는 이동은 허용)
  - 자동 관리 순서: 부상자 말소 → 부상 복귀(꽉 찼으면 같은 포지션 약한 선수와 교체) → 최대 초과 정리 → 최소 미달 보강
    (자리가 없으면 다른 포지션의 가장 약한 선수와 교체) → 빈자리 채우기 → 28명 초과 정리
  - 트레이드로 선수가 오간 구단은 그 자리에서 다시 맞춘다. 개막 1군도 첫 화면 전에 맞춘다
  - 유저 구단은 시즌 시작 때 물려받은 1군만 한 번 정리하고, 시즌 중에는 건드리지 않는다
  - 유저 1군에 뛸 수 있는 포수가 없으면 브리핑에 알림만 뜬다 (막지는 않는다)

## 2군 추정 성적
능력치 기반 기대 성적 + 랜덤 편차로 주간 기록 생성. 연산 최소화. 출장 여부는 2군 성장 배율(09)에 반영.

## 자동 진행
- 목표 지점: N주 뒤 / 올스타 / 트레이드 마감 / 정규시즌 종료
- 멈춤 조건(체크): 주전 부상, N연패, 트레이드 제안, 감독 요청, 기록 달성 임박, 우리 선수 데뷔전, 5강 진입·탈락, 구단주 경고
- **드래프트 주차에는 항상 멈춤**
- 〔구현 2026-09-27〕 지금 멈추는 것: 드래프트 주차 + **급한 돌발 이벤트**(주전 부상·부상 투혼·연패·감독 거취·트레이드 제안).
  나머지 돌발 이벤트는 비서가 추천대로 처리하고 "비서 처리"로 기록한다. 멈춤 조건을 유저가 고르는 화면은 아직 없다
- 〔개정 2026-10-03, 유저 요청〕 자동 진행(올스타까지·시즌 끝까지)은 **드래프트 주차 + 계약이 걸린 돌발 이벤트**
  (트레이드 제안·트레이드 문의·방출 매물 영입·연장 계약, `IncidentKind.contract`)에만 멈춘다.
  주전 부상 대체·부상 투혼·콜업·연패·감독 거취 등 엔트리·현장 일은 비서가 추천대로 처리한다 — 빠르게 넘기기 위해서다.
  한 주씩 진행할 때는 그대로 급한 일이 창으로 뜬다
- 자동 진행 중 주간 방침 유지, 부상 대체는 규칙표의 대체 규칙으로 자동 처리

## 주목 경기 자동 추천
- 우리 선수 1군 데뷔전, 부상 복귀전
- 기록 달성 임박 (100홈런, 100승 등)
- 순위 경쟁 팀과의 맞대결
- 포스트시즌 전 경기

## 문자 중계
- 속도: 1타석씩 / 1이닝씩 / 빨리 감기 / 결과로 건너뛰기
- 템플릿 기반 문장, 표현 변형 여러 개
- **한국어 조사 처리 필수**: 이름 마지막 글자 받침 여부 = `(code − 0xAC00) % 28 != 0`. 이/가, 을/를, 은/는, 과/와, 으로/로(ㄹ받침 예외) 처리. 외국인 등록명도 한글 표기 기준
- 결산 하이라이트용 주요 장면은 관전 여부와 상관없이 이벤트 스트림에서 추출
