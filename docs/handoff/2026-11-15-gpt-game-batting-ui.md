# 경기 타석 화면 UI 시안 v1

- 원본: `docs/mockups/game_batting_ui_v1.png` (1844×853px).
- 프롬프트: `docs/mockups/game_batting_ui_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 캐릭터 기준: `docs/refs/sprites/main_player_tpose_v2.png`. 복장·머리·비율을 이어 가고 타석에서는 모자를 남색 타격 헬멧으로 바꿨다.
- 그림체·색감 기준: `docs/mockups/training_ui_v1.png`.
- 화면 구성 기준: `docs/02-design.md` §5-1의 타자 뒤 시점과 중계형 HUD.
- 칸 배치: 단일 화면 1칸. 왼쪽 전경 오른손 타자, 중앙 투수·날아오는 공·3×3 존·조준점, 왼쪽 위 점수/이닝/주자/B·S·O, 오른쪽 위 구종·구속/일시정지, 왼쪽 스윙 종류 4개, 오른쪽 아래 스윙, 왼쪽 아래 타자 자막.
- 경기 예시: 5회 초 서림고 2 대 동인고 1, 1루 주자·1볼 1스트라이크 1아웃. 점수·투구 수·오늘 기록·시즌 타율은 UI 검토용이며 실제 기록을 변경하지 않았다. “내 선수”는 입력 이름의 자리 표시다.
- 투구 중 상태이므로 구종·구속을 ---로 숨겼다. 투구 전 선택 타이머/던져 버튼, 결과·홈런·주루·타구 중계 화면은 이번 시안에 없다.
- 개편상 수비 조작 UI는 넣지 않았다. 실제 카메라 원근·존 크기·공 크기·주자/수비수 위치는 게임 좌표와 폰 조작 확인을 거쳐 연결해야 한다. 시안의 원근을 물리 좌표로 그대로 사용하지 않는다.
- 배경·인물·HUD가 합쳐진 검토용 이미지다. 게임 적용에는 UI 없는 경기장 배경, 메인 캐릭터 타석 동작 시트, 상대 선수 및 UI 분리 제작이 필요하다.
- 게임 적용은 Claude 담당. 코드·설정·기존 문서 수정 및 테스트 실행 없음. 이번 추가 시안은 아직 커밋하지 않았다.
