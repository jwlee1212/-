# 훈련 하위 UI — 개인 레슨·관리 시안 v1

- 도구: 내장 GPT 이미지 생성.
- 기준 그림: docs/mockups/training_ui_v1.png. 동일한 캐릭터·운동장·헤더·탭과 펜선·평면 채색을 유지했다.
- 각 이미지 단일 UI 화면 1칸.

- 개인 레슨: `docs/mockups/training_lesson_v1.png` (1844×853px), 프롬프트는 같은 이름의 `_prompt.md`.
- 관리: `docs/mockups/training_care_v1.png` (1843×853px), 프롬프트는 같은 이름의 `_prompt.md`.

## 내용

- 개인 레슨: 현재 컨택 훈련을 보충하는 레슨, 비용 100,000원, 이용 후 잔액. 실제 성장량을 고정 정수로 약속하지 않았다.
- 관리: 스포츠 마사지 60,000원/컨디션 +15, 보양식 30,000원/컨디션 +8·폼 회복. 마사지 선택 및 예상 컨디션 68→83 표시.
- 서비스 이름·비용·효과는 config/balance.json career.shop.services 및 기존 use_service 구현 참조. 밸런스를 변경하지 않았다.
- 보유금액 150,000원, 컨디션 68, 컨택 D·42는 시안용 예시.
- 관리 시안은 부상 없는 상태라 마사지의 부상 회복 부가 효과는 생략했다. 부상 상태에는 해당 정보를 추가해야 한다.
- 기존 주간 이용 제한과 구간 진행 방식 간의 규칙은 이번 이미지로 확정하지 않았다. 사용 불가·금액 부족·이용 후 결과 화면은 별도 시안이 없다.
- 완성 화면 합성 이미지다. 게임 적용에는 아트와 인터랙션 UI 분리가 필요하다. 적용은 Claude 담당.
- 코드·설정·기존 문서 수정 및 테스트 실행 없음.
