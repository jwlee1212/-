# 선수 정보 UI 시안 v1

- 이미지: `docs/mockups/player_info_v1.png` (1844×853px).
- 프롬프트: `docs/mockups/player_info_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 캐릭터 기준: `docs/refs/sprites/main_player_tpose_v2.png`. 같은 외형·복장·펜선·평면 채색을 유지하고 편하게 선 포즈로 변경했다.
- 구조 기준: `docs/02-design.md` §5-3 선수 정보.
- 칸 배치: 단일 UI 화면 1칸. 위 골목 복귀·제목·학년, 그 아래 능력치/장비/성장 기록/수상·기념 탭. 왼쪽 방 배경과 선수 전신, 오른쪽 컨택·파워·선구안·주력 및 최근 성장·성장 단계.
- 능력치 탭만 그렸다. 장비·성장 기록·수상 탭 내부 화면은 아직 없다.
- 수비 능력치는 개편 결정에 따라 제외했다. 수치·등급·최근 성장은 시각 검토용 예시이며 실제 밸런스 변경이 아니다. 실사용 시 등급 기준과 최대치에 맞춰 표시해야 한다.
- “내 선수”는 사용자 입력 이름의 자리 표시다. 실제 이름을 고정하지 않는다.
- 완성 화면 합성 이미지. 게임 적용에는 아트와 UI를 분리해야 한다. 현재 코드의 컨디션·출전 상태·스카우트 등 추가 정보의 위치는 후속 상세 설계에서 정리 필요.
- 게임 적용은 Claude 담당. 게임 코드·설정·기존 문서 수정 및 테스트 실행 없음.
