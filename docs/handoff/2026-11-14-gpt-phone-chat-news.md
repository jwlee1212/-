## 채팅방

- 소율의 기존 일러스트를 참조한 왼쪽 인물과 프로필을 유지하고, 수신 말풍선·답장 선택지 2개를 배치했다.
- 문구 출처: config/content.json messages의 m_y1_soyul_folder. “내 선수”는 사용자 입력 이름의 자리 표시다. 선택 전 상태라 보낸 답장과 이후 응답은 아직 없다.
- 기존 주간 답장 기한은 구간 진행 전환과의 정합성이 확정되지 않아 표시하지 않았다. 실제 기한·만료 상태는 적용 때 연결해야 한다.

## 뉴스

- 목록과 본문은 가독성을 위해 인물 영역을 접고 중앙 가로형 읽기 패널로 넓혔다. 기존 세로 폰 구현의 레이아웃 변경 제안이며 이미 적용한 것이 아니다.
- 목록: 가상 매체명·기사 제목·시간·신규 N·조회와 댓글 수. 첫 행은 선택 강조 예시.
- 상세: 매체·기자·제목·본문·댓글·스크롤과 목록 복귀. 댓글 3개 중 첫 댓글만 보이며 나머지는 스크롤 영역.
- 기존 news 문장 틀 homer tiers 0/1과 댓글에서 문구를 가져와 김도윤/서림고/동인고/성적 등 예시 값을 대입했다. 기자 문정우와 매체 베이스볼 투모로우·다이아몬드 게시판은 기존 가상 설정이다.
- 이름·계절·월·조회·댓글 수·성적은 UI 검토용 데이터이며 실제 커리어 기록이나 서사를 변경하지 않았다.
- 기사 상세 생성본의 홈런 문구 일부가 프롬프트와 미세하게 달라졌다. 실제 UI 텍스트는 원본 콘텐츠 템플릿과 한국어 조사 처리 결과를 사용해야 한다.

## 인계

- 세 이미지 모두 글자·버튼·인물·배경이 합쳐진 검토용 시안이다. 실제 적용은 기존 원본 인물 일러스트와 별도 UI 컴포넌트를 사용한다.
- 게임 적용은 Claude 담당. 코드·설정·기존 문서 변경 및 테스트 실행 없음.
