# 경기 결과 UI 시안 v1

- 원본: `docs/mockups/game_result_ui_v1.png` (1836×857px).
- 프롬프트: `docs/mockups/game_result_ui_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 기준: `docs/mockups/game_batting_ui_v1.png`의 경기장·그림체·HUD 색감, `docs/refs/sprites/main_player_tpose_v2.png`의 메인 캐릭터 외형.
- 칸 배치: 단일 UI 화면 1칸. 왼쪽 경기장·선수 전신, 오른쪽 승패·최종 점수·내 기록·4개 능력치의 전후 수치와 증감, 아래 박스스코어 및 골목 복귀.
- 경기 예시: 서림고 5:3 동인고, 4타수 2안타 1홈런 2타점. 컨택 42→43, 파워 38→39, 선구안 51·주력 56 유지. 수치·성장량은 시각 검토용 임시 데이터이며 새 밸런스 규칙이 아니다.
- 경기 뒤 대기 이벤트가 없는 경우의 복귀 버튼이다. 이벤트가 있다면 기존 대화/이야기 흐름을 연결해야 한다. 구간 마지막 경기는 구간 결산으로 연결하는 별도 상태가 필요하다.
- 기존 결과 코드의 수비 성과는 개편 결정에 따라 제외했다. 기존 코드의 수입 카드와 감독 코멘트는 이번 핵심 구성 시안에서 생략했으며 시스템 삭제를 결정한 것은 아니다.
- 박스스코어 내부, 패배·무승부, 성장 없음·하락, 대타·미출전 상태는 별도 시안이 없다.
- 이미지에는 아트·글자·버튼이 합쳐져 있다. 실제 적용에는 배경/인물/UI 분리가 필요하다.
- 게임 적용은 Claude 담당. 코드·설정·기존 문서 수정 및 테스트 실행 없음. 이번 시안은 아직 커밋하지 않았다.
