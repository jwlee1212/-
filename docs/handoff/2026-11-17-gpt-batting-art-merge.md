# 타자·투수·타석 배경 한정 적용

- 사용자 요청: 타자·투수·배경만 커밋해 `claude/merge-codex-1117`에 합친다.
- 타자: `batter_ink_swing_pair01~06_v2.png`의 12동작. 준비 1~3번 머리는 뒤쪽 시점으로 수정. 사용자 선택 배율 **1.65**. 존·배트 접점 고정, 하체 잘림 허용.
- 투수: `pitcher_ink_throw_v2.png` 16동작. 정면 시선·무표정. 게임 15상태에 매핑, 공 놓는 원본은 9번(0부터), 손 좌표 `(74,68)`.
- 배경: `docs/mockups/stadium_ink_batting_v1.png`, 1846×852. 원본 비율을 보존하고 투수판을 화면 높이 56%에 맞춘다. 빈 전광판에 기존 점수를 그린다.
- 재생성: `scripts/pack_batting_ink_art.py` → `tidy_sheet.py`의 타자·투수 정의만 처리. Pillow·NumPy 필요. 메타는 자동 생성하며 손으로 수정하지 않는다.
- 커밋 범위: 관련 원본·프롬프트·출처, 게임용 시트·메타·배경, 표시·패킹 코드, 타자 배율 설정. 커리어 UI·골목·휴대폰·전역 색상·수비수·주자 변경은 제외한다.
- 앞선 확인: 실제 Godot 준비·컨택 캡처와 웹 빌드 실행 확인. 최종 투구 관련 검사 11건 통과 기록이 있다. 전체 테스트 통과를 주장하지 않는다. 저장 관련 재검증은 AGENTS.md의 테스트 금지로 자동 승인에서 거절되어 이번에도 재실행하지 않는다.
- 통합 시 구버전 배경용 마운드/원근 상수와 충돌하면 새 배경에 맞는 56% 마운드 및 원래 홈플레이트 원근을 함께 적용한다.

## 통합 확인

`claude/merge-codex-1117`의 구버전 노을 배경 코드 충돌을 새 잉크 배경으로 해결했다. 마운드 56%와 홈플레이트 원근을 맞췄으며, 기존 통합 브랜치의 UI·휴대폰 코드는 보존했다. Godot 가져오기에서 스크립트 구문 오류가 없었고, shots_batter 장면의 실제 준비·컨택 캡처에서 1.65배 타자·투수 v2·새 배경을 확인했다. 이번 병합에서는 테스트 러너를 실행하지 않았다.
