# 폰 메시지 목록 UI 시안 v1

- 원본: `docs/mockups/phone_messages_v1.png` (1843×853px).
- 프롬프트: `docs/mockups/phone_messages_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 사용자 요청: 기존 인물 일러스트를 메시지 프로필 사진으로 사용.
- 인물 기준: `docs/refs/portraits/originals/manager.png`(소율), `neighbor.png`(하린), `buddy.png`(박준수), `mom.png`(엄마).
- UI·배경 기준: `docs/mockups/career_street_home_v1.png`.
- 칸 배치: 단일 가로 게임 화면 1칸. 어둡게 처리한 골목 위 왼쪽 소율 반신·이름표, 오른쪽 폰 메시지 목록. 소율/하린/박준수/엄마 얼굴을 원형 프로필로 활용하고 아래 메시지/뉴스/연락처 탭 배치.
- 기존 일러스트를 이미지 생성 참조로 제공한 합성 시안이다. 원본 픽셀을 그대로 잘라 붙인 납품용 프로필 에셋은 아니다. 게임 적용 단계에서는 위 원본 일러스트를 직접 원형 마스킹해 얼굴을 정확히 유지하는 것을 권장한다.
- 문구는 config/content.json의 기존 메시지 m_y1_soyul_folder / m_y1_harin_club / m_y1_junsu_winter / m_mom_tired에서 가져왔다. 시간·읽지 않은 수와 인물 동시 노출은 시각 검토용 예시라 실제 발생 조건·시점과 다를 수 있다.
- 새 서사·대사를 만들거나 콘텐츠를 변경하지 않았다. 채팅방 상세/답장 선택지/뉴스/연락처 내부는 이번 이미지에 포함하지 않았다.
- 소율의 선택 강조는 왼쪽 인물 표시를 설명하기 위한 시안 상태다. 기존 목록에서 대화방으로 들어가는 실제 동작은 Claude가 연결한다.
- 완성 화면 이미지라 인물·배경·폰·글자가 합쳐져 있다. 실제 게임 적용은 Claude 담당.
- 게임 코드·설정·기존 문서 수정 및 테스트 실행 없음.
