# 메인 캐릭터 골목 걷기 시트 v1

- 이미지: `docs/refs/sprites/main_player_walk_right_v1.png` (1536×1024px, RGBA).
- 프롬프트: `docs/refs/sprites/main_player_walk_right_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성. 투명 배경 요청.
- 기준 그림: `docs/refs/sprites/main_player_tpose_v2.png`. 원래 캐릭터 기준은 `docs/mockups/career_name_screen_v2.png`.
- 동작: 오른쪽을 향한 옆모습 제자리 걷기. 배트·가방·글러브 없음.
- 배치: 4열×2행, 총 8칸. 칸 크기는 384×512px. 위 행 왼쪽부터 1~4, 아래 행 왼쪽부터 5~8. 1→2→3→4→5→6→7→8→1 반복.
- 의도한 위상: 왼발 접지→체중 이동→통과→올라감→오른발 접지→체중 이동→통과→올라감.
- 적용 시작값 제안: 초당 8~10프레임. 실제 이동 속도와 발 디딤은 게임에서 조율 필요. 프레임별 발 위치·몸통 등록은 Claude가 적용 전에 확인해야 한다.
- 왼쪽 걷기는 무늬·번호 없는 복장이므로 적용 단계에서 좌우 반전을 활용할 수 있다. 별도 왼쪽 시트는 만들지 않았다.
- 원본 시트 그대로 보관했다. 칸 정리·변환 스크립트·게임 적용·테스트를 실행하지 않았다. 실제 반복 재생 검증은 아직 하지 않았다.
- 칸 정리·발 기준 메타·게임 연결은 Claude 담당.
