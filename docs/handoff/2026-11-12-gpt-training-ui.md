# 훈련 UI 시안 v1

- 원본: `docs/mockups/training_ui_v1.png` (1844×853px).
- 프롬프트: `docs/mockups/training_ui_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 그림체·UI 기준: `docs/mockups/player_info_v1.png`. 동일한 메인 캐릭터, 펜선·평면 채색·크림/남색/주황색 구성을 이어 간다.
- 기능 기준: `docs/00-concept.md` §0-1과 `docs/02-design.md` §5-3. 주간 스케줄 대신 구간 시작에 훈련 방향 하나 선택.
- 칸 배치: 단일 화면 1칸. 상단 골목 복귀·훈련 제목·학년, 구간 훈련/개인 레슨/관리 탭. 왼쪽 운동장과 메인 캐릭터, 오른쪽 컨택·파워·선구안·주루·휴식 선택 목록 및 확정 버튼.
- 컨택을 선택했지만 아직 확정하지 않은 상태의 시안이다. 개인 레슨·관리·확정 후·결과 화면은 이번 이미지에 포함하지 않았다.
- 확정 후 재선택 가능 시점·훈련 성장량·비용 등 미확정 규칙은 새로 정하지 않았다. 선택 항목 설명은 UI 기능 설명용이며 서사·대사 변경이 아니다.
- 감독 목표를 보고 선택하는 흐름은 개편 문서에 있다. 이번 화면에서는 목표 영역을 별도로 그리지 않았으므로 실제 구현 시 골목 목표와의 연결 또는 상단 요약 표시 검토 필요.
- 검토용 합성 화면 이미지. 실제 게임 적용에는 캐릭터·배경·UI 분리 제작 필요. 적용은 Claude 담당.
- 게임 코드·설정·기존 문서 수정 및 테스트 실행 없음.
