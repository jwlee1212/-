# 고교 골목길 연속 배경 v1

- 원본: `docs/mockups/street_hs_long_v1.png` (2172×724px).
- 프롬프트: `docs/mockups/street_hs_long_v1_prompt.md`.
- 도구: 내장 GPT 이미지 생성.
- 기준 그림: `docs/mockups/career_street_home_v1.png`의 골목 건물·펜선·색감.
- 사용자 요청: 골목길 시안을 긴 하나의 이미지로 제작.
- 칸 배치: 분할 칸 없는 단일 연속 가로 배경 1장. 왼쪽부터 102동 아파트, 은하식당, 용품점, 야구부 컨테이너, 서림고 정문·운동장, 본관, 동네 야구장.
- UI·캐릭터·부유하는 기능 이름표를 제외했다. 건물에 붙은 물리적 간판은 유지했다. 앞쪽 보도가 연속되어 있다.
- 실제 출력 비율은 3.00:1이다. 프롬프트의 목표 7596×1170(약 6.5:1, 화면 세 장)과는 다르며 현재 원본은 그 제작 규격을 충족하지 않는다. 구성을 확인하는 파노라마 시안으로 사용하고 실제 세 화면 길이 제작에는 후속 확장·고해상도 작업이 필요하다. 이번 작업에서는 강제 가로 늘리기·업스케일·분할 합성을 하지 않았다.
- 원본은 단일 합성 레이어다. 건물별 레이어 분리·누를 영역·문 입장 효과는 별도 적용 작업이다.
- 아파트·본관 입구에 계단이 있어 문 기준과 보행 기준의 연결은 적용 때 확인 필요. 모든 입구 문턱을 완전히 같은 수평선으로 맞춘 것은 아니다.
- 게임 적용은 Claude 담당. 게임 코드·설정·기존 문서 수정 및 테스트 실행 없음. 커밋은 아직 하지 않았다.
