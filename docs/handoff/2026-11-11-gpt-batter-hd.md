사용자 요청: 실제 인게임에서 타자 화질이 뭉개지므로 해상도를 높인다.

기존 `batter_video_swing_v1.png`(1448×1086, 4×3, 칸당 362×362)를 기준으로 내장 GPT 이미지 생성 도구로 두 프레임씩 재생성했다. 동일 카메라·포즈·캐릭터·화풍을 유지하도록 요청했다. 단순 확대가 아니라 다시 그린 결과라 원본과 세부 윤곽·비율·발 위치에 차이가 있을 수 있다.

## 확인과 적용

- 여섯 파일 모두 실제 픽셀 크기·RGBA·배경 알파 0을 확인. 도구 미리보기의 검은 배경과 빛은 RGB에 보이지만 샘플링한 배경 위치는 알파 0이다. 가장자리에 미세 알파 잔여가 있을 수 있으므로 알파>0만으로 바운딩박스를 잡지 말 것.
- 기존 칸 대비 높이 약 2.83배, 너비 약 2.12배. 캐릭터도 더 크게 재생성하여 확대에 필요한 원본 픽셀을 확보했다.
- 투구를 향한 시선·배트의 곧은 형태·후반 뒷모습을 육안 확인. 서로 다른 요청으로 생성했으므로 장 사이 캐릭터 크기·발 기준점을 맞추고 애니메이션 흔들림을 확인해야 한다.
- 컨택 위치는 고해상도 4번 파일 왼쪽 칸에서 재측정. 기존 컨택 좌표를 그대로 쓰지 말 것.
- 원본을 작게 줄였다가 확대하지 말고, 게임 적용 과정의 리사이즈·텍스처 최대 크기·필터 설정도 확인할 것. 실제 뭉개짐의 원인이 원본 크기만이라고 확정한 것은 아니다.
- **게임 적용 전.** Codex는 새 이미지·프롬프트·이 메모·라이선스 끝줄만 추가했다. 게임 코드·설정·기존 문서를 수정하지 않았으며 테스트·칸 정리 스크립트는 실행하지 않았다.
