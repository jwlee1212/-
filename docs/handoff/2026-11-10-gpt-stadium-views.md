# 경기장 배경 두 시점

- `docs/refs/sprites/batting_stadium_2d_v2.png` (1846×852). 포수 뒤 고정 시점. 기존 `hud-4-speed.png` 캡처의 구도를 참조했다. 홈플레이트, 투수판과 전광판 내부를 기준으로 게임 좌표에 정렬한다. 투수 마운드는 한 곳만 그렸다.
- `docs/refs/sprites/broadcast_stadium_2d_v1.png` (1844×853). 중계 화면의 내야 방향을 따르고, 카메라가 이동할 수 있도록 외야 담장까지 담았다. 그림의 다이아몬드가 세로로 눌려 있으므로 기존 중계 카메라로 투영할 때 홈·1루·2루·3루와 마운드 기준점을 확인한다.
- 두 PNG는 배경 원본이다. 선수·공·전광판 숫자·HUD는 게임에서 그린다. 프롬프트는 같은 이름의 `_prompt.md` 파일에 있다.

## 게임 적용 확인

- `codex/stadium-views`에서 기존 `codex/field-art`의 수비수·주자 연결을 가져오고 타석 배경과 정면 대기 수비수를 교체했다.
- 탑뷰는 기존 카메라의 역투영 좌표를 사용한다. 홈·세 베이스·마운드에 원본의 위치를 맞추고 이미지 밖은 기존 경기장 그림으로 채운다.
- 주요 화면 확인은 `shots_hud.tscn`과 `shots_steal.tscn`으로 했다.
