## 화면 구성과 적용 메모

- 장비: 네 종류 분류·보유 배트 선택·장착·보정 합계. 항목과 보정값은 UI 설명용 임시 예시이며 기존 시스템 변경이 아니다.
- 성장 기록: 구간 시작/현재/변화 비교와 최근 성장 내역. 전체 필터의 별도 시안은 없다.
- 수상·기념: 초기 커리어의 빈 상태. 수상 기록·기념 순간 세부 데이터와 획득 후 상태는 별도 작업이다.
- 능력치 상세 4종: 현재 등급·수치·구간 성장·성장 내역·성장 단계와 성장 여력 영역. 잠재력 상한 수치는 노출하지 않는다.
- 성장 여력의 코치 평가 문구는 자리 표시다. 실제 구현은 기존 Growth.room_text 등과 기획에 맞게 연결해야 한다.
- 각 시안의 수치·등급·장비·성장 내역은 예시다. 실제 능력치 최대치·등급 기준 및 경기 결과 성장 정의와 맞춰야 한다.
- 파워 상세는 이번 구간 변화가 없지만 생성본 막대 끝에 주황색이 들어갔다. 실제 구현에서는 변화 없음 상태의 주황 강조를 빼야 한다.
- 완성 화면 이미지라 인물·배경·텍스트·버튼이 합쳐져 있다. 실제 적용 때 분리 제작 필요.
- 게임 코드·설정·기존 문서 수정 및 테스트 실행 없음.
