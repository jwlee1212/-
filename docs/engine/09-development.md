# 09. 성장과 노화

## 확정 사항
- **시즌 중 월 1회 소폭 성장 + 시즌 후 본 성장**
- **은퇴 선수 → 코치 → 감독 후보** 경로
- 훈련 방향은 유저가 선수별로 지정하지 않고 **코치 성향**으로 결정

## 성장 시점
| 시점 | 대상 | 내용 |
|---|---|---|
| 시즌 중 매월 (6회) | 25세 이하 | 연간 성장량의 약 40%를 나눠 반영 |
| 시즌 후 | 전원 | 나머지 60% 성장 + 노화·하락 + 각성·급노쇠 판정 + 은퇴 |
하락은 시즌 후에만 적용.

## 나이 곡선
| 성장 타입 | 성장기 | 전성기 | 하락 시작 |
|---|---|---|---|
| 조기 완성형 | ~23 | 24~28 | 29~ |
| 일반형 | ~26 | 27~31 | 32~ |
| 대기만성형 | ~28 | 29~33 | 34~ |
- 성장기: 매년 (잠재력 − 현재치)의 약 20~35%만큼 상승
- 전성기: 작은 랜덤 변동
- 하락기: 매년 하락, 나이가 많을수록 폭 증가

## 능력치별 곡선 차이
| 능력치 | 특징 |
|---|---|
| 주루, 수비 | 가장 먼저 하락 (20대 후반~) |
| 파워 | 늦게 완성, 30대 초반까지 유지 |
| 컨택 | 중간 |
| 선구안 | 30대에도 유지·상승 가능 |
| 구위, 구속 | 30대 초반부터 하락 |
| 제구 | 30대 중반까지 상승 가능 |
→ 유격수의 1루·지명타자 전향, 파이어볼러의 기교파 전향 같은 커리어가 자연 발생.

## 출장 경험 보정 (25세 이하)
| 상황 | 배율 |
|---|---|
| 1군 주전 | ×1.2 |
| 2군 주전 | ×1.0 |
| 1군 벤치 | ×0.7 |
| 부상 결장 | ×0.5 |
| 상무 복무 | ×1.0 |
| 현역·사회복무 | ×0 + 감각 하락 (12) |
양타 선수는 소폭 감소 배율.

## 코칭스태프 효과
| 코치 | 성향 (하나) |
|---|---|
| 타격코치 | 장타 / 컨택 / 출루 중심 |
| 투수코치 | 구위 / 제구 / 땅볼 유도 중심 |
| 수비·주루코치 | 수비 / 주루 중심 |
| 2군 감독 | 성향 없음, 25세 이하 전체 성장 보너스 |
- **재분배 방식**: 집중 능력치 ×1.3, 같은 그룹의 나머지 ×0.9 (총 성장량을 부풀리지 않음). 배율 크기는 코치 등급에 비례
- 감독 전문 분야: 해당 그룹 성장 +10%
- 코치는 등급·연봉·계약을 가진 캐릭터, 스토브리그 스태프 시장에서 고용 (13)

## 각성과 급노쇠 (드묾, 시즌당 리그 몇 명)
- 각성: 잠재력 +5~10. 25세 이하·대기만성형 위주
- 급노쇠: 33세+ 한 해 큰 폭 하락

## 은퇴
- 시즌 후 나이·능력치·계약 여부로 확률 판정 (계약 없는 30대 후반 하락 선수 위주)
- 프랜차이즈 스타 은퇴 시 은퇴식 이벤트, 팬심 보너스
- 은퇴 선수 일부는 **코치 후보 풀** 진입. 코치 성향은 선수 시절 유형에서 상속(거포 → 장타 중심). 코치 경력 수년 후 **감독 후보**

## 장기 밸런스 테스트 (M5)
30시즌 자동 진행 후
- 주전 평균 능력치 60±3 유지
- 90+ 선수 수 안정
- 드래프트 유입과 은퇴 유출의 균형
