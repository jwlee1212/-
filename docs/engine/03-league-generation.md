# 03. 초기 리그 생성

## 확정 사항
- **고정 리그**: 모든 유저가 같은 리그로 시작. 반복성은 구단 선택으로 확보
- **2군까지 한 번에 생성** (팀당 약 58명)
- 생성기는 **개발 도구**(`tools`)다. 결과를 `data/league_2026.json`으로 저장해 게임에 포함하고, 게임은 이 파일을 읽어 시작한다
- 저장된 데이터는 손으로 수정 가능 (예: 대전 1순위 후보 "고교 최대어 파이어볼러", 나이츠 노장 에이스의 마지막 시즌)
- **첫해 드래프트 풀과 외국인 선수 풀도 고정**
- 2시즌째부터 성장·부상·드래프트 풀은 세이브별 시드로 달라진다 ("시작은 같고, 흘러가는 방향은 매번 다름")
- 감독(현직 10 + 무직 후보 6~8), 코치, 메디컬 스태프, AI 단장, 경기 일정표도 고정 데이터에 포함

## 생성 순서 (중요)
능력치를 먼저 뽑고 나이를 붙이지 않는다. 거꾸로 만든다.
1. 팀 템플릿이 자리별 요구(나이대, 역할, 목표 능력치)를 정한다
2. 선수의 **잠재력**을 먼저 뽑는다
3. 나이와 성장 타입으로 **현재 능력치를 역산**한다 (09의 곡선 사용)
4. 계약·연봉·군 복무를 나이와 능력치로 채운다
5. 팀 전력을 계산해 목표와 비교, **±2 이상 차이 나면 그 팀만 재생성**

## 선수단 규모
| 구분 | 인원 |
|---|---|
| 1군 | 28 (투수 13~14 / 야수 14~15) |
| 2군 | 약 30 |
| 팀 합계 | 약 58 (외국인 3 포함) |
| 리그 전체 | 약 580 |
| 드래프트 풀 | 매년 약 100 |
| 외국인 풀 | 매년 약 40 |

## 이름 생성
- 성씨: 실제 인구 비율 가중 추출 (김·이·박 비중 높게, 희귀 성씨도 가끔)
- 이름: 2음절 조합, 출생 연도(1986~2007) 세대에 흔한 음절 위주
- 리그 내 동명이인 금지
- 유명 현역·은퇴 선수 이름 **금지 목록**으로 필터
- 외국인: 영어·스페인어권 이름 풀, 화면에는 등록명(성 또는 짧은 애칭)
- 문자 중계 조사 처리를 위해 이름의 마지막 글자 받침 여부를 쓸 수 있어야 함 (07)

## 나이·숨김 수치 분포
| 항목 | 분포 |
|---|---|
| 나이 | 19~40, 1군 주전은 26~32 집중 |
| 성장 타입 | 조기 25% / 일반 55% / 대기만성 20% |
| 내구도 | 평균 60 정규분포, 극단값 소수 |
| 기복 | 평균 50, 젊을수록 높게 |
| 플래툰 민감도 | 대부분 작게, 일부 크게, 좌타자 평균 더 큼 |

## 계약·연봉·군 복무
- 연봉: 능력치 + 연차. 신인 최저 연봉, FA 계약자 시장가, 그 외 중간. **FA 계약자 일부는 연봉 > 실제 기량** (악성 계약)
- FA까지 남은 시즌: 나이·데뷔 연차로 역산
- 군 복무: 28세+ 대부분 군필, 23세 이하 대부분 미필, 사이 혼재
- 외국인: 팀당 3명(보통 투수 2 + 타자 1), 능력치 높고 편차 큼

## 팀 템플릿 (성격 → 생성 파라미터)
| 구단 | 핵심 파라미터 |
|---|---|
| 대성 나이츠 | 주전 평균 연령 31+, 조기 완성형 비중↑, 고액 장기 계약 다수, 유망주 얇게 |
| 인천 시걸스 | 투수 목표 +8, 야수 목표 −5, 핵심 투수 2명 FA까지 1년 |
| 한강 팬텀스 | 30대 FA 계약 야수 다수(연봉 > 기량), 불펜 목표 −8, 2군 잠재력 낮게 |
| 부산 타이드 | 야수 파워 쪽으로, 선발 목표 −8 |
| 수원 로얄스 | 전 부문 평균, 연령·계약 균형 |
| 창원 머신스 | 저연봉 선수 비중↑, 외국인 능력치 +5 |
| 대구 블레이즈 | 25세 이하 비중↑, 미필 유망주 다수, 불펜 목표 +5, 타자 친화 구장 |
| 광주 스톰 | 2군 잠재력 A급 다수, 1군 목표 낮게, 연봉 총액 최저 |
| 미래 코메츠 | 30대 중후반 저연봉 베테랑 다수, 잠재력 전반 낮게 |
| 대전 로켓츠 | 전 부문 낮게, 유망주 중상위 |

수치는 `data/teams.json`의 `generation` 필드.

## 재현성
생성기는 시드를 받는다. 같은 시드 → 같은 리그. 최종 채택한 시드를 `data/league_2026.json`에 기록한다.
