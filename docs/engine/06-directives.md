# 06. 사전 지시 시스템과 감독

## 확정 사항
- 경기 중 개입은 없고, 경기 운영은 전부 **사전 지시 규칙표**로 한다
- 규칙 편집은 **슬롯 방식 + 프리셋** (IF-THEN 자유 조합은 백로그)
- **감독은 캐릭터**다. 고용·경질 가능
- 플레이 모드는 **단장 전용 / 감독 겸직** 두 가지 (감독 전용 모드 없음)

## 구조
규칙표(`DirectiveSheet`)는 하나이고, 누가 채우는지만 다르다. 시뮬레이터는 규칙표만 읽는다.
| 모드 | 규칙표 작성자 |
|---|---|
| 단장 전용 | 감독 AI가 성향 파라미터로 생성. 유저는 방침만 전달 |
| 감독 겸직 | 유저가 편집. 빈 칸은 AI 기본값 |
| AI 구단 9개 | 감독 AI |

## 규칙표 항목
**① 라인업**
- 상대 선발 **좌완용 / 우완용 라인업 두 벌** (필수)
- 타순, 수비 위치, 지명타자
- 휴식 규칙: 피로도 기준 이상이면 제외, 포수 주 1회 휴식 등

**② 선발 로테이션**
- 5인 순서, 최소 휴식일(기본 4일)
- 피로·부상 시 건너뛰기, 대체 선발 지정

**③ 선발 교체 조건** (먼저 충족되는 것)
- 투구수 한계, 실점 한계, 세 번째 타순 상대 시 교체 여부, 피로도 한계

**④ 불펜 역할**
| 역할 | 기본 투입 조건 |
|---|---|
| 마무리 | 9회 이후, 3점 차 이내 리드 |
| 셋업 | 8회, 3점 차 이내 리드 |
| 필승조 | 6~7회, 접전 리드 또는 동점 |
| 좌완 스페셜리스트 | 후반, 강한 좌타자 차례 |
| 추격조 | 지고 있을 때 |
| 롱릴리프 | 선발 조기 강판, 연장 |
- 연투 제한 (예: 3연투 금지), 최근 7일 투구수 한도

**⑤ 선수 교체 조건**
- 대타: 이닝, 점수 차, 득점권, 상대 투수 좌우
- 대주자: 후반, 접전, 느린 주자 출루
- 대수비: 리드한 후반, 수비 약한 선수

**⑥ 작전 성향** (1~5 슬라이더): 희생번트, 도루, 고의사구

## 예외 처리 (시뮬레이션이 절대 멈추지 않게)
- **던질 투수 없음**: 역할 맞는 투수 → 휴식한 아무 투수 → 추격조 → 피로 무시 투입(부상 위험 증가). 연장 11회(포스트시즌 15회)까지 반드시 누군가 던진다
- **대타 자원 없음**: 교체 없이 진행
- **규칙 충돌 우선순위**: 부상·피로 제한 > 투수 교체 > 대타·대주자 > 작전

## 주간 방침
| 방침 | 효과 |
|---|---|
| 정상 운영 | 규칙표 그대로 |
| 총력전 | 투구수·연투 제한 완화, 필승조 범위 확대. 피로·부상 위험 증가 |
| 선수 보호 | 제한 강화, 주전 휴식 증가 |

## 프리셋
정석형 / 공격형 / 투수 보호형 / 스몰볼. 프리셋으로 채운 뒤 항목별 조정.

## 감독 캐릭터
| 속성 | 내용 |
|---|---|
| 기본 | 이름, 나이, 선수 시절 포지션 |
| 성향 파라미터 7 | 선발 인내심, 불펜 혹사, 번트 선호, 도루 적극성, 플래툰 활용, 유망주 기용, 베테랑 신뢰 |
| 전문 분야 | 투수 육성 / 타격 / 수비·주루. 해당 분야 성장 +10% (09) |
| 계약 | 연봉(운용 자금), 계약 기간 |
| 평판 | 영입 협상·팬심 영향 |

| 파라미터 | 규칙표 반영 |
|---|---|
| 선발 인내심 | 투구수·실점 한계 |
| 불펜 혹사 | 연투 제한, 필승조 범위 |
| 번트 선호 | 번트 슬라이더 |
| 도루 적극성 | 도루 슬라이더 |
| 플래툰 활용 | 좌우 라인업 차이 정도 |
| 유망주 기용 | 젊은 선수 선발 기준 |
| 베테랑 신뢰 | 부진한 베테랑 유지 정도 |

- **감독 풀**: 현직 10 + 무직 후보 6~8 (고정 데이터). 은퇴 선수 → 코치 → 감독 후보 경로 (09)
- **경질**: 시즌 중 가능, 남은 계약 연봉 전액 지급(운용 자금). 시즌 중 경질 시 임시 감독(성향 평균값)
- **방침 반영률**: 단장 방침은 파라미터를 목표값까지 바로 옮기지 않고 **감독 성향 쪽으로 일부만** 이동 (반영률은 balance.json)
- **감독 겸직 모드**: 감독 자리 없음. 감독 연봉 절약, 전문 분야 보너스 없음
