## 0. 한눈에

```
고3 시즌 결산 → 진로(이미 있음: s3_path → path = draft | college)
  ├ draft  → 드래프트 당일(11라운드 · 110명 시뮬레이션) → 지명 → 계약금 → 프로 1년 차
  │           └ 미지명 → [대학] / [독립리그 1년 → 재도전] / [육성선수 테스트]
  └ college → 대학 4년 (요약 진행, 2학년에 얼리 드래프트 선택) → 드래프트
프로 한 시즌 = 스프링캠프(1주) → 정규시즌 24주 → (가을야구) → 시즌 결산·연봉 → 겨울
  1군 / 2군(퓨처스)을 성적·감독 신뢰로 오르내린다
  만 27세 전에 군 복무(상무 지원 / 현역) — 아시안게임 금·올림픽 메달이면 면제(특례)
  1군 시즌이 쌓이면 FA(고졸 8 · 대졸 7시즌) → 잔류 / 이적
  30대 중반부터 노쇠 → 은퇴(직접 고르거나 방출) → 커리어 연대기(스크랩북) → 다음 선수
```

- 유저가 매주 꼭 하는 결정은 고교와 같다: **훈련 1 + 이벤트 0~2** (상한 3). 엔트리·연봉·계약 서류는 모두 자동이고, 갈림길만 이벤트 선택지로 보여 준다.
- 실제 구단·선수·학교·대회 이름은 쓰지 않는다. 프로 구단은 `content.json proTeams` 의 가상 10개 구단을 쓴다.

## 2. 게임용 단순화안

### 2-0. 지킬 원칙
1. **매주 꼭 하는 결정은 0~3개** (CLAUDE.md §3-4): 훈련 1 + 이벤트 최대 2. 프로에서 새로 생기는 일(콜업·말소·연봉·FA·입대)은 **자동 처리 + 갈림길만 이벤트**로 보여 준다. 이벤트도 `story.maxEventsPerWeek`(2) 자리를 함께 쓴다.
2. **서류·관리 디테일은 시키지 않는다.** 엔트리 등록, 연봉 숫자 입력, 계약서, 병무 서류 없음.
3. **기록은 사실적으로.** 프로 정규시즌 기록이 한국 프로 분포(좋은 타자 3할, 홈런왕 30~40개)로 나와야 한다 → 시즌 타석 수가 현실 규모(주전 500~600타석)여야 한다 (§2-2 시즌 구조).
4. **이름은 모두 가상.** 구단은 `proTeams`, 리그·대회·대학·독립 구단 이름도 `content.json` 에 새로 만든다.
5. **원칙 2(시드)·원칙 3(수치는 balance.json)** 그대로. 드래프트·콜업·연봉·노쇠 확률은 전부 커리어 시드 + 시즌 + 주차로 만든다.

| `career/rival.gd` (라이벌 = 라이벌 학교 명단 속 타자) | 고교 맞대결 | 라이벌도 드래프트에 나가 다른 구단에 지명된다 → 그 구단 명단에 들어가 프로 맞대결이 이어진다 |
| `Growth` (잠재력 · `gradeRate` [1.2, 1.0, 0.85]) | 학년별 성장 배율 | 학년 대신 **나이**로 배율 (§2-2 노쇠). 잠재력 위로는 못 큰다 |
| `School` / `Team` (고정 명단·졸업) · `GameRunner` · `AutoPa` | 고교 경기 | 프로 구단도 같은 `Team` 으로 (명단 26명 중 선발 9명). 리그 전력이 고교보다 높고 퍼짐이 작다 |
| `CareerRecords` (경기별·대회별·분할 기록) | 고교 기록실 | 그대로 쓰고 "단계"에 1군·2군·상무·국제대회를 더한다. 통산은 고교 / 프로 따로 |
| 세이브 (`SaveGame`, 세이브 브랜치 — 병합 대기) | 커리어 통째 저장 | 새 상태(프로·군·대학)도 객체 필드만 더하면 저장된다. 새 객체 종류는 `SaveGame.TYPES` 에 한 줄 |
| `content.json proTeams` (가상 10개 구단) · `chapters` | 주목 구단 이름 | 프로 리그 구단. 챕터는 "프로 1년 차 · 신인" 같은 이름을 더한다 |

### 2-2. 현실 → 게임에서는

**드래프트**
- 현실: 9월, 110명, 전년 순위 역순, 1라운드 계약금 2~5억.
- 게임에서는: 고3 시즌 결산(진로 = draft) 뒤 **"드래프트 당일" 화면 하나**. 10개 가상 구단이 전년 순위 역순으로 11라운드를 고른다. 화면은 1라운드 10명을 한 명씩 보여 주고(긴장감), 내 이름이 불리면 멈춘다. 2라운드 뒤로 밀리면 "N라운드까지 건너뛰기". 구단은 참가자 평가값 + 흔들림(구단마다 다른 시드) + 주목 구단 가중치로 고른다. 계약금은 순번 표(`draft.bonusByPick`)로 자동. 유저 결정: 없음 (보는 이벤트). 계약금은 돈으로 들어온다(고교 돈과 같은 지갑).

**미지명**
- 현실: 대학 · 독립리그 · 육성선수.
- 게임에서는: 이벤트 하나로 셋 중 하나를 고른다. ① **대학** (장학금 제안을 받았으면 돈 +) ② **독립리그 1년** → 다음 해 드래프트 재도전 (그 1년은 대학처럼 요약 진행) ③ **육성선수 테스트** (평가값이 기준 근처면 합격 → 2군에서 시작, 시즌 중 정식 등록 이벤트를 넘어야 1군). 모두 "다시 오는 기회"로 느끼게 한다.

**대학**
- 현실: 4년(얼리 드래프트는 2학년), 졸업 예정 해에 드래프트.
- 게임에서는 (추천, §4 Q1): **한 해 = 요약 시즌**. 매년 "대학 리그 결산" 화면 한 장(자동 진행한 기록 · 성장 · 이벤트 1~2개)으로 넘기고 직접 치는 경기는 없다. 성장은 고교 3학년 배율을 이어 쓴다. 2학년 겨울에 **얼리 드래프트 신청 이벤트**(지금 나갈래 / 졸업까지). 4년 차 뒤 드래프트 당일로. 대졸은 FA 7시즌.

**프로 시즌 구조**
- 현실: 144경기, 주 6경기, 3~10월 (약 26주).
- 게임에서는 (추천, §4 Q2·Q3): **한 주 = 현실 한 주 = 6경기, 정규시즌 24주**. 그중 **1경기는 내가 직접 친다**(지금 고교 경기와 같은 화면, 2~5분), 나머지 5경기는 내 타석도 `AutoPa` 로 자동 진행하고 결과 화면에 "이번 주 6경기 · 24타수 7안타 2홈런"으로 묶어 보여 준다. 그래서 주전이면 시즌 550~600타석, 기록 분포가 현실처럼 나온다. 직접 치는 경기는 주의 "빅매치"(라이벌 구단·순위 경쟁 팀)를 고른다. 순위표는 10구단 144경기를 그대로 (다른 경기는 전력 차 빠른 결과 `quick_result`).
- 시즌 앞: 스프링캠프 1주(훈련만, 1군 캠프 / 2군 캠프 명단이 이벤트로). 시즌 뒤: 상위 5팀 가을야구(토너먼트를 짧게, 내가 1군이면 직접 치는 경기 1~3개).

**1군 / 2군**
- 현실: 28명 등록 · 26명 출장, 말소 뒤 10일, 감독 판단.
- 게임에서는: 내 상태는 **1군 주전 · 1군 백업 · 2군** 셋. 매주 결산에서 자동으로 바뀐다. 근거는 최근 4주 성적(OPS+), 종합 능력치와 그 포지션 1군 선수의 차이, 감독 신뢰(고교 `coach` 처럼 프로 감독 인물), 부상. 내려가면 최소 2주는 2군(10일 규칙의 단순화). 오르내림은 **이벤트로 알린다**(콜업 전화 · 말소 통보). 결정은 유저가 하지 않는다. 2군 주는 직접 치는 경기 없이 요약(§4 Q4).
- 백업이면 6경기 중 일부만 나간다(대타 · 선발 2~3경기). 직접 치는 경기도 대타 한 타석일 수 있다 → 긴장감.

**연봉**
- 현실: 겨울 협상, 구단 제시안 근처에서 합의, 조정 신청은 드물다.
- 게임에서는: 시즌 결산에서 **구단 제시액 자동 계산**(지난 연봉 × 성적 배율, 최저 연봉 바닥). 이벤트 하나: ① 도장 찍는다 ② 조금 더 요구한다(감독·구단 관계와 성적에 따라 확률로 +10% 또는 협상 길어져 캠프 컨디션 −). 연봉은 돈으로 매주 나눠 들어오고 장비·레슨·관리·데이트에 쓴다(쓸 곳이 커진다: 개인 트레이너, 집).

**FA**
- 현실: 1군 145일 = 1시즌, 고졸 8 · 대졸 7시즌, 등급·보상, 4년 뒤 재자격.
- 게임에서는: **1군 등록 주 수**를 센다. 정규시즌 24주 중 **20주 이상이면 1시즌**(145/175일 비율을 그대로). 고졸 8 · 대졸 7시즌을 채운 겨울에 "FA 시장" 이벤트: 원 소속 구단 + 관심 구단 2~3곳의 제안(돈 · 출장 기회 · 우승 전력)이 나오고 하나를 고른다(기획 §6 "의리 / 돈 / 우승"). 등급·보상은 화면에 안 보이고 제안 수에만 반영한다(A등급이면 데려가기 어려워 제안 수가 준다). 계약 기간 4년 뒤 다시 FA. 구단이 바뀌면 동료·감독 인물도 바뀐다.

**군 복무**
- 현실: 만 27세 전 상무 지원(선발 경쟁, 18개월, 퓨처스에서 계속 뜀) / 현역 18개월(야구 공백) / 사회복무 21개월, 아시안게임 금·올림픽 메달이면 특례.
- 게임에서는: 나이는 **만 나이**로 센다(고1 = 16세, 고졸 신인 = 19세가 되는 해). 프로 2년 차부터 겨울마다 **"입대 시기" 이벤트**가 뜬다(아직 안 갔으면): ① 이번 겨울 상무 지원 ② 1년 더 미룬다(다음 아시안게임에 건다) ③ 현역 입대. 상무 합격 확률 = 지원 직전 시즌 성적·종합 능력치(1군 주전이면 높음, 2군이면 낮음). 떨어지면 다음 해 다시 지원하거나 현역. **만 27세가 되는 해 겨울까지 안 가면 현역으로 자동 입대.**
  - 상무 18개월 → **"상무 시즌" 2개**(각 요약 진행 + 직접 치는 경기 주 1개, §4 Q5). 성장은 계속, 1군 등록 주는 0 (FA 시계가 멈춘다).
  - 현역 18개월 → **두 시즌 건너뛰기**(연대기에 "입대"·"전역" 한 줄). 능력치가 조금 떨어지고(`military.activeDecline`) 전역 첫해는 2군에서 시작.
- **특례**: 아시안게임은 **4년마다**(게임 안 연도 기준), 올림픽도 4년마다 번갈아. 대회가 있는 해 6월쯤 **대표 선발 이벤트**: 만 25세 이하 또는 입단 4년 차 이하이고 리그 성적 상위면 선발(와일드카드는 만 29세 이하 최상위만). 대회는 **3~5경기 토너먼트**(직접 치는 경기 1~2 + 자동, §4 Q6). 금메달 확률은 대표팀 전력으로. 따면 **병역 해결**(연대기에 큰 장면) + 평판·인기 ↑. 34개월 봉사 같은 디테일은 없다.

**노쇠·은퇴**
- 현실: 30대 중반부터 하락, 주력·수비가 먼저.
- 게임에서는: `Growth` 의 학년 배율을 **나이 배율**로 바꾼다(성장기 ~26세, 전성기 27~31세, 하락 32세~). 하락은 겨울 훈련 때 능력치별로 다른 크기로 깎는다: 주력 먼저 → 파워 → 컨택, 선구안은 가장 늦게. 컨디션 회복도 느려진다. **은퇴**는 ① 시즌 결산에서 유저가 고른다(만 33세 이후 "은퇴 고민" 이벤트) ② 방출(2군 2시즌 연속 + 나이) 뒤 받아 주는 구단이 없으면 강제. 은퇴하면 연대기 화면 → 로비 → 새 선수.

**커리어 연대기 (스크랩북)**
- 현실: 없음 (게임 장치).
- 게임에서는: 시즌마다 한 페이지. `CareerRecords`(시즌 기록 · 대회) + `EventBook.log`(스토리 이벤트) + 자동 "장면"(첫 1군 안타, 첫 홈런, 콜업, 입대·전역, 메달, FA 계약, 개인 타이틀, 은퇴 경기)을 연도별 카드로 모은다. 사진 자리는 G8 SD 일러스트(지금은 빈 틀). 로비 기록실에 "연대기" 탭. 은퇴 때 통산 기록 + 업적 목록 + 한 줄 평.

**라이벌**
- 게임에서는: 라이벌도 같은 드래프트에서 지명된다(보통 나보다 앞). 그 구단 명단에 들어가 프로 맞대결이 이어지고, 신인왕·타이틀·대표 선발에서 다시 부딪힌다. 군 입대 시기도 라이벌은 따로 정한다.

### 2-3. 프로 한 주 (결정 수 확인)
```
주 시작 이야기(0~1) → 훈련 1개 고르기 → 직접 치는 경기 1개 + 자동 5경기 → 결과(이번 주 6경기 묶음 · 성장 · 1군/2군 변동 · 돈)
→ 경기 뒤 이야기(0~1)                       ※ 이벤트는 주 시작 + 경기 뒤 합쳐 최대 2개 (지금과 같은 상한)
```
- 콜업·말소·연봉 제시·FA 공시·입대 영장은 **이벤트 자리를 쓰는 스토리 이벤트**라 그 주에는 무작위 이벤트가 밀린다. 한 주 결정 수는 최대 3을 넘지 않는다.
- 2군·상무·대학 요약 주는 훈련 1개만 고르고 "다음 주"(결정 1).

| `gold_medal` | 대회 결승 뒤 | 금메달 | 병역 해결의 순간. 누구에게 먼저 전화할까 (관계) |
| `discharge` | 전역 | 전역 | 2군에서 다시 시작. 조급하게 / 차근차근 |
| `fa_market` | FA 겨울 | FA 시장 | 원 소속(의리) / 돈 많이 주는 구단 / 우승 전력 구단 |
| `trade_rumor` | 시즌 중 | 트레이드설 | 기사 하나에 흔들린다. 감독 찾아가기 / 무시 (컨디션·관계) |
| `rival_pro` | 라이벌 구단전 | 프로 맞대결 | 고교 라이벌과 1군에서 다시. 인터뷰에서 도발 / 존중 |
| `retire_thoughts` | 33세~ 시즌 결산 | 은퇴 고민 | 1년 더 / 이번이 마지막 (은퇴 경기 이벤트로 이어짐) |

### 3-4. 필요한 테스트
- **드래프트**: 110명이 겹치지 않게 뽑힌다, 지명 순서 = 전년 순위 역순(모든 라운드 같은 순서), 계약금 표가 순번에 단조 감소, 같은 시드 → 같은 지명. **내 실제 지명이 `Scouting.projection` 예상 범위 안에 대부분(예: 80%) 든다**
- **미지명**: 평가값이 낮으면 미지명 → 세 경로 모두 다음 단계로 이어진다
- **프로 시즌**: 24주 × 6경기 = 144경기, 순위표 승 = 패 합, 주전 시즌 타석 500~650
- **1군/2군**: 잘 치면 콜업, 못 치면 말소, 말소 뒤 최소 2주, 등록 주 수 집계
- **FA 시계**: 고졸 8 · 대졸 7시즌, 군 복무 시즌은 세지 않는다, 계약 4년 뒤 재자격
- **군**: 만 27세가 되는 해 겨울에 미필이면 반드시 입대, 상무 합격률이 성적에 따라 오른다, 현역 = 두 시즌 건너뛰고 능력치 하락, 메달이면 이후 입대 이벤트가 안 나온다
- **노쇠**: 32세 이후 해마다 종합 하락, 주력이 가장 먼저
- **이벤트 무결성**: `EventBook.validate` 에 새 조건·효과, 새 이벤트 모든 선택지
- **세이브**: 프로 단계에서 저장 → 불러오기 → 진행이 원래와 같다 (지금 `test_save_then_continue_is_same` 확장)
- **장기 밸런스** (`tests/calibrate_pro.gd`, CLAUDE.md §7 G7~): 자동 커리어 **16~32번**(고교 3년 + 프로 은퇴까지) →
  - 지명 분포: 1라운드 10~20%, 미지명 15~30%
  - 프로 통산: 은퇴 나이 중앙값 34~37, 통산 타율 분포(.240~.300), 통산 홈런(0~300, 중앙값 60~120), 1군 시즌 수
  - 시즌 기록: 리그 타격왕 .330~.360, 홈런왕 30~45 (다른 가상 선수 포함)
  - 군: 상무 / 현역 / 특례 비율, FA 도달률
  - 돈: 시즌별 수입·지출이 "쓸 곳이 있게" (모으기만 하는 커리어가 없게)
  - **분포가 안정**: 같은 설정을 두 번 돌린 결과 중앙값 차이가 작다 (시드만 다름)
