# 퍼스트픽 세계관 설정

---

## 1. 기본 전제

| 항목 | 설정 |
|---|---|
| 배경 | 현대 한국 |
| 시간 표기 | 연도 표기 없음. "고1 봄", "프로 2년 차"처럼 학년·시즌으로만 표시 |
| 현실성 | 야구 규정·제도·일정은 현실 기준. 학교·구단·인물은 가상, 도시는 실제 |
| 판타지 요소 | 없음. 능력치 상승은 훈련·경기 경험으로만 |
| 메인 스토리 범위 | 고1 입학 ~ 프로 8년 차 FA 시점 |

### 2-1. 어머니 식당

| 항목 | 설정 |
|---|---|

## 5. KBA 프로리그

### 5-1. 리그 구조

| 항목 | 설정 |
|---|---|
| 리그명 | KBA (Korea Baseball Association) |
| 구단 수 | 10개 |
| 정규시즌 | 3월 말 ~ 9월, 팀당 144경기 |
| 포스트시즌 | 와일드카드(4·5위) → 준플레이오프 → 플레이오프 → 한국시리즈 |
| 1군 엔트리 | 28명 |
| 2군 | 퓨처스리그 |

### 5-2. 구단

| 구단 | 연고지 | 전력 | 성격 |
|---|---|---|---|
| KKG 스타즈 | 서울 | 강 | KKG그룹 소유. 자금력 최고, FA 큰손, 인기 구단 |
| 동진 불스 | 대구 | 강 | 전통의 강호. 투수력 중심, 우승 경험 많음 |
| 한성 블루호크스 | 서울 | 중 | 육성형. 젊은 선수 기용에 적극적 |
| 세광 웨이브스 | 인천 | 중 | 장타력 중심 공격 야구 |
| 남도 팔콘스 | 광주 | 중 | 열성 팬덤. 성적에 따라 분위기가 크게 출렁임 |
| 가야 워리어스 | 창원 | 중 | 데이터 야구, 프런트 주도 운영 |
| 한별 코메츠 | 대전 | 중 | 수비·주루 중심의 짜임새 야구 |
| 해동 샤크스 | 부산 | 약 | 인기 최상위, 성적은 수년째 하위권 |
| 태성 썬더스 | 수원 | 약 | 창단 역사 짧은 신생 구단. 리빌딩 중. 주인공 고향 구단 |
| 대륙 웨일즈 | 울산 | 약 | 2년 연속 최하위. 전면 리빌딩 선언 |

※ 전력 구분은 주인공 입단 시점 기준. 이후 시즌마다 변동

### 5-3. 드래프트 결과

전년도 하위 3팀: 10위 대륙 웨일즈 / 9위 태성 썬더스 / 8위 해동 샤크스

**강태오**: 전체 1순위 → 대륙 웨일즈

| 주인공 관심도 | 지명 | 구단 |
|---|---|---|
| S | 1라운드 전체 2순위 | 태성 썬더스 (수원, 고향) |
| A | 1라운드 중반 | 한성 블루호크스 (서울) |
| B | 2~5라운드 | 한별 코메츠 (대전) |
| C 이하 | 육성선수 계약 | 가야 워리어스 (창원) |

- S등급은 고향 구단 전용 장면 추가 (은하식당에 오는 팬, 지역 뉴스 등)
- 프로 편 메인 스토리는 구단과 상관없이 같은 흐름. 감독·선배 이름과 일부 대사만 구단별로 교체

### 5-4. 계약·연봉

| 항목 | 기준 |
|---|---|
| 계약금 | 전체 1~2순위 약 5억 / 1라운드 2~4억 / 2~5라운드 5천만~1.5억 / 육성선수 없음 |
| 신인 연봉 | 리그 최저연봉 3천만 원 |
| 연봉 협상 | 매년 시즌 종료 후, 전년도 성적 기반 |
| FA 자격 | 고졸 입단 8시즌 1군 등록 후 |

※ 계약금·연봉을 재화로 쓰는 콘텐츠 범위는 미정. 금액은 기준값
