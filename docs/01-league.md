# 01. 리그 구조와 세계관

## 확정 사항
- 리그 구조는 현실 KBO와 동일. 시대 배경은 2026년 시즌
- 최신 규정 변화(ABS, 피치클락, 시프트 제한)는 반영하지 않음
- 구단명은 "모기업명/연고지 + 별칭". 실제 구단의 마스코트·상징·컬러·로고를 따라가지 않음
- 시작 전력은 강 2 / 중 5 / 약 3, 팀마다 고유 성격
- 구단 선택 화면에 전력(1~100)·예산·이번 드래프트 순번을 함께 표시 → 팀 선택 = 난이도 선택

## 리그 구조
| 항목 | 값 |
|---|---|
| 구단 | 10개, 단일 리그 |
| 정규시즌 | 144경기, 상대별 16경기 (3연전 4회 + 2연전 2회) |
| 주간 편성 | 화~일 6경기, 월요일 휴식. 24주 |

| 선수단 | 1·2군 체계 |
| 포스트시즌 | 5팀. 와일드카드(4위 vs 5위, 4위 1승 어드밴티지·4위 홈) → 준PO(vs 3위, 5전 3선승) → PO(vs 2위, 5전 3선승) → 한국시리즈(vs 1위, 7전 4선승) |

## 구단과 모기업
모기업은 재정 상태를 가진 게임 속 존재다. 지원 규모가 운용 자금과 FA 공격성을 정하고, 구단 경영(13)에서 구단주 신뢰도·긴축·모기업 교체 이벤트로 이어진다.

> 미결: 도시명으로 시작하는 7개 구단(인천·수원·대전·대구·부산·광주·창원)의 **모기업명은 아직 정하지 않았다.** `data/teams.json`에 `parentCompany: null`로 두고, 표시명은 그대로 쓴다. 유저 확인 후 채운다.

### 구단별 성격 설명
- **대성 나이츠**: 지난 시즌 우승. 주전 대부분 30대 초중반, 2~3년 내 급격한 노쇠화. 연봉 여유 거의 없고 팜 얇음. 과제: 한 번 더 우승 vs 연착륙
- **인천 시걸스**: 선발·불펜 리그 최강, 타선 중하위. 핵심 투수 FA 임박. 과제: 남는 투수로 타선 보강
- **한강 팬텀스**: 모기업 지원 최대(운용 자금 최대), 연봉 총액은 상한 직전. 스타 FA 다수, 불펜 붕괴, 유망주 고갈. 과제: 악성 계약 정리
- **부산 타이드**: 최다 관중·열성 팬. 타선 강팀급, 선발 약함. 팬심 변화 폭 1.5배. 과제: 팬 압박 속 선발 보강
- **수원 로얄스**: 전 부문 리그 평균. 연봉 구조 건강. 과제: 팀 색깔 정하기
- **창원 머신스**: 저비용 고효율, 외국인 스카우트망 최고(외국인 정보 정확도·능력치 보너스). 과제: 돈 쓸 타이밍
- **대구 블레이즈**: 젊은 선수로 교체 중, 불펜 탄탄, 타자 친화 구장. 과제: 성적과 육성 균형, 군 입대 관리
- **광주 스톰**: 1군 약하지만 유망주 A, 연봉 여유 최대. 과제: 정석 재건
- **미래 코메츠**: 모기업 교체 직후, 운용 자금 리그 최저. 저연봉 베테랑·방출 선수 로스터. 과제: 돈 없이 드래프트·트레이드로 버티기
- **대전 로켓츠**: 수년째 하위권, 모기업 지원은 꾸준. 전체 1순위 지명권. 과제: 드래프트 중심 재건

## 전력 수치
- 세 갈래: **타선**(주전 9명 가중 평균), **선발**(5명, 1~2선발 가중), **불펜**(마무리·필승조 중심)
- **유망주 등급** A~D는 1군 전력과 별도
- 표시 범위 1~100, 실제 팀 값은 40~90에 분포. 최강·최약 종합 격차 20점 안팎
- `종합 = 타선 × 0.45 + 선발 × 0.35 + 불펜 × 0.20` (가안. M2 이후 실제 승률과 가장 잘 맞는 비율로 역산해 재조정)

## 예산 표시
- **연봉 총액 / 상한**: 선수단 연봉 합계와 샐러리캡(가안 120억) 사이의 여유. FA·연봉 협상에 사용
- **운용 자금**: 모기업 지원에서 나오는 단기 현금. 계약금, 스카우트, 스태프 연봉, 트레이드 현금, 제재금
- 목표: 선택 화면에서 "다음 시즌 확정 연봉"도 함께 표시

## 드래프트 순번
- 전년도(2025) 최종 순위의 역순. 프로토타입은 단순 역순
- 탱킹이 최적 전략이 되면 하위 3팀 추첨 도입 검토 (백로그)
- 소프트캡 2회 연속 초과 시 1라운드 순번 하락 제재 있음 (11)
