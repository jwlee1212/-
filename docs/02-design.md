# 02. 디자인 (캐주얼, 2026-10-05)

> 이전 "비서 브리핑형" 디자인(`pre-redesign` 태그의 `docs/16-design.md`)을 대체한다.

## 1. 톤

- **밝고 귀엽고 가볍게.** 레퍼런스 분위기는 게임빌 프로야구(SD 캐릭터, 원색, 만화 같은 연출). 단, 캐릭터·에셋·UI 레이아웃·글꼴을 베끼지 않는다
- 숫자는 숨기지 않지만 **놀이처럼** 보이게: 표보다 막대·별·도장·스티커
- 말투는 편한 구어체. 팀장·동료·학부모·감독이 말풍선으로 말을 건다
- 진지한 이벤트(뒷돈, 부상 은폐)도 무겁게 그리지 않는다. 대신 선택의 결과는 확실히 돌아온다

## 2. 캐릭터

- **SD 2~2.5등신, 단색 플랫 벡터.** 실사·사실적 AI 얼굴 금지 (CLAUDE.md 원칙 8)
- **파츠 조합 아바타**: 얼굴형·피부톤·눈·눈썹·머리·모자·유니폼 색을 시드로 조합해 수천 명의 선수를 자동 생성. 선수 얼굴은 세이브 내내 고정
- 표정 4종 이상(기본·웃음·당황·화남) — 이벤트 대사에 맞춰 바뀐다
- 고정 인물(팀장, 동료 스카우터, 라이벌 스카우터)은 별도 일러스트로 개성을 준다
- 주인공 스카우터는 유저가 외형을 고른다(선택)

## 3. 색

- 원색 계열, 채도 높게. 배경은 밝은 크림·하늘색
- 의미 색(좋음/나쁨/주의)과 구단 색은 섞지 않는다
- 등급 색: 능력치·잠재력 등급은 일관된 색 사다리 (예: 회색 → 초록 → 파랑 → 보라 → 금색)
- 모든 색은 테마 토큰으로만 쓴다

## 4. 숫자 표현

- **범위 막대 = 안개.** 관찰이 부족하면 막대가 뿌옇게 넓고, 관찰할수록 안개가 걷히며 좁아진다
- 잠재력은 별(★)과 범위로: "★★★~★★★★★"
- 관찰 카드는 손글씨 메모 느낌의 카드 한 장에 한 문장
- 상세 수치 표는 "더 보기"로 접어 둔다

## 5. 애니메이션

| 순간 | 연출 |
|---|---|
| 관찰 결과 | 카드가 한 장씩 뒤집히며 등장, 범위 막대의 안개가 걷힘 |
| 돌발 이벤트 | 인물이 화면 옆에서 튀어나오며 말풍선. 선택 후 결과 도장 쾅 |
| 경기 하이라이트 | 간단한 SD 투구·타격 모션 (전체 중계가 아니라 핵심 장면만) |
| 드래프트 호명 | 이름이 불리면 모자 던지기, 다른 팀이 채가면 "앗!" |
| 시간 점프 | 달력이 휙휙 넘어가며 내가 본 선수들의 소식이 팝업 |
| 평판 변화 | 숫자가 통통 튀며 올라가거나 내려감 |

- 길이와 이징은 토큰으로 관리. 반복되는 화면의 애니메이션은 짧게(0.2~0.4초), 큰 순간(드래프트·승진)만 길게
- "애니메이션 줄이기" 설정 제공

## 6. 화면 흐름 (초안)

```
타이틀 → 스카우터 이름·외형 → 구단 배정(팀장 첫 인사)
홈(이번 주): 팀장 한마디 / 이번 주 일정 칸 / 진행 중 이벤트 / 관심 선수
  → 일정 고르기(지도형: 권역별 학교·대회 핀)
  → 주 진행 → 관찰 카드 공개 → 돌발 이벤트 → 다음 주
선수 파일: SD 얼굴, 범위 막대, 관찰 카드 모음, 소문·메모
9월: 빅보드 → 회의 → 드래프트 당일
겨울: 시간 점프 → 연대기 → 다음 시즌
```

하단 탭(초안): 홈 / 선수 파일 / 일정 / 내 기록.
