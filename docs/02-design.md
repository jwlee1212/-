# 02. 디자인 (캐주얼, 2026-10-05)

> 이전 디자인 문서(비서 브리핑형, 스카우터용)는 git 태그 `pre-redesign`·`pre-godot`에 있다.

## 1. 톤

- **밝고 귀엽고 가볍게.** 레퍼런스 분위기는 게임빌 프로야구(SD 캐릭터, 원색, 만화 같은 연출). 캐릭터·에셋·UI 레이아웃·글꼴을 베끼지 않는다
- **손맛이 디자인의 중심.** 모든 조작에 소리와 화면 반응이 따른다 (§5)
- 숫자는 숨기지 않지만 놀이처럼: 표보다 막대·별·도장·스티커
- 말투는 편한 구어체. 감독·동료·부모·스카우트가 말풍선으로 말을 건다
- 진지한 이벤트(뒷돈, 승부조작)도 무겁게 그리지 않는다. 대신 선택의 결과는 확실히 돌아온다

## 2. 캐릭터

- **SD 2~2.5등신, 단색 플랫 벡터.** 실사·사실적 AI 얼굴 금지 (CLAUDE.md 원칙 6)
- **내 선수**: 시작할 때 외형(얼굴형·머리·피부톤)과 이름을 고른다. 유니폼은 소속 팀 색
- **다른 선수**: 파츠 조합 아바타를 시드로 자동 생성. 같은 선수는 커리어 내내 같은 얼굴
- 표정 4종 이상(기본·웃음·당황·화남) — 이벤트 대사에 맞춰 바뀐다
- 고정 인물(감독, 라이벌, 스카우트, 부모)은 별도 일러스트로 개성을 준다
- 프로토타입 단계에서는 단순 도형(원·막대)으로 그리고, G8에서 스프라이트로 바꾼다

## 3. 색

- 원색 계열, 채도 높게. 배경은 밝은 크림, 그라운드는 선명한 초록·흙색
- 의미 색(좋음/나쁨/주의)과 팀 색은 섞지 않는다
- 능력치 등급 색 사다리: 회색 → 초록 → 파랑 → 보라 → 금색
- 모든 색은 `godot/scripts/ui/tokens.gd`의 토큰으로만 쓴다

## 4. 숫자 표현

- 능력치는 막대 + 등급 글자(F~S). 상세 숫자는 "더 보기"로
- 성장하면 막대가 통통 튀며 늘어나고 효과음
- 경기 기록은 한 줄 요약 → 핵심 숫자 → 상세 표 순서
- 숫자는 고정폭(tabular)으로

## 5. 손맛 연출 (타격 프로토타입에서 확정한 기준)

| 순간 | 소리 | 화면 |
|---|---|---|
| 투구 | "슉" | 투수 와인드업(팔이 올라감 = 곧 던진다는 신호) |
| 스윙 | 바람 소리 | 배트 궤적 잔상 |
| 정타 | 맑은 "딱!" | **히트스톱** 70ms, 노란 별 파편, 하얀 섬광, 화면 흔들림, 공이 꼬리를 그리며 날아감 |
| 빗맞음 / 파울 | "퍽" / "틱" | 작은 파편, 약한 흔들림 / 공이 옆으로 튕김 |
| 헛스윙·볼 | 미트 "팡" | 미트 위치에 링 |
| 안타 / 홈런 | 짧은 함성 / 큰 함성 | 결과 카드가 "팡" 하고 커짐 / 꽃가루 |

- 결과 문구는 타구가 절반쯤 날아간 뒤에 띄운다 (날아가는 장면의 기대감을 지키려고)
- 연출 시간·흔들림 크기는 전부 `config/balance.json`의 `presentation`에서 조절
- 효과음은 코드로 합성한다 (`sound_synth.gd`) — 저작권 걱정 없음. G8에서 녹음 음원으로 바꿀지 검토
- 투구·수비도 같은 원칙: 조작 → 즉시 소리 → 결과에 비례한 화면 반응
- "애니메이션 줄이기" 설정 제공 (G9)

## 5-1. 타석 화면 (2026-10-06, 게임빌 프로야구 2013 구도를 참고해 현대적으로)

```
┌─[◆ 미니 다이아몬드] 7회말  새싹 2 : 3 번개 ············ B ●●○ S ●○ O ●○  [Ⅱ]┐  ← 반투명 유리 바
│ [7번 김도윤 · 오늘 2타수 1안타]      [밸런스 스윙 · ▬▬▬▬ 남은 시간]          │
│            (전광판)     하늘 · 관중석 · 조명탑                                │
│ ═════════════════════ 외야 담장 ═════════════════════                        │
│        줄무늬 잔디 · 내야 흙 · 마운드 위 투수                                 │
│   ( 타자 뒷모습 )          ⌜  ⌝  ← 스트라이크존 꺾쇠 + 노려치기 칸 + 포수 미트  │
│ (밸런스)(컨택)(파워)(번트)  ⌞  ⌟                                     ( 스윙 ) │
│                       [ 슬라이더  136 km/h ]  ← 구속 표시                     │
└──────────────────────────────────────────────────────────────────────────┘
```
- 시점: 타자 어깨 너머. 타자는 크게(SD, 머리 큼) 앞 왼쪽, 투수는 가운데 마운드
- HUD 는 반투명 유리 패널(`HUD_GLASS`), 둥근 모서리(`RADIUS_HUD`), 볼카운트 점은 볼 초록·스트라이크 노랑·아웃 빨강
- 투구 전 선택 시간(`selectMs`): 투수가 세트 자세로 기다리고, 위 가운데에 "○○ 스윙 · 바꾸려면 왼쪽 아래" + 남은 시간 막대, 스윙 버튼에 남은 시간 링과 "던져!"(누르면 바로 던짐)
- 스윙은 스윙 버튼 또는 화면 아무 곳이나 탭 (손가락이 닿는 순간)
- 정타 뒤에는 같은 HUD 아래로 타구 중계 화면
- 레퍼런스(게임빌)의 에셋·버튼 모양·배치를 그대로 쓰지 않는다: 방향키 자리에 스윙 종류 캡슐, 아이콘·색·패널은 우리 토큰

## 5-2. 메뉴 화면: 로비 · 커리어 허브 (2026-10-07)

유저가 준 시안(어두운 남색 + 형광 라임의 스포츠 중계 톤)을 **레이아웃만** 따르고 색은 이 문서의 밝은 톤 토큰을 그대로 쓴다 (유저 결정).

```
로비                                                       커리어 허브
┌──────────────────────────────────────────┐   ┌─[퍼스트픽] 홈 선수 훈련 인물 스카우트 기록 ── 1학년·3주차─┐
│ KOREAN BASEBALL CAREER     ░(조명 + 타자)░ │   │┌NEXT MATCH──┐┌OVERALL  POTENTIAL┐┌SCOUT REPORT┐│
│ 퍼스트픽 (기울인 굵은 글자)                 │   ││대회 라운드   ││44        74-82   ││3-8 순위 예상 ││
│ F I R S T  P I C K                         │   ││[새싹] VS [번개]││막대 4개           ││[A][C][F][H] ││
│ ▰01 이어하기▰  ← 비스듬한 강조 막대           │   ││상대 선발 …   │├SEASON────────────┤├INBOX · 2───┤│
│    김도윤 · 1학년 · 주말리그 전반기 1/6       │   │└────────────┘│AVG  OPS  wRC+     ││▍감독 한마디   ││
│  02 새 커리어 / 03 타격 연습                 │   │[ 경기 준비 › ]└──────────────────┘└────────────┘│
│  04 기록실 · 05 설정 (준비 중, 흐리게)        │   │컨디션 피로도 행동                     [다음 주] │
│ v0.1 · 가제                  PLAYER 김도윤 │   └─────────────────────────────────────────────┘
└──────────────────────────────────────────┘
```

- 영문 소제목은 자간을 넓힌 굵은 글자(`UiKit.kicker`, `TRACKING_KICKER`), 로고는 기울인 굵은 글자(`Shapes.SlantText`, `SLANT`)
- 강조색은 `ACCENT`(주황): 선택된 메뉴 막대, 탭 밑줄, 경기 준비 버튼, 새 소식 띠. 종합 능력치 카드만 왼쪽 `PRIMARY` 띠
- 카드는 흰 바탕에 작은 모서리(`SPACE_SM`) — 데이터가 촘촘한 화면이라 큰 모서리(`RADIUS_CARD`) 대신
- 아직 없는 시스템(잠재력 범위, 스카우트 예상 순위·주목 구단, 피로도, wRC+, 유망주 랭킹, 받은 소식 일부)은 `content.json` 의 `hubPlaceholders` 임시 값. 시스템이 생기면 실제 값으로 바꾸고 거기서 지운다
- 허브 로고를 누르면 로비로. 인물·스카우트·기록 탭과 로비의 기록실·설정은 "준비 중"

## 6. 화면 흐름 (초안)

```
타이틀 → 선수 만들기(이름·외형·포지션) → 입학식(감독 첫 인사)
홈(이번 주): 감독/동료 한마디 / 훈련 칸 / 다음 경기 / 진행 중 이벤트
  → 훈련 고르기 → 경기(내 차례만 조작, 나머지 하이라이트) → 이벤트 카드 → 주간 결산
선수 정보: SD 얼굴, 능력치 막대, 기록, 관계
커리어: 연대기(스크랩북)
```

하단 탭(초안): 홈 / 내 선수 / 기록 / 커리어.
