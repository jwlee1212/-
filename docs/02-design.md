# 02. 디자인 (캐주얼, 2026-10-05)

> 이전 디자인 문서(비서 브리핑형, 스카우터용)는 git 태그 `pre-redesign`·`pre-godot`에 있다.

## 1. 톤

- **밝고 귀엽고 가볍게.** 레퍼런스 분위기는 게임빌 프로야구(SD 캐릭터, 원색, 만화 같은 연출). 캐릭터·에셋·UI 레이아웃·글꼴을 베끼지 않는다
- **손맛이 디자인의 중심.** 모든 조작에 소리와 화면 반응이 따른다 (§5)
- 숫자는 숨기지 않지만 놀이처럼: 표보다 막대·별·도장·스티커
- 말투는 편한 구어체. 감독·동료·부모·스카우트가 말풍선으로 말을 건다
- 진지한 이벤트(뒷돈, 승부조작)도 무겁게 그리지 않는다. 대신 선택의 결과는 확실히 돌아온다

## 2. 캐릭터

- **인게임(경기·타석·중계): 코드로 찍은 도트** (2026-10-31 유저 결정 "도트 확정하자" — 10-12 의 SD 카툰 포즈 그림은 AI 로 포즈를 맞추기 너무 힘들어서 그만뒀다). `scripts/make_pixel_art.py` 가 관절 좌표와 손으로 찍은 판(몸통·헬멧)으로 그린다. 부위마다 1픽셀 남색 테두리 + 오른쪽 아래 그늘. 타석 화면은 배경 높이에 맞춘 정수 배율(투수는 멀어서 2/3 배율), 중계 화면 선수는 5×8 도트(팀 색만 다름, 원근으로 크기를 바꾸지 않음). 공·조준 표시·타격 이펙트·HUD 글자는 매끈하게 그대로
- 프로토타입 단계의 단순 도형(원·막대)은 모두 도트로 바뀌었다. 남은 것: 주자·포수 동작, 팀 색(팔레트 교체), 좌타자(좌우 반전)
- **대화 화면 인물 일러스트: 애니메이션풍 반신 그림** (2026-10-11 유저 결정). 굵은 외곽선, 셀 채색, 남색 모자·회색 유니폼의 새싹고 톤. 배경은 투명 (흰 배경이면 가장자리부터 지워 넣는다). 파일 목록은 `godot/art/README.md`
- 어느 쪽이든 실사·사실적 AI 얼굴 금지 (CLAUDE.md 원칙 6)
- **내 선수**: 시작할 때 외형(얼굴형·머리·피부톤)과 이름을 고른다. 유니폼은 소속 팀 색
- **다른 선수**: 파츠 조합 아바타를 시드로 자동 생성. 같은 선수는 커리어 내내 같은 얼굴
- 표정 4종 이상(기본·웃음·당황·화남) — 이벤트 대사에 맞춰 바뀐다
- 고정 인물(감독, 라이벌, 스카우트, 부모)은 별도 일러스트로 개성을 준다

## 3. 색

- 원색 계열, 채도 높게. 배경은 밝은 크림, 그라운드는 선명한 초록·흙색
- 의미 색(좋음/나쁨/주의)과 팀 색은 섞지 않는다
- 능력치 등급 색 사다리: 회색 → 초록 → 파랑 → 보라 → 금색
- 모든 색은 `godot/scripts/ui/tokens.gd`의 토큰으로만 쓴다

## 4. 숫자 표현

- 능력치는 막대 + 등급 글자(F~S). 상세 숫자는 "더 보기"로
- 성장하면 막대가 통통 튀며 늘어나고 효과음
- 경기 기록은 한 줄 요약 → 핵심 숫자 → 상세 표 순서
- 숫자는 고정폭(tabular)으로

## 5. 손맛 연출 (타격 프로토타입에서 확정한 기준)

| 순간 | 소리 | 화면 |
|---|---|---|
| 투구 | "슉" | 투수 와인드업(팔이 올라감 = 곧 던진다는 신호) |
| 스윙 | 바람 소리 | 배트 궤적 잔상 |
| 정타 | 맑은 "딱!" | **히트스톱** 70ms, 노란 별 파편, 하얀 섬광, 화면 흔들림, 공이 꼬리를 그리며 날아감 |
| 빗맞음 / 파울 | "퍽" / "틱" | 작은 파편, 약한 흔들림 / 공이 옆으로 튕김 |
| 헛스윙·볼 | 미트 "팡" | 미트 위치에 링 |
| 안타 / 홈런 | 짧은 함성 / 큰 함성 | 결과 카드가 "팡" 하고 커짐 / 꽃가루 |

- 결과 문구는 타구가 절반쯤 날아간 뒤에 띄운다 (날아가는 장면의 기대감을 지키려고)
- 연출 시간·흔들림 크기는 전부 `config/balance.json`의 `presentation`에서 조절
- 효과음은 코드로 합성한다 (`sound_synth.gd`) — 저작권 걱정 없음. G8에서 녹음 음원으로 바꿀지 검토
- 투구·수비도 같은 원칙: 조작 → 즉시 소리 → 결과에 비례한 화면 반응
- "애니메이션 줄이기" 설정 제공 (G9)

## 5-1. 타석 화면 (2026-10-06, 2026-10-15 중계 그래픽으로 바꿈)

시점은 그대로 타자 어깨 너머(게임빌 프로야구 2013 구도를 현대적으로). HUD 만 **실제 야구 중계 그래픽**처럼 짙은 남색 판(`BROADCAST_BG`)으로 바꿨다. 시안: `docs/mockups/broadcast-batting.svg` (중견수 카메라 시안이지만 그래픽 배치는 같다 — 카메라는 바꾸지 않기로 유저 결정).

```
┌[번개 3 │ ▲ │  ◆  │B ●●○]────────────────────────────────────────── [Ⅱ]┐
│[새싹▶2 │ 7 │ ◆ ◆ │S ●○ ]        [밸런스 스윙 · 바꾸려면 왼쪽]  ┌구속──────┐ │
│[P 하늘 번개   87구]            ▬▬▬▬ 남은 시간               │직구 146km/h│ │
│(밸런스)    하늘 · 관중석 · 전광판                            └───────────┘ │
│(컨택 )     줄무늬 잔디 · 마운드 위 투수                                    │
│(파워 )   ( 타자 뒷모습 )    ⌜  ⌝  ← 스트라이크존 + 노려치기 칸 + 미트        │
│(번트 )                      ⌞  ⌟                                          │
│▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔ ← 주황 줄                                     ( 스윙 ) │
│[7│김도윤 1학년·7번 타자 / 오늘 2타수 1안타  시즌 .312·3홈런·18타점]  ← 자막   │
└──────────────────────────────────────────────────────────────────────────┘
```
- **스코어 버그(왼쪽 위)**: 원정·홈 두 줄(팀 색 띠, 공격 팀은 줄을 밝게 + 주황 ▶), 이닝 숫자와 ▲초/▼말(지금 쪽만 주황), 주자 다이아몬드, B·S·O 세 줄 점(볼 초록·스트라이크 노랑·아웃 빨강). 아래 투수 줄: `P 이름 팀 … N구`(N = 이 투수가 이 경기에서 던진 공)
- **구속 패널(오른쪽 위)**: 왼쪽 띠와 구종 글자는 구종 색(`PITCH_COLORS`). 구종은 선구안 시점이 지나야, 구속은 공이 지나간 뒤에 보인다. 모르면 `---`
- **타자 자막(왼쪽 아래)**: 타석이 시작되면 왼쪽 밖에서 미끄러져 나와 `batterCardMs` 동안 있다가 들어간다. 그 전에 첫 공을 던지면 바로 들어간다. 나올 때·들어갈 때 `batterCardSlideMs`
- 스윙 종류는 왼쪽 세로 칩(왼손 엄지 자리, 고른 칩은 `PRIMARY` + 왼쪽 주황 띠), 스윙 버튼은 오른쪽 아래 그대로
- 투구 전 선택 시간(`selectMs`): 위 가운데 "○○ 스윙 · 바꾸려면 왼쪽" + 남은 시간 막대, 스윙 버튼에 남은 시간 링과 "던져!"(누르면 바로 던짐)
- 스윙은 스윙 버튼 또는 화면 아무 곳이나 탭 (손가락이 닿는 순간)
- 정타 뒤에는 같은 HUD 아래로 타구 중계 화면
- 실제 방송사 로고·그래픽을 베끼지 않는다. 색·모양은 우리 토큰

## 5-2. 메뉴 화면: 로비 · 커리어 허브 (2026-10-07)

유저가 준 시안(어두운 남색 + 형광 라임의 스포츠 중계 톤)을 **레이아웃만** 따르고 색은 이 문서의 밝은 톤 토큰을 그대로 쓴다 (유저 결정).

```
로비                                                       커리어 허브
┌──────────────────────────────────────────┐   ┌─[퍼스트픽] 홈 선수 훈련 인물 스카우트 기록 ── 1학년·3주차─┐
│ KOREAN BASEBALL CAREER     ░(조명 + 타자)░ │   │┌NEXT MATCH──┐┌OVERALL  POTENTIAL┐┌SCOUT REPORT┐│
```

- 영문 소제목은 자간을 넓힌 굵은 글자(`UiKit.kicker`, `TRACKING_KICKER`), 로고는 기울인 굵은 글자(`Shapes.SlantText`, `SLANT`)
- 강조색은 `ACCENT`(주황): 선택된 메뉴 막대, 탭 밑줄, 경기 준비 버튼, 새 소식 띠. 종합 능력치 카드만 왼쪽 `PRIMARY` 띠
- 카드는 흰 바탕에 작은 모서리(`SPACE_SM`) — 데이터가 촘촘한 화면이라 큰 모서리(`RADIUS_CARD`) 대신
- 아직 없는 시스템(잠재력 범위, 스카우트 예상 순위·주목 구단, 피로도, wRC+, 유망주 랭킹, 받은 소식 일부)은 `content.json` 의 `hubPlaceholders` 임시 값. 시스템이 생기면 실제 값으로 바꾸고 거기서 지운다
- 허브 로고를 누르면 로비로. 로비의 설정은 "준비 중"
- **로비 (2026-10-21, 유저 결정 "로비화면은 그냥 일러스트 넣어놓자")**: 오른쪽 위 도형 실루엣 대신 **화면 전체에 일러스트**(`art/backgrounds/lobby.png`, 없으면 학교 운동장 `field.png`)를 깐다. 메뉴·로고는 **오른쪽 판**(`LOBBY_PANEL`, 화면 57%부터, 왼쪽 모서리 비스듬히) — 그래서 로비 일러스트는 볼거리를 왼쪽에 둔다. 판은 오른쪽 밖에서 미끄러져 들어오고 메뉴 줄은 하나씩 나타난다. 내 선수 요약은 판 아래 한 줄. 개발 빌드 버튼은 왼쪽 위. (10-18 에 컴퓨터 타자가 혼자 치는 데모 장면을 깔아 봤다가 이걸로 바꿨다)
- **폰 (2026-10-12)**: 허브 탭은 홈 · **폰** · 선수 · 훈련 · 상점 · 스카우트 · 기록. 폰 탭은 누르면 페이지 대신 폰이 뜨고, 안 읽은 문자가 있으면 글자 오른쪽 아래에 빨간 원 + 흰 숫자(`Shapes.Badge`). 인물 탭은 폰의 연락처로 옮겼다. 누르면 허브 위에 어두운 막(`SCRIM`)과 세로 폰(`PHONE_WIDTH`, 몸체 `PHONE_BODY`, 화면 `PHONE_SCREEN`)이 가운데 오른쪽에 뜨고, 대화방·인물 카드를 열면 폰 왼쪽에 그 인물 일러스트와 이름표가 선다. 폰 밖을 누르면 닫힌다. 폰 아래 탭은 메시지 · 연락처 둘. 받은 말풍선 `BUBBLE_THEM` 왼쪽, 보낸 말풍선 `BUBBLE_ME` 오른쪽, 안내 줄(답장할 때를 놓쳤다 · 컨디션 +2)은 가운데 작은 글자. **색은 폰도 밝은 톤 토큰 그대로** (받은 기획안의 "어두운 바탕 + 라임"은 2026-10-07 결정에 따라 쓰지 않았다). 관계는 숫자·막대 없이 문구로만 (`People.relation_text`), 문구가 바뀌면 "서먹하다 → 그럭저럭"이 `ACCENT` 로 깜빡인다. 새 문자는 이야기가 끝난 뒤 오른쪽 위에 알림 띠("알림이 N개 쌓여 있습니다." + 첫 문자 미리보기, `PHONE_BODY` 바탕)가 화면 오른쪽 밖에서 미끄러져 들어왔다가 다시 미끄러져 나간다 (누르면 그 대화방)
- 기록 화면(허브 기록 탭 = 로비 기록실, `RecordsView`): 작은 탭(요약 · 시즌 · 경기 · 대회 · 분할 · 이야기) + 경기·분할은 시즌 칩(전체/통산 · N학년, `ACCENT`). 표는 캡션 글자, 글자 칸 왼쪽 · 숫자 칸 오른쪽 정렬, 지금 시즌은 `PRIMARY`, 승 `GOOD` · 패 `BAD`

## 6. 화면 흐름 (초안)

```
타이틀 → 선수 만들기(이름·외형·포지션) → 입학식(감독 첫 인사)
홈(이번 주): 감독/동료 한마디 / 훈련 칸 / 다음 경기 / 진행 중 이벤트
  → 훈련 고르기 → 경기(내 차례만 조작, 나머지 하이라이트) → 이벤트 카드 → 주간 결산
선수 정보: SD 얼굴, 능력치 막대, 기록, 관계
커리어: 연대기(스크랩북)
```

하단 탭(초안): 홈 / 내 선수 / 기록 / 커리어.
