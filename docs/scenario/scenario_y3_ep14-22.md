# 퍼스트픽 — 2학년 끝 · 3학년 시나리오 (EP14 ~ EP22, 카드판)

> **2026-11-05 새로 씀.** 형식은 1·2학년 문서와 같다 (`card-plan.md`): 장면 하나 = 카드 한 장, 대사 1~4줄, 선택지마다 `| 힌트`, 고르면 반드시 능력치·관계·진로 중 하나가 바뀐다. 경기 밖 결정은 한 주 0~3개.
> - 줄거리는 `scenario_y2y3_outline.md` 표를 따른다. 개요의 EP14(상비군)·EP16(갈림길)은 이미 2학년 문서의 EP12·EP13 에 들어가 있어서, 번호를 앞으로 당겼다 (아래 표).
> - 컷신은 넣지 않는다. 넣을 자리는 장면 아래 **※ 컷신 후보** 로만 적는다 (목록: `pro-cutscene-list.md` 1장).
> - 대사는 이 문서에서만 고친다 → `python3 scripts/build_scenario.py`.
> - 드래프트 결과(구단·순번·계약금)는 엔진이 정한다: 유망주 랭킹 → 관심도 등급(S/A/B/C) → `docs/worldview.md` 5-3 표 (`balance.json career.pro.draft`).

# EP14 — 백 번째

### SCENE ep14_01 | 2학년 겨울 캠프 3주 | 부실

```
soyul: 오늘 올리는 게 백 번째야. 네 타석, 네 수비.

  soyul: 2년 동안 한 번도 안 빠지고 나왔더라. 그래서 백 개야.
ELSE:
  soyul: 다친 날 빼고 다 찍었어. 그래도 백 개는 채웠다.
END

CHOICE ep14_hundred:
  - "졸업해도 계속 찍어 주세요." | 소율 호감 ▲ -> goto A
  - "이제 제 기록은 제가 볼게요." | 선구안 경험치 (영상 복기) -> goto B

A:
  soyul: 대학 가도 주말엔 와. 삼각대 들고.
B:
  soyul: 폴더 비밀번호 알려 줄게. 백 개 다 봐.
```
