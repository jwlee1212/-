## 유저 확인 필요 (초안에서 임시로 정한 것)

1. **서지안의 학교.** 정하지 않았다. 청운고 방송부로 하면 태오와 이야기가 이어진다.
2. **주장.** 고정하지 않고 선택형으로 했다 (내가 맡거나 준수를 추천).
3. **미지명일 때.** 육성선수 계약과 대학 진학 중 고르게 했다 (세계관에는 육성선수만 있다).
4. **결승 결과.** 실제 경기 결과로 갈리게 했다 (우승 / 준우승). 세계관 연표는 "결승"까지만 정해 두었다.
5. **연애는 한 명만**, 고백은 2학년 가을~겨울로 했다.
6. **"학부모 뒷돈"** (컨셉 문서의 돌발 이벤트)은 넣지 않고 "인성 찌라시"만 넣었다.
