# 이야기 스토리판 — 압축 규칙 (2026-11-09 시험 중)

> 결정(2026-11-09, 유저): "솔직히 스토리가 더 재밌어. 근데 이전에는 스토리가 너무 많고 루즈했어."
> 카드판(2026-11-04, `card-plan.md`)을 통째로 되돌리지 않고, **한 줄씩 넘기는 대화로 돌아가되 옛 분량의 3분의 1쯤으로 줄인다.**
> 먼저 **EP01 하나만** 바꿔 폰에서 해 보고, 길이가 괜찮으면 EP02~ 로 넓힌다.

## 분량 비교 (1학년 EP01~08 문서)

| | 분량 | 에피소드당 장면 |
|---|---|---|
| 옛 스토리 (태그 `pre-card-events`) | 약 96,000자 · 2,735줄 | 6~7개 |
| 카드판 | 약 22,000자 · 676줄 | 카드 몇 장 |
| 스토리판 목표 | 옛 분량의 1/3 | 2~4개 |

EP01 시험판: 옛 장면 7개·대사 약 120줄 → **장면 4개·대사 약 45줄**.

## 규칙

1. **에피소드당 장면 2~4개.** 이동 장면(버스·복도), "하루 정리" 장면은 뺀다. 사건이 있는 장면만 남긴다.
2. **장면당 대사 약 10줄.** 설명하는 대사를 지우고 인물 성격이 드러나는 대사만 남긴다. 새로 쓰지 않고 옛 대본에서 고른다.
3. **장면은 선택이나 플레이로 끝낸다.** 읽기만 하는 장면은 두지 않는다. 선택은 카드판처럼 반드시 무언가 바꾼다(능력치·관계·진로, `CHOICE_FX`).
4. **밤 폰 장면은 폰 문자(`messages`)로.** 원하는 사람만 연다 (지금 구조 그대로).
5. **건너뛰기는 그대로.** 대화 화면의 [건너뛰기 ▶▶] 는 스토리판에서 보인다.

## 구현

- `scripts/build_scenario.py` 의 `STORY_PREFIXES` 에 든 접두어(지금 `ep01_`)로 시작하는 이벤트는 `card: false` → 대화 화면이 한 줄씩 넘기는 모드로 보인다. 넓힐 때는 이 목록에 `ep02_` 처럼 더하고 문서를 다시 쓰면 된다.
- 선택지 `| 힌트` 는 문서에 그대로 둔다 (카드로 되돌릴 때 쓰고, 스토리 화면도 언젠가 보일 수 있게).
- 테스트: `test_story_cards` 가 EP01 은 스토리판, 나머지는 카드인지 본다.
