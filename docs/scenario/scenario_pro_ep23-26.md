# 퍼스트픽 — 프로 입단 ~ 1군 데뷔 시나리오 (EP23 ~ EP26, 카드판)

> **2026-11-05 새로 씀.** 형식은 고교 문서와 같다 (카드 한 장, 대사 1~4줄, 선택지마다 `| 힌트`, 고르면 무언가 바뀐다).
> - **이야기 카드는 1군 데뷔(EP26)에서 끝난다.** 그 뒤로는 줄거리 대신 **상황이 컷신을 연다** — 첫 안타·첫 홈런·첫 타점·첫 도루·10·20홈런·100안타·가을야구 데뷔·우승·신인왕·골든글러브·MVP… (`content.json pro.milestones`, 목록과 컷신 자리: `pro-cutscene-list.md` 2장).
> - 구단에 따라 바뀌는 것은 이름뿐이다 (`{proTeam}` 구단, `{proCoach}` 감독, `{proCaptain}` 주장 — `content.json proTeams`). 흐름은 구단과 상관없이 같다 (worldview 5-3).
> - 사이드 스토리(하린·소율·서지안의 프로 편, 새 인물 윤채아)는 폰 문자(`m_pro_*`)와 그 문자가 예약하는 카드(`pro_side_*`)에 있다 — 이 문서가 아니다.
> - 컷신은 넣지 않는다. **※ 컷신 후보** 로만 적는다.

## 1. 화자

| 화자ID | 이름 | 설정 |
|---|---|---|
| `pro_coach` | 감독 | 지명 구단 감독 (이름은 `{proCoach}`) |
| `captain` | 주장 | 지명 구단 주장, 같은 유격수 출신 (이름은 `{proCaptain}`) |
| `futures_coach` | 퓨처스 코치 | 2군 타격 코치 |

## 2. 변수

| ID | 타입 | 값 | 생성 | 사용 |
|---|---|---|---|---|
| `bonus_use` | enum | `restaurant` / `keep` | EP23 | 사이드 스토리(윤채아)·엄마 문자 |

# EP23 — 입단

### SCENE ep23_01 | 프로 1년 차 1월 | 구단 사무실

```
IF draft_tier in [S, A, B]:
  NARR: {proTeam} 입단식. 계약서 맨 아래 숫자는 {bonus}.
  IF mom_knows == true:
    NARR: 은하식당 월세가 몇 달 밀려 있다는 걸 나는 안다.
  END
  CHOICE ep23_bonus:
    - "계약금으로 가게 빚부터 갚는다" | 엄마 관계 ▲▲ · 돈 ▼ -> bonus_use = restaurant ; goto A
    - "내가 들고 있는다 (나중을 위해)" | 돈 유지 · 컨디션 ▲ -> bonus_use = keep ; goto B
  A:
    mom: …이 돈은 네 거야. 엄마는 한 번만 빌리는 거야.
  B:
    NARR: 통장 앱을 몇 번이고 다시 열어 봤다.
ELSE:
  NARR: {proTeam} 퓨처스 구장. 등번호는 세 자리, 계약금은 없다.
  CHOICE ep23_number:
    - "세 자리 번호를 그대로 단다" | 컨디션 ▲ (각오) -> bonus_use = keep ; goto A
    - "엄마 가게에 사인 볼부터 보낸다" | 엄마 관계 ▲ -> bonus_use = keep ; goto B
  A:
    NARR: 등 뒤의 숫자가 길다. 그래도 프로 유니폼이다.
  B:
    mom: 계산대 옆에 놨어. 손님들이 다 물어봐.
END
```

※ 컷신 후보: `pro_signing` — 입단식 플래시 속 유니폼 실루엣 / 육성선수면 새벽 퓨처스 구장에 혼자 선 뒷모습.
