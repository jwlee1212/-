# 선수 커리어 이름 입력 화면 v2

사용자 수정 요청: AI 느낌 축소, 추천 이름 삭제.
도구: 내장 GPT 이미지 생성.

Use case: ui-mockup
Create a substantially revised Korean mobile baseball career game name-entry screen. Landscape 2.16:1. User rejected previous concept as looking too AI-generated and explicitly asks to REMOVE ALL RECOMMENDED NAME UI.
Art direction: crafted restrained 2D game UI, minimalist Japanese/Korean indie sports game feel, flat matte colors, purposeful graphic shapes, very limited cel shading, imperfect hand-drawn ink lines, no glossy rendering, no soft airbrushed anime art, no excessively detailed backgrounds, no cherry blossoms, no sparkles, no cinematic lighting. Not an AI fantasy illustration. Mostly solid warm ivory negative space and dark ink navy. One burnt orange primary action. Original design.
One actual full screen, no device frame, no explanation labels. Top left small back arrow with "뒤로", top right understated small "퍼스트픽". Left 40% has a quiet editorial illustration: a small appealing teenage baseball player in original 2.5-head SD proportions, simple unbranded navy cap and off-white uniform, navy socks, worn sneakers, bat tucked under arm. Simple dot/line facial features with determined relaxed expression, very spare solid cel colors, ONE hard-edged shadow tone only, outlined by expressive ink strokes. Behind him just a simple desaturated pale-blue chain link fence segment, warm sandy ground and flat school clubhouse shape, huge empty cream sky. No lush painted scenery. Illustration should look deliberately designed by a human game artist, not glossy anime key art or 3D toy.
Right 53% clean flat UI with generous margins and sharp typographic hierarchy. Small blue text "새 커리어". Large navy title split naturally in TWO lines "선수 이름을" then "정해 주세요". Small muted line "서림고 야구부 · 1학년". Below generous gap and one label "선수 이름". One wide off-white input with simple navy bottom border, placeholder "이름을 입력하세요", tiny helper underneath "최대 6자". Bottom wide solid burnt orange button "입학하기" and simple white right arrow. Flat buttons with small 6px corner radius, no gradients no glow no thick plastic borders. All text beautifully legible Korean, align elements precisely. NO recommended names, no name chips, no random-name button, no name lists. NO position choice, stats, currency, appearance controls, new slogans or story copy. Show a polished viable mobile game screen with very few elements and relaxed empty space. Keep content within safe area. No real logos, no real people, no photoreal faces, no watermark.
