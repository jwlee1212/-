# 04. 타석 시뮬레이션과 기록 지표

## 확정 사항
- 타석 단위 시뮬레이션 (투구 단위 아님)
- 매치업 확률은 **Log5**
- 리그 환경은 **매 시즌 이벤트로 변동** (스토브리그 시작 때 발표)
- 경기는 항상 이벤트 스트림을 만든다. 주간 진행과 문자 중계 관전은 유저가 경기별로 선택 (07)

## 단계별 결과 결정
```
① 승부 결과   삼진 / 볼넷 / 사구 / 인플레이      구위·제구 vs 컨택·선구안
② 홈런 여부   인플레이 중 홈런                   파워 vs 구위·땅볼 유도, 구장
③ 타구 종류   땅볼 / 뜬공 / 라인드라이브          땅볼 유도 vs 파워
④ 안타 여부   수비가 처리했는지                   타구 종류, 컨택, 수비팀 수비력
⑤ 안타 종류   1루타 / 2루타 / 3루타               파워, 주루
⑥ 상황 결과   병살, 희생플라이, 진루, 실책 등      베이스 상태, 주루, 수비 (05)
```
⑥에서 베이스·아웃 상태에 맞지 않는 결과는 확률표에서 제거하고 가장 가까운 결과로 대체한다 (예: 3루 주자 없음 → 희생플라이 대신 뜬공 아웃).

## Log5
```
p = (B × P / L) / (B × P / L + (1 − B)(1 − P) / (1 − L))
B = 타자의 해당 결과 비율, P = 투수의 허용 비율, L = 리그 평균
```
결과 종류마다 적용한다. 극단 매치업에서도 0~1을 벗어나지 않는다.

## 능력치 → 비율 변환표
능력치 50 = 리그 평균. 결과 종류별로 앵커 포인트를 두고 선형 보간. 예 (타자 컨택 → 삼진율):

| 컨택 | 20 | 50 | 80 | 95 |
|---|---|---|---|---|
| 삼진율 | 30% | 19% | 11% | 7% |

모든 표는 `config/balance.json`의 `ratingTables`에 둔다.

## 보정
| 보정 | 방식 |
|---|---|
| 좌우 상성 | 리그 공통 보정 × 선수 플래툰 민감도 |
| 구장 | 홈런·장타 비율에 구장 계수 (대구 1.10, 그 외 1.00 시작) |
| 투수 피로 | 투구수·피로도가 한계에 가까울수록 구위·제구 하락 |
| 폼 | 능력치 ±5 이내 (08) |
| 수비력 | 인플레이 안타 확률·실책 확률에 해당 포지션 수비 반영 |
| 리그 환경 | 시즌별 홈런·삼진·볼넷 배율 |

**팀 분위기(연승/연패)는 경기력에 영향 없음.**

## 투구수 추정
| 결과 | 평균 투구수 |
|---|---|
| 삼진 | 약 4.8 |
| 볼넷 | 약 5.7 |
| 인플레이 | 약 3.3 |
결과별 평균 + 랜덤 편차. 타자 선구안이 높을수록 증가. 사전 지시의 투구수 한계와 피로 계산에 사용.

## 캘리브레이션 목표 (100시즌 평균)
| 지표 | 목표 |
|---|---|
| 리그 타율 | .260~.275 |
| 삼진 비율 | 18~20% |
| 볼넷 비율 | 9~10% |
| 경기당 팀 득점 | 4.6~5.0 |
| 팀당 시즌 홈런 | 100~140 |
| 최고 승률 팀 | .600~.650 |
| 최저 승률 팀 | .350~.400 |
목표 수치는 근사값이다. 첫 캘리브레이션 때 최근 KBO 시즌 실제 기록으로 재확인한다 (유저에게 확인 요청).

## 리그 환경 이벤트
시즌 종료 직후, 스토브리그 시작 때 "리그 사무국 발표"로 공개 → FA 시장에 영향.
| 이벤트 | 효과 |
|---|---|
| 공인구 반발력 조정 | 홈런·장타 ±5~12% |
| 스트라이크존 조정 | 삼진·볼넷 ±1~2%p |
| 구장 리모델링·펜스 조정 | 해당 구장 계수만 변경 |
| 변화 없음 | 약 50% |
발표 내용과 실제 효과 사이에 작은 오차를 둔다.

## 기록 지표
투구·타구 추적 지표(헛스윙률, 타구 속도, 발사각, 구종 가치)는 **구현하지 않는다.**

**1단계 (프로토타입, M2)**
- 타자: 타율, 출루율, 장타율, OPS, 홈런, 타점, 득점, 도루, 안타, 2루타, 3루타, 볼넷, 삼진
- 투수: 평균자책점, 이닝, 승·패·세이브·홀드, 탈삼진, 볼넷, 피홈런, WHIP, 피안타율

**2단계 (정식, M7)**
- 타자: K%, BB%, ISO, BABIP, wOBA, wRC+, 좌/우 투수 상대 분리, 땅볼/뜬공 비율
- 투수: K/9, BB/9, HR/9, K-BB%, BABIP, LOB%, FIP, ERA+, 좌/우 타자 상대 분리, 땅볼/뜬공 비율

**3단계 (정식, M7)**
- WAR. 수비 기여는 "수비 능력치 × 포지션 난이도"로 단순 추정
- WPA/클러치는 구현하지 않음 (백로그)

**화면**: 기본 탭과 세이버 탭 분리.

## 기록 저장 방식
- 타석 단위 로그는 저장하지 않는다
- 선수별·시즌별 **누적 카운트**를 좌우 분리로 저장. 비율 지표는 표시 시점에 계산
- **현재 시즌의 경기별 박스스코어는 보관** (주간 결산, 최근 10경기). 시즌 종료 시 누적으로 합침
- **리그 상수**(wOBA 가중치, FIP 상수, 리그 평균, 대체 선수 수준)는 시즌 종료 시 리그 전체 기록으로 계산해 저장
- wRC+, ERA+, FIP는 구장 계수로 보정

## 타석 결과 목록 (기록해야 할 것)
1루타, 2루타, 3루타, 홈런, 볼넷, 고의사구, 사구, 삼진, 땅볼 아웃, 뜬공 아웃, 라인드라이브 아웃, 병살타, 희생번트, 희생플라이, 실책 출루, 야수선택, 낫아웃 출루, 타격방해. 모든 결과에 타구 종류와 투수·타자 좌우를 붙인다.
