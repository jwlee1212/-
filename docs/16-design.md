## 1. 컨셉

단장(유저)이 서류를 직접 뒤지지 않는다. **베테랑 비서가 매주 브리핑하고, 유저는 승인·결정만 한다.**

| 항목 | 내용 |
|---|---|
| 비서 | 이름 미정, 가칭 **"미스 백"**. 이름은 코드 한 곳(`Secretary.NAME`)에서만 바꾼다 |
| 성격 | 낙관적이고 담백한 베테랑. 나쁜 소식도 침착하게, 좋은 소식도 과장 없이 |
| 말투 | 편한 구어체 해요체. 호칭은 "단장님". 느낌표·이모지 남발 금지 〔추정〕 |
| 모습 | 실사·AI 생성 얼굴 금지. **단순 아이콘 아바타**(원 + 이니셜)만 |

### 말투 예시 〔추정〕
| 상황 | 문구 |
|---|---|
| 알림 없음 | "이번 주는 조용해요. 바로 진행하셔도 됩니다." |
| 연패 | "3연패예요. 아직 시즌 초반이니 너무 걱정하진 마세요." |
| 부상 | "김OO 선수가 햄스트링을 다쳤어요. 2주 정도 걸린답니다." |
| 우승 | "우승이에요. 올해 정말 고생 많으셨습니다." |

## 3. 정보 구조 (유지)

- 모든 화면: **한 줄 요약 → 핵심 숫자 → 상세 표**
- 긴 표: 첫 열(이름) 고정, 나머지 가로 스크롤
- 기록: 기본 탭 / 세이버 탭 (2026-10-04: 리그 탭에선 따로 칸을 두지 않고 기록표 안의 "기본 / 세이버" 보기로 나눈다)
- **선수 기록 한눈에** (2026-10-04): 선수 상세 "기록" 탭 = 핵심 숫자 넷(타자 OPS·홈런·wRC+·WAR / 투수 평균자책·탈삼진·FIP·WAR) + **팀 내 N위** → **리그 백분위 막대**(Baseball Savant 식 여섯 줄, 규정 절반 이상(투수 1/3)과 비교, 막대 색은 능력치 등급 색 구간, "상위 N% / 하위 N%") → 상세 기록 4칸 격자 → 통산. 공개 기록만 쓰므로 타 팀 선수에게도 그대로 (원칙 4와 무관)
- 하단 탭 **5개** 〔2026-10-03 개편 — 더쇼 프랜차이즈·FM 식, 더 캐주얼하게〕: **단장실 / 선수단 / 영입 / 메시지 / 리그** (순서 고정)
  | 탭 | 들어가는 것 |
  |---|---|
  | 단장실 | 허브: 팀 띠 · 다음 경기 매치업(예상 선발) · 메시지 미리보기 · 타일 넷(선수단·영입·구단주 목표·리그) · 이번 주 일정 띠 · 시뮬 버튼 + "어디까지" 메뉴 |
  | 선수단 | 선수(전력 요약 + **기록 바로가기** + 목록, 간단히/자세히) / 뎁스(다이아몬드 + 리그 전력 비교) / 지시(사전 지시). 기록 바로가기(2026-10-04): 타자·투수 기록(리그 탭 기록표를 "우리 팀"으로) · 팀 기록, 설명줄은 팀 OPS·팀 평균자책과 리그 순위 |
  | 영입 | 트레이드 / FA / 외국인 / 스카우트(드래프트 풀·관찰·드래프트) / 구단 현황 |
  | 메시지 | 답장 필요(돌발 이벤트) · 결정할 것 · 발신자별 대화(미스 백·스카우트팀·의료진·코칭스태프·프런트). FM 받은편지함을 메신저처럼 |
  | 리그 | **허브** (2026-10-04, 유저 요청 — 상단 가로 탭 폐지): 카드 일곱 장(순위 / 타자 / 투수 / 팀 기록 / 뉴스 / 팬 반응 / 역대)에 맛보기만 두고, 카드를 누르면 그 구역 전체 화면이 쌓인다. 맛보기: 순위 상위 다섯(+ 밖이면 우리 팀), OPS·평균자책 리그 1~3위 + 우리 팀 1위 한 줄, 팀 타율·OPS·평균자책·실점과 리그 순위, 최근 기사 둘, 팬심 + 최근 글 하나, 지난 시즌 우승·MVP. 타자·투수는 **정렬 기록표** (2026-10-04): 범위(리그 전체 / 우리 팀 = 팀 내 순위) · 보기(기본 / 세이버) 세그먼트, 접이식 필터(포지션·보직 / 최소 타석·이닝: 규정 이상·규정 절반·직접(슬라이더)·전체), 머리글을 누르면 정렬. **팀 기록**: 열 팀 합계 표(타격 / 투구 — 팀 타율·OPS·득점·홈런·wRC+ / 팀 평균자책·WHIP·실점·FIP·ERA+·실책) |
  - 예전 구성(홈/로스터/스카우트/시장/기록, 2026-09-27)에서 바뀐 점: 스카우트가 영입 안으로, 뉴스·팬 반응이 리그로, 결정 일지와 주간 알림이 메시지로
  - 능력치는 **오버롤 숫자**(등급 색)로 보인다. 등급 글자 배지는 쓰지 않는다 (2026-10-03 유저 결정)
  - 구단 운영(재정·**연봉 계획**·구단주·스태프)과 커리어는 단장실 "구단주 목표" 타일에서 들어간다
  - **연봉 계획** (2026-10-04): 앞으로 4년의 캡 여유(해마다 막대)와 연말 운용 자금 표 → FA 로 풀리는 선수 → 선수별 연봉 장부(확정 / ~재계약 예상 / FA). FA 조건 창·트레이드 교환대·다년계약 창에는 "이 조건이면" 해마다 캡 여유·운용 자금 변화 표
- 선수 목록(스카우트·로스터·시장)에는 접이식 필터: 포지션 / 잠재력 / 현재 종합, 로스터·시장은 계약 기간 / 연봉 추가
- 이름 옆 정체 칩: "신인"(브랜드 색), "우리 팀"(구단 색), **"핵심 유망주"(등급 색 높음, 2026-10-04)** — 상태 배지(의미 색)와 겹치지 않는다
- **진행(시뮬) 버튼은 하단 고정**, 구단 색으로 칠한 유일한 큰 면. 알림이 없으면 이것만 누르면 된다. **단장실 탭(허브·주간 브리핑)에서만 보인다** (2026-09-27 유저 요청).
  옆의 "⋯" 메뉴에 자동 진행(올스타까지·시즌 끝까지) — 더쇼의 "어디까지 시뮬" (2026-10-03)

## 4. 앱 진입 흐름 〔2026-09-27 추가〕

```
스플래시(데이터·세이브 읽기) → 타이틀 ─┬─ 이어하기 카드 (단장 이름 · 대표 칭호 · 구단 · 시즌) → 홈
                                      └─ 새 게임 → 단장 이름 입력 → 구단 선택 → 부임 확인 → 리그 구성 → 홈(비서 첫 인사)
```
- 세이브가 있는데 새 게임을 고르면 확인 창 (지금 기록이 지워진다)
- 단장 이름은 비서 카드 안에서 묻는다. 최대 8자, 이후 "OOO 단장님"으로 부른다

## 4-1. 주간 루프 화면 흐름 〔2026-09-27 개정 — 홈 허브·돌발 이벤트〕

```
[주 시작] 단장실 = 허브 〔2026-10-03 개편. 섹션 4개 규칙의 예외 — 유저 결정〕
  ├ (첫 주만) 비서 첫 인사
  ├ 팀 띠: 엠블럼 · 전적·순위·연승 · 가을야구권 칩
  ├ 다음 경기 매치업 (시즌 중) / 시즌 단계 카드 (FA·포스트시즌·시즌 종료)
  │   요일·홈/원정·상대 · 예상 선발 둘(로테이션 다음 순번, 승·평균자책) · 상대 전적
  ├ 메시지 미리보기: 비서 한 줄 + "답장 필요 N" (누르면 메시지 탭)
  ├ 타일 넷: 선수단(1군 인원·부상) · 영입(트레이드 마감까지·관찰 슬롯) · 구단주 목표(상태 칩, 누르면 구단 운영) · 리그(1위·5위와 경기 차)
  ├ 이번 주 일정 띠: 요일 칸마다 상대, 치른 날은 승·패 (라이벌전 표시)
  └ 하단 시뮬 버튼 + "⋯" 자동 진행
[메시지] 돌발 이벤트는 메시지 탭에 쌓인다 (2026-10-03). 급한 일(urgent)만 어느 탭에서든 창으로 뜨고, 나머지·기회형은 메시지 탭 배지로.
  결과 공개 중 생긴 이벤트는 공개 화면이 창으로 묻는다(아래). "나중에"를 누르면 메시지 탭에 남고, 진행 버튼은 "결정하고 진행하기" → 메시지 탭
[주중] 돌발 이벤트가 생기면 그 경기 뒤에서 멈춤 → 창이 뜬다 → 답하면 "N주차 이어서 · O요일 경기부터"
[주 진행 = 결과 공개] (2026-10-02, 재미 개선 1번) 진행 버튼 → 결과 공개 화면이 열리고 이 화면이 한 주를 진행한다
  ├ 경기 카드: 요일 · 홈/원정 상대 · 선발 매치업(치른 경기는 닫혀 있을 때부터) → 한 장씩 뒤집히며 열린다
  │   → 라인 스코어가 한 이닝씩 채워지고 점수가 따라 오름 → 승·패 도장 → 경기 성격 칩(끝내기·역전·연장·완봉·대승·1점 차, 최대 2)
  │   + 결승 장면 한 줄 + 승·패·세이브 투수. 접전(1점 차·끝내기·연장·역전)은 천천히, 마지막 이닝 앞에서 멈칫
  ├ 주중 돌발 이벤트: 엔진이 그 경기 뒤에서 멈춘다 → 공개가 거기까지 오면 비서 한 줄 "잠깐만요, 일이 하나 생겼어요" + 이벤트 창.
  │   "나중에"면 그 자리에 "답하기" 카드. 답하면 그 경기 카드 뒤에 "헤드라인 → 고른 답" 한 줄이 남고 남은 경기를 이어서 진행·공개.
  │   주 시작 이벤트는 첫 카드 앞에서 같은 식으로. 아직 안 치른 경기 카드는 "경기 전"
  ├ 주가 끝나면 주간 전적이 0부터 올라가고(주인공) 순위 변화(화살표 + 글자) · 이번 주 영웅
  ├ "건너뛰기"는 연출만 건너뛴다(이벤트 창은 그대로 뜬다). 열린 카드를 누르면 그 경기 문자 중계.
  │   공개 도중 나갔다 들어오면(이벤트에서 선수 상세를 보고 오는 등) 본 데까지는 다시 연출하지 않는다
  │   자동 진행(올스타까지·시즌 끝까지)은 공개 화면 없이 넘어간다
  └ 주간 브리핑 (결과 공개의 "주간 브리핑 보기" 또는 홈 요약 카드 → 전체 화면)
  └ 비서 한 줄(이번 주 전적 = 주인공) + 경기 결과·주요 장면·메아리 → 결정 성적표 → 소식 → 더 보기(기사·팬 반응·중계)
```

  화면은 "지금 − 그때"로 보여 준다. **팀 전체 성적을 일괄로 보여 주지 않고, 그 선택이 건드린 것만** 보여 준다(유저 요청 2026-10-03).
  판정 칩 넷: 통했어요(좋음) / 반반이에요(주의) / 아쉬워요(나쁨) / 지켜보는 중(회색, 표본 부족)

  | 선택이 건드린 것 | 보여 주는 지표 (판정 기준) |
  |---|---|
  | 선수 (콜업·부상자 명단·휴식·부상 투혼·폼·방출 매물 영입·유망주 시험) | 그 선수의 그 뒤 1군 기록 (타자 OPS / 투수 평균자책). 휴식 → 피로 변화, 부상 투혼 → 재발 여부, 유망주 시험 → 종합 변화 |
  | 트레이드 수락 | 받은 선수 기록 vs 보낸 선수 기록(새 팀에서) — 받은 쪽으로 판정 |
  | 트레이드 거절 | 지킨 선수 기록 vs 놓친 선수 기록 — 지킨 쪽으로 판정 |
  | 연장 계약 | 그 선수 기록 + 계약 내용 (연장했으면 "N년 X억", 넘겼으면 시즌 끝 FA 결과) |
  | 팀 폼 (선수단 미팅·특타·신임 표명·분발 촉구) | 1군 평균 폼 변화 + 연패를 끊었나 ("2경기 만에 끊음") |
  | 팀 피로 (특타) | 1군 평균 피로 변화 |
  | 팬심 · 구단주 신뢰 | 그 수치 변화 |
  | 이번 주 방침 (라이벌 주간) | 그 주 라이벌 상대 전적 |
  | 아무것도 안 함 (더 지켜본다·그냥 쓴다·거절) | 이벤트 대상 선수의 그 뒤 기록 (2군에 남겼으면 2군 기록) |

  - 보이는 곳: 홈 비서 브리핑 한 줄(판정 난 최근 결정 하나) · 결과 공개 정리 카드 한 줄 · 주간 브리핑 "결정 성적표" 카드(최근 3주) · 결정 일지(결정마다)

  "급함"·"확인" 칩, 누르면 해당 화면(시장·스카우트·로스터·커리어)으로 이동

**선수가 보내는 메시지** 〔2026-10-04, docs/13 "선수 성향과 만족도"〕: 카드의 발신자가 비서가 아니라 그 선수다.
- 카드·창 모양은 비서 카드와 같고 아바타만 **그 선수의 등번호 배지**(구단 색 원, 얼굴 없음 — §9). 머리 글자 "이름 · 종류 · 언제", 본문은 선수의 1인칭 구어체
- 카드 아래 "선수 보기"(선수 상세로) + "미스 백에게 맡기기". **약속하는 선택지는 비서 추천이 되지 않는다** — 약속은 단장이 직접 지켜야 해서, 맡기면 안전한 쪽(콜업·시장에 내놓기·시즌 뒤 반영)을 고른다
- 메시지 탭에 **선수단** 대화(아바타 "선"): 선수들이 한 말(약속 지킴·어김, 만족도 단계 변화) + 선수 메시지에 단장이 어떻게 답했나

| 종류 | 언제 | 선택지 |
|---|---|---|
| 이적 요청 | 만족도 불만 문턱 아래로 몇 주 + 야망 | (2군) 1군 기회 약속 / (1군) 다년계약 약속 / 트레이드 시장에 내놓는다 / 거절 |
| 연봉 불만 | 올해 잘하는데 시장가 절반도 못 받는 선수 | 다년계약 약속 / 시즌 뒤 반영 / 지금은 때가 아니다 |
| 멘토링 자청 | 만족한 고충성심 베테랑 | 부탁한다(유망주 능력치 소폭 ↑) / 마음만 받는다 |

**기회형 이벤트** 〔2026-10-03, 재미 개선 3번〕: 위의 위기형은 "문제가 생겼을 때" 온다. 그래서 잘나가는 팀은 할 일이 없었다(2위 팀 24주 중 9주가 빈 주).
기회형은 **좋은 상황·시장 타이밍**에서 오는 제안이고, 얻는 것과 내주는 것이 함께 있다. 칩은 "기회"(좋음 색).
- 주 시작에만, **위기형 선택 이벤트(피로·2군 폭격·출장 요구·라이벌 주간)가 없는 주에** 한 건. 시즌 상한·종류별 간격은 `incidents.opportunity`
- "넘긴다"가 언제나 안전한 기본값이고 급한 일이 아니다 — 다만 트레이드 문의·방출 매물·연장 계약은 계약이 걸려 있어 자동 진행도 멈춘다 (2026-10-03)
- 상대 팀 선수는 스카우트 범위로만 설명한다(불변 원칙 4)

| 종류 | 언제 | 선택지 |
|---|---|---|
| 트레이드 문의 | 마감 전, 우리 1군 베테랑(29세+)이 잘할 때 | 상대 유망주를 받고 보낸다(미래 ↑, 올해 전력 ↓) / 거절. 상대가 실제로 받아들일 만한 묶음만 온다(트레이드 AI 판정) |
| 방출 매물 | 다른 팀 2군의 쓸 만한 베테랑(30세+) | 데려온다(연봉 승계, 1군 등록) / 넘긴다 |
| 유망주 1군 시험 | 우리 2군 유망주(23세 이하, 잠재 높음) | 1군에 올려 써 본다(능력치 소폭 상승, 대신 1군 자리 하나) / 2군에서 더 키운다 |
| 연장 계약 협상 | 이번 시즌 끝 FA 가 되는 우리 주전 | 지금 연장(시장가보다 10% 싸게, 지금부터 연봉 인상) / 시즌 끝까지 본다(FA 시장에서 경쟁) |

### 기억이 남는 리그 — 통산·시상·역대 〔2026-10-01〕

- **포스트시즌 중 홈 카드** (2026-10-03): 비서 브리핑(상대·시즌 상대 전적·시리즈 스코어·감독의 다음 선발) → 단장 결정(방침 세그먼트 · 피로 높은 선수 휴식 칩 · 엔트리 정하기 입구, 시리즈 중엔 잠김 안내) → 대진(끝난 시리즈 + 진행 중) · 직전 우리 경기 문자 중계 입구. 진행 버튼 = "준플레이오프 2차전 진행"
- **포스트시즌이 끝나면 홈 카드**에 "포스트시즌 다시 보기"(시리즈 승자 요약)와 "시상식"(MVP · 우리 팀 수상 수) 두 줄 입구
- **시상식**: 비서 한 줄(우리 팀 수상 목록 또는 위로) → MVP·신인왕(큰 글자) → 골든글러브(포지션별) → 부문 타이틀. 수상 근거(WAR·타율·홈런 수)를 같이 쓴다. 우리 팀 수상자는 브랜드 색·굵게
- **포스트시즌 다시 보기**: 시리즈 카드(결과 한 줄 + 경기별 점수·연장·끝내기) → 경기를 누르면 문자 중계 (주간 중계 화면을 그대로 쓴다)
- **선수 상세 → 기록 탭 → 통산 기록**: 시즌별 표(첫 열 고정, 가로 스크롤) + 굵은 통산 줄 + 수상 내역. 이전 소속 시절이 있으면 한 줄 안내
- **기록 → 역대 탭**: 역대 시즌(최근부터, 누르면 그 시즌 시상식) → 통산 순위 4종(5위까지, 은퇴·떠난 선수 표시, 우리 선수 강조)

### 스토브리그 준비 〔2026-10-01〕

시즌·포스트시즌이 끝나면 진행 버튼이 "스토브리그 준비"가 되고 이 화면으로 간다 (브리핑 "결정할 것"에도 급함으로 뜬다).
비서 추천으로 미리 채워져 있어 그대로 시작해도 된다. 위에서부터:
- 비서 한 줄 + **다음 시즌 예상 선수단**(목표·최대 대비 색)
- **외국인 재계약**: 선수별 WAR·기록, 요구액(올해 연봉 대비), 일본 구단 제안이면 경고 문장, [재계약 X억] [결별], 비서 추천 칩
- **연봉 재계약**: 계약이 끝난 비FA 선수, 액수 큰 순 8명 + 더 보기. [요구 수용 Y억] [깎아서 Z억] — 깎으면 개막 폼 하락. 아끼는 돈 칩
- **FA 자격 취득**: 시장에 나가는 우리 선수 안내 (막을 수 없음, FA 시장에서 경쟁)
- **방출 명단**: 남길 가치 낮은 순, 비서 추천 체크, 12명 + 전체 보기
- **스태프**: 감독·코치·메디컬, [경질] → 위약금 확인 창
- **이대로 스토브리그 시작** → 요약 확인 창(되돌릴 수 없음)
- 숫자는 실제 처리와 같다: 외국인 요구액은 선수별 고정 시드, 연봉은 미리 보여 준 액수 그대로 계약
- 결과는 새 시즌 홈의 "스토브리그 결과" 줄에 "겨울 결정: …"으로 남는다

### 타 팀 선수 보기·선수 비교 〔2026-10-01〕

- **트레이드 목록** 한 줄: 체크(거래에 넣기) · 포지션 · **이름(누르면 선수 상세)** · 종합 범위(등급 색) ·
  핵심 능력치 범위 셋(타자 컨택·파워·수비 / 투수 구위·제구·체력) · 나이·연봉·올 시즌 기록 · "비교+"
- **들어온 트레이드 제안**(시장 탭 카드와 돌발 카드·창 모두): 받는/주는 선수마다 한 줄, 누르면 상세. 기한 표시.
  "제안 선수 한눈에 비교" / "오가는 선수 능력치 비교하기"
- **비교함**: 최대 4명, 넘치면 가장 먼저 담은 선수가 빠진다. 선수 상세·트레이드 목록에서 담고, 시장 탭 위 "비교함" 줄과
  선수 상세의 "비교 보기"로 연다. 화면을 옮겨 다녀도 남는다(세션이 들고 있음)
- **비교 화면**: 열 = 선수(이름 누르면 상세, 소속, 포지션·나이, 정보 정확도 칩). 능력치는 **범위 + 작은 범위 막대**,
  가운데가 가장 높은 칸 굵게, **최저값이 다른 모든 선수의 최고값 이상일 때만 ▲(확실히 앞섬)** — 범위가 겹치면 단정하지 않는다.
  해당 없는 능력치(투수의 컨택 등)는 "—". 이어서 잠재력(등급), 올 시즌 공개 기록(타율·OPS·홈런·타석 / 평균자책·이닝·탈삼진·WHIP / WAR,
  좋은 값 굵게), 계약(연봉·잔여·FA까지·병역·상태)
- 타 팀 능력치는 전부 `ScoutingView` 범위를 거친다(불변 원칙 4). 기록·계약은 공개 정보라 그대로 보인다

### FA 협상 테이블 〔2026-10-04, FM식〕
- FA 명단 줄의 "협상" · 협상 현황 줄을 누르면 별도 화면(제목 "FA 협상 테이블"). 위에서부터
  **협상 상황**(상태 칩·한 문장 · 라운드 · 에이전트 인내심 칸 게이지 · 경쟁 구단과 소문 · 최저 연봉 · 계약금으로 쓸 수 있는 돈) →
  **조건 표**(연봉·기간·계약금: 항목 · 중요도 점 · 선수 요구 · 우리 제안 −/+ — 요구에 못 미치는 값은 주의 색) → 보장 총액·옵션 최대 · 선수 마음 막대 →
  **옵션 조항**(이 선수에게 걸 수 있는 조항 한 줄씩: 이름 · "지난 시즌 24개 · 선수 생각: 충분히 가능/반반/어렵다" · −/+ 금액, 0 이면 "없음". 위에 걸어 둔 합계 / 상한) →
  **제안하기**(유일한 채운 버튼) · 요구대로 채우기 → 에이전트 답 카드(합의/고민 중/역제안/거절/결렬 칩 + "이 조건으로 맞추기") →

### 선수 프로필 · 트레이드 교환대 〔2026-10-03 화면 개편〕

- **선수 프로필**: 머리 = 큰 정체(등번호 배지 48dp) + 종합(이 화면의 주인공, 20sp 등급 색) + 잠재 등급(회색). 탭 넷:
  **요약**(비서의 쉬운 말 평가 + 강점·약점 칩 각 하나 + 핵심 기록 셋 + 우리 선수는 컨디션) / **능력치**(범위 막대 + 스카우트 리포트) /
  **기록**(시즌·세이버·통산) / **계약**(계약 → 선수 정보). 타 팀 선수는 요약 카드 안에 정보 정확도 한 줄.
  강점·약점은 **스카우트 범위의 중심**으로만 고른다(진짜 값으로 고르면 칩만 보고도 숨김 값이 샌다 — 불변 원칙 4)
- **만족도 카드** 〔2026-10-04, 우리 선수만, 요약 탭 컨디션 아래〕: 단계 이름 + 값 → 만족도 막대(`MeterBar`, 만족 = 좋음 색 / 보통 = 브랜드 / 불만 = 주의 / 매우 불만 = 나쁨) →
  이적 희망·진행 중인 약속 → 요인 목록(큰 것부터, +는 좋음 색 −는 나쁨 색) → 회색 한 줄 "성향 원클럽맨 — 충성심 높음 · 야망 보통 · 프로의식 높음".
  함께한 시간(유대)은 머리 캡션에서 빠지고 요인 한 줄이 됐다(유저 결정). 성향은 능력치 탭 스카우트 리포트에도 있다(타 팀은 "(추정)")
- 선수 목록 상태 아이콘에 **불만**(찡그린 얼굴, 나쁨 색): 만족도 불만 이하 또는 이적 희망
- **트레이드 교환대**: 트레이드 구역 맨 위. 보내는 것 / 받는 것 두 칸(선수 + 지명권, 누르면 빠짐, 칸마다 "+ 지명권") → 상대 반응 **칸 게이지**(숫자 대신, `tradeGauge`) + 비서 한마디 →
  "제안하기"(화면의 유일한 채운 버튼). 게이지는 선수를 넣고 뺄 때마다 미리 보기 판정으로 저절로 다시 본다(협상 피로도 없음).
  꽉 찬 게이지는 "받아들일 것 같아요"일 때만, 규칙 위반이면 빈 게이지 + 이유.
  선수는 그 아래 **좌우 두 칸 목록**(왼쪽 줄 선수 · 우리 / 오른쪽 받을 선수 · 상대, 교환대와 같은 방향, 2026-10-03)에서 줄을 눌러 넣고 뺀다.
  반 폭이라 표 대신 짧은 줄(등번호 · 이름 / 포지션 · 종합, 상세는 i 버튼). 위의 접이식 필터(포지션 · 현재 종합 · 나이)가 양쪽에 같이 걸린다.
  **지명권**: 칸마다 "+ 지명권" → 그 팀이 가진 지명권 고르기 창(우리 것 = 추가, 상대 것 = 요구). 거래할 수 없는 지명권도 고를 수는 있고,
  규칙 판정(거래 가능 연도·1라운드 연속 거래 금지 등)은 엔진이 해서 게이지에 이유로 뜬다

## 절제 규칙 (2026-10-01 추가: 화면이 조잡해지는 것 방지)
화면에 요소를 추가할 때보다 뺄 때 더 엄격하게 판단한다. 아래 규칙이 다른 섹션의 "~를 표시한다"와 충돌하면 이 규칙이 우선이며, 그 정보는 탭해서 들어가는 상세 화면으로 보낸다.

- **화면당 주인공 하나**: 각 화면에서 가장 크고 진한 요소는 하나만 둔다. 단장실 = 시뮬 버튼과 다음 경기 매치업(2026-10-03), 로스터 = 전력 카드, 주간 브리핑 = 이번 주 전적. 나머지는 그보다 작고 연하게 둔다.
- **카드 중첩 금지**: 카드 안에 카드를 넣지 않는다. 같은 화면 안의 구역은 여백과 얇은 구분선으로 나눈다. 그림자는 떠 있는 요소(바텀시트, 하단 진행 버튼)에만 쓴다.
- **색은 면이 아니라 점에**: 기본은 중립색(배경, 글자 회색 단계)이다. 등급 색과 의미 색은 숫자, 막대, 작은 칩에만 쓰고 카드 배경은 칠하지 않는다. 구단 색으로 칠한 큰 면은 진행 버튼 하나뿐이다 (기존 규칙 재확인).
- **글자 위계 3단계**: 큰 숫자·제목 / 본문 / 보조(회색) 세 단계만 쓴다. 굵기는 Regular와 Bold 두 가지만 쓴다.
- **간격은 토큰만**: 4·8·12·16·24·32dp 외의 값은 쓰지 않는다.
- **칩 남발 금지**: 칩은 상태(부상, 폼, 등급)에만 쓰고, 한 행에 최대 2개까지 붙인다. 설명용 라벨을 칩으로 만들지 않는다.
- **이모지 금지**: 아이콘은 한 세트(선 굵기·크기 통일)만 쓴다.
- **중복 문구 금지**: 제목이 말하는 내용을 부제나 라벨이 반복하지 않는다.
- **정렬**: 기본은 왼쪽 정렬, 숫자는 오른쪽 정렬(고정폭)로 한다. 가운데 정렬은 타이틀 화면에만 쓴다.
- **금지 효과**: 그라데이션, 반투명 유리 효과, 네온, 장식용 패턴.
- **점진 공개**: 메인 화면에는 요약만 둔다. 같은 화면에 섹션이 4개를 넘으면 세그먼트 탭으로 나누거나 상세 화면으로 보낸다.
  **예외: 단장실 허브** (2026-10-03 유저 결정) — 더쇼 허브처럼 여러 섹션을 한눈에 둔다. 대신 타일은 넷으로 고정하고 각 칸은 숫자 하나 + 상태 한 줄.
  **예외: 리그 허브** (2026-10-04 유저 결정) — 카드 일곱 장. 카드마다 맛보기(줄 서너 개 또는 숫자 넷)만 두고 상세는 눌러서 들어간다.

**적용 메모 (2026-10-01, M10 빼기 작업 — 규칙을 코드에 옮기며 정한 해석. 자세한 건 dev-log)**
- 글자 세 단계 = 20sp Bold(주인공) / 14sp Regular·Bold(본문, 카드 제목) / 12sp Regular(보조). Material 열두 슬롯을 셋에 몰아 맵핑해서 코드가 어느 슬롯을 골라도 못 벗어난다. 머리줄 화면 제목도 본문 굵게
- 간격 토큰에 32(xxl) 추가. padding·Spacer·spacedBy 의 숫자 dp 는 테스트(DesignRulesTest)가 막는다. 막대 높이·열 너비 같은 **크기**는 간격이 아니라서 대상 아님
- "칩"은 표시용 칩(Pill)을 말한다. 필터·선택용 FilterChip 은 조작부로 보고 규칙 밖에 두되, 한 줄에 다섯 개가 넘던 선택(투자 단계·주간 방침·상대 구단·경기 고르기)은 세그먼트 버튼·스크롤 탭으로 바꿨다
- "색은 점에": 채운 버튼은 진행 버튼 외에 화면의 유일한 주 버튼(타이틀 이어하기·이름 확정)만. 나머지는 외곽선·글자 버튼. 비서 카드도 일반 카드와 같은 중립 바탕
- 가운데 정렬은 타이틀 화면과 같은 진입 흐름(스플래시·리그 구성 대기)까지 허용으로 본다
- 카드 안 카드 금지: 카드 안 구역은 SectionDivider(여백 + 얇은 선), 이동은 NavRow(제목 + 회색 요약 + 화살표 아이콘)
## 12. 움직임 (2026-10-02, 재미 개선 1번)

화면이 정적이라는 유저 피드백으로 넣었다. 절제 규칙과 같은 방향으로 **"결과가 공개되는 순간에만"** 움직인다.

- 쓰는 곳: 결과 공개(카드 뒤집기 · 라인 스코어 채우기 · 승패 도장 · 전적 숫자 올라가기 · 순위 화살표), 화면 전환(밀어 넣기·페이드)
- 〔2026-10-03, 재미 개선 5번〕 숫자가 바뀌는 순간: 홈 전적·승률·시즌 진행 막대·팬심이 **지난주 값에서 이번 주 값으로** 이어진다
  (처음 그릴 때는 그대로 — 열 때마다 0부터 올라가면 장식이다). 순위표에 지난주 대비 오르내림(화살표 아이콘 + 칸 수, 처음 보일 때 살짝 들어옴).
  비서 후속 한마디 카드와 결과 공개 중 끼어드는 이벤트 줄은 살짝 올라오며 들어온다
- 〔2026-10-04 개정, 유저 승인〕 **그래프는 처음 나타날 때 한 번 차오른다**: 백분위 막대 등 기록 그래프는 처음 그릴 때 0 에서 제 길이까지 `motion.barFill`(0.5초) 동안, 위에서부터 `motion.barStagger`(0.05초) 간격으로. 반복하지 않고, 값이 바뀌면 지금 길이에서 이어진다. 숫자 자체는 움직이지 않는다 (처음부터 최종 값)
- 쓰지 않는 것: 반복(무한 깜빡임·맥박), 장식용 움직임, 배경 움직임, 흔들기. 금지 효과(그라데이션·유리·네온)는 움직임에도 그대로
- 시간은 토큰 `motion`(`app/ui/Tokens.kt`)으로만. 접전은 느리게, 보통 경기는 빠르게 — 긴장의 차이를 시간으로 만든다
- 모든 연출에 **건너뛰기**가 있다. 건너뛰면 끝 상태가 바로 나온다. 결과(숫자)는 연출과 상관없이 이미 정해져 있다 (불변 원칙 5)
- 움직이는 숫자도 고정폭 숫자(tnum)라 자리가 흔들리지 않는다
