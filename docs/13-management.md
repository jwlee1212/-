# 13. 구단 경영

## 확정 사항
- **커리어 모드**: 해임되어도 게임이 끝나지 않고 다른 구단으로 이어짐
- **시설 투자 없음** → 대신 **코칭스태프·메디컬팀 고용**

## 돈의 흐름
단장이 결정하는 돈만 추적. 구장 운영비 등 고정비는 제외.
| 수입 | 결정 요소 |
|---|---|
| 관중 | 연고 시장 규모 × 관중률(성적, 팬심, 스타, 연승) |
| 중계권 | 리그 전체 균등 배분 |
| 스폰서·굿즈 | 팬심, 스타 보유 |
| 포스트시즌 | 진출 라운드별 배분 |
| 모기업 지원 | 연간 기본액 × 구단주 신뢰도 × 모기업 경기 |

| 지출 | 재원 |
|---|---|
| 선수단 연봉 | 연봉 총액 |
| 계약금 | 운용 자금 |
| 감독·코치·메디컬 연봉 | 운용 자금 |
| 스카우트 예산 | 운용 자금 |
| 제재금·위약금·경질 잔여 연봉 | 운용 자금 |

현실처럼 자체 수입만으로는 적자, 모기업이 메우는 구조. **구단주 허용 적자 범위** 안에서 운영.

## 구단주 신뢰도 (0~100)
- 개막 전 구단 성격에 맞는 시즌 목표 제시 (예: 나이츠 KS 진출, 로얄스 PS 진출, 스톰 승률 .450 + 유망주 2명 1군 정착, 코메츠 적자 30% 축소)
- 시즌 말 평가: 목표 달성 + 적자 준수 + 팬심 변화
- 높으면: 지원 증가, 대형 FA 승인
- 낮으면: 지원 삭감, 일정 금액 이상 계약은 구단주 승인 필요
- 시즌 중 **경고 단계** 알림

## 팬심 (0~100)
| 상승 | 하락 |
|---|---|
| 승리, 연승, PS 진출 | 패배, 연패, 하위권 |
| 대형 FA 영입 | 프랜차이즈 스타 트레이드·방출 (큰 폭) |
| 신인 스타 등장 | 스타 FA 유출 |
| 레전드 은퇴식 | 잦은 감독 교체 |
부산 타이드는 변화 폭 1.5배.

## 모기업 이벤트
- 매년 호황/보통/불황 → 지원금
- 불황 누적 시 시즌 중 예산 삭감 통보
- 드물게 모기업 교체 (구단 별칭 유지, 새 모기업 투자 성향 랜덤)

## 스태프
**코칭스태프**: 감독(06) + 타격·투수·수비주루 코치 + 2군 감독 (09)

**메디컬팀**
| 스태프 | 효과 |
|---|---|
| 팀 닥터 | 부상 발생률 감소, 수술 후 영구 하락 폭 감소 |
| 재활 트레이너 | 회복 기간 단축, 재발 위험 감소 |
| 컨디셔닝 코치 | 피로 회복 속도 증가 |
- 등급별 효과 10~20% 수준 (작게 유지, "무조건 최고 스태프"가 정답이 되지 않게)
- 연봉은 운용 자금
- 스토브리그 스태프 시장, 좋은 스태프는 AI와 경쟁

## 해임
- 시즌 말 신뢰도 20 미만 → 해임
- 2년 연속 목표 미달성 시 신뢰도 큰 폭 하락

## 커리어 모드
세이브 중심은 **단장 개인** (`GeneralManager`).
| 항목 | 내용 |
|---|---|
| 평판 (0~100) | 기대 대비 성과. 약팀 5강 > 강팀 우승 |
| 커리어 기록 | 재임 구단, 시즌 성적, 우승, 주요 거래 |
- AI 구단에도 가벼운 AI 단장(이름, 평판, 거래 성향)이 있고, 목표 실패 시 해임 → 빈자리 발생
- 해임 시: 시즌 종료 때 평판에 맞는 구단들이 제안. 제안이 없으면 1년 **해설위원**(리그 관전) 후 재제안
- 자진 이직: 계약 만료 또는 더 좋은 제안 시 시즌 종료 시점에 이동
- 플레이 모드(단장 전용/감독 겸직)는 이직 후에도 유지, 시즌 사이에 변경 가능

### 과거 선택의 메아리
단장의 선수 결정(드래프트 지명, 트레이드 영입·방출, FA 영입, 외국인 영입)을 커리어 기록에 남기고,
그 결정이 몇 년 뒤 경기에서 되돌아오는 순간을 비서가 한 줄로 알린다 (주당 최대 2건).
- 보낸 선수가 **우리를 상대로** 홈런·승리 투수 → "2년 전 트레이드로 보낸 OOO 선수가 우리 상대로 홈런을 쳤어요."
- 데려온 선수가 한 주에 홈런 2개 이상 → "그때 결정이 빛을 보네요."
- 지명한 신인이 처음 1군 무대에 → "2026 드래프트에서 뽑은 OOO 선수가 올해 처음 1군 무대를 밟았어요."
- 트레이드·드래프트는 기존 기록(트레이드 기록, 드래프트 결과)에서 뽑고, FA·외국인만 따로 적는다
- 경기 결과에는 영향이 없다

### 장기 재임 선수 유대
이 단장 밑에서 함께한 시즌 수(올 시즌 포함). 3 / 5 / 8시즌 → **동료 / 믿음 / 프랜차이즈**.
부임 전부터 있던 선수는 부임 시즌부터, 데려온 선수는 영입 시즌부터, 지명 선수는 입단(다음 시즌)부터 센다.

### 선수 성향과 만족도 〔2026-10-04 유저 요청 "FM처럼 선수 개개인의 충성도 수치 → 선수에게서 오는 돌발 이벤트"〕

유저 결정: ① 만족도가 **실제 결과에 영향**을 준다 ② 선수 상세에 **막대로 표시** ③ 유대는 만족도에 **합친다**. FM 모티브, 선수가 직접 메시지를 보낸다.
수치는 전부 `balance.json` `morale` (초안).

**두 층으로 나눈다** (FM 의 성격 + 기분):

| 층 | 무엇 | 변하나 | 누구에게 |
|---|---|---|---|
| 성향 (숨김) | 충성심 · 야망 · 프로의식 (각 1~100) | 안 변한다 | 모든 선수. 숨김 수치 (docs/02) |
| 만족도 (0~100) | 지금 이 구단·단장에게 얼마나 만족하나 | 매주 | **유저 구단 선수만** (AI 구단은 굴리지 않는다) |

- **충성심**: 구단 애착. 함께한 시즌(유대) 효과가 커지고, FA 때 원소속 구단을 더 원하고, 연장 계약을 싸게 해 준다
- **야망**: 이기고 싶고 뛰고 싶다. 출장 기회·팀 성적 요인이 커지고, 불만이 쌓이면 이적을 요구한다
- **프로의식**: 기분이 경기력에 덜 번진다(만족도가 낮을 때 폼 하락 폭이 줄어든다). 낮으면 불만을 더 자주 말한다

**만족도 = 목표값 쪽으로 매주 끌려가는 값.** 목표값 = 50 + 요인 합 (0~100):

| 요인 | 내용 |
|---|---|
| 출장 기회 | 1군이면 + (주전이면 더). 2군인데 같은 자리 1군 최하위보다 낫거나 고액 베테랑이면 −. 23세 이하 2군은 0. 야망이 배율 |
| 팀 성적 | 승률 − .500 에 비례 (10경기 뒤부터). 야망이 배율 |
| 연봉 | 3시즌 이상 뛴 선수가 기대 WAR 시장가의 절반도 못 받으면 −. 시장가 이상이면 소폭 + |
| 함께한 시간 (유대) | 이 단장 밑 시즌 수 × 계수 (상한 있음). 충성심이 배율. 동료/믿음/프랜차이즈 단계 이름은 그대로 보인다 |
| 기억 | 단장의 결정·약속. 하나하나 값과 지속 주 수가 있고 시간이 지나면 옅어진다. **같은 종류는 쌓이지 않고 덮어쓴다** (콜업·말소 반복으로 만족도를 올리는 꼼수 방지) |

- 기억이 생기면 그 값의 절반이 **바로** 만족도에 반영되고, 나머지는 목표값을 통해 천천히 따라온다
- 새로 온 선수(트레이드·FA·신인)는 목표값에서 시작한다

**기억이 생기는 결정** (돌발 이벤트 답·단장 직접 조작)

| 결정 | 기억 |
|---|---|
| SNS 논란: 감싼다 / 사과 / 징계 | + / 소폭 − / − |
| 부상 투혼: 본인 뜻대로 뛰게 한다 | + |
| 2군 폭격·유망주 시험·출장 요구: 1군에 올린다 / 안 올린다 | + / − |
| 연장 계약: 연장 / 미룬다 | + / − |
| 트레이드 문의를 거절하고 지킨다 | + |
| 단장이 직접 1군에 올린다 / 2군으로 내린다 (주전급만) | + / − |
| 비FA 다년계약 성사 | + |
| 약속을 지켰다 / 어겼다 | + / 크게 − (오래 간다) |

**약속** (FM 의 약속): 선수 메시지에 "약속한다"로 답하면 생긴다. 기한 안에 지키면 +, 못 지키면 크게 −.
- 출장 약속: N주 안에 1군 등록
- 계약 약속: 정규시즌이 끝나기 전에 다년계약(또는 연장)

**만족도가 바꾸는 것** (유저 결정 ① — 영향이 있어야 재밌다)
1. **폼**: 매일 폼이 돌아가는 중심이 50 → 50 + (만족도 − 50) × 계수. 만족도가 낮을 때는 프로의식이 높을수록 덜 빠진다
2. **비FA 다년계약·연장 계약 요구액**: 만족도·충성심이 높으면 싸고, 낮으면 비싸다 (그래도 FA 시장가는 넘지 않는다). 만족도가 아주 낮으면 협상 자체를 거부한다
3. **FA 잔류**: 우리 구단에서 FA 로 나온 선수가 우리에게 주는 애정 점수(`faMarket.weights.loyalty`)가 충성심·만족도에 따라 커지거나 줄어든다. 불만이 큰 우리 FA 는 다른 팀 조건을 더 좋게 본다.
   〔임시 결정〕 AI 구단 FA 에는 걸지 않는다 — 걸었더니 30시즌 장기 밸런스의 90+ 수가 8.8 → 10.8 로 움직였다(시드 5150). AI 생태계는 예전 그대로 둔다
4. **선수가 보내는 돌발 이벤트** (아래)

**선수가 직접 보내는 메시지 (돌발 이벤트)** — 카드의 발신자가 비서가 아니라 그 선수다. 1인칭 구어체.

| 종류 | 언제 | 선택지 |
|---|---|---|
| 이적 요청 | 만족도가 불만 문턱 아래로 N주 이상 + 야망 | 약속으로 달랜다(2군이면 출장 약속) / 트레이드 시장에 내놓는다(이적 희망 표시, 트레이드 문의가 그 선수로 먼저 온다) / 거절한다(크게 −) |
| 연봉 불만 | 3시즌 이상, 올해 잘하는데 시장가의 절반도 못 받는다 | 다년계약을 약속한다 / 스토브리그 연봉 협상에서 반영한다(소폭 +) / 지금은 때가 아니다(−) |
| 출장 요구 (기존 개편) | 2군 고액 베테랑 | 1군에 올린다 / N주 안에 올리겠다고 약속 / 선을 긋는다 |
| 후배 멘토링 자청 | 만족도 높은 고충성심 베테랑(31세+) | 부탁한다(같은 쪽 23세 이하 유망주 능력치 소폭 ↑, 베테랑 +) / 마음만 받는다 |

- 선수 메시지는 **기회형 슬롯을 함께 쓴다**(위기형 선택 이벤트가 없는 주에 한 건) — 이벤트 수가 늘어 잔소리가 되지 않게. 이적 요청만 예외로 언제든 온다
- 같은 선수에게 같은 종류는 `cooldownWeeks` 안에 다시 오지 않는다
- 자동 진행 중에는 비서가 추천대로 처리한다 (계약이 걸린 일이 아니다)

**보여 주기**
- 선수 상세 요약 탭(우리 선수): **만족도 막대**(0~100, 의미 색) + 단계 이름(매우 만족~매우 불만) + 요인 목록(“출장 기회 −8”) + 진행 중인 약속 + 성향 한 줄
- 성향은 단계 글자로만(높음/보통/낮음) — 우리 선수도 숫자는 안 보인다. 타 팀 선수는 스카우트 정확도만큼 흐린 글자 (내구성 코멘트와 같은 방식)
- 메시지 탭에 **선수단** 대화: 선수들이 보낸 말(약속 지킴·어김, 만족도 단계 변화, 메시지 이벤트 답)
- 로스터 선수 줄: 만족도가 불만 이하면 상태 아이콘
